# Escape Drone — 使用マニュアル（日本語）

[English manual](MANUAL.en.md)

**Escape Drone** は、物理エンジン **MuJoCo（WebAssembly）** で 5 台のクアッドローターを同時に剛体シミュレートするデスクトップ／ブラウザアプリです。

逃げる機体 **D0** が A 地点から B 地点へ決められたルートを飛び、B の手前で待ち構える 4 機の迎撃ドローン **d1〜d4** の体当たり（比例航法・会合点突入）を避けて B に着陸できるかを検証します。全機が自律制御（AUTO）で飛び、手動操縦は行いません。**風・乱流・突風・未知の追加質量（重い機体）・通信遅延や誤差・障害物の認識方式（目視カメラ／リアルタイム位置共有／センサー融合）** などの条件を自在に変えて試行し、結果を CSV で保存できます。

画面は左パネル右上のボタン（または <kbd>L</kbd> キー）で **日本語と英語（English）** をいつでも切り替えられます。

## 1. 起動方法

完全オフライン（インターネット接続なし）で動作します。

| 版 | 起動のしかた |
| :--- | :--- |
| **macOS デスクトップ版（.dmg）** | `EscapeDrone_1.0.0_aarch64.dmg` を開き、`EscapeDrone` を「アプリケーション」フォルダへドラッグして起動します。初回起動時に「開発元を確認できません」と表示された場合は、Finder でアプリアイコンを **右クリック（Control + クリック）→「開く」** を選んでください。 |
| **ブラウザ / 開発版** | `escape_drone` フォルダで `npm install`（初回のみ）に続いて `npm run dev` を実行し、ブラウザで `http://localhost:5173` を開きます。配布用の静的ファイルは `npm run build` で `dist/` に生成されます。 |

## 2. 言語の切り替え（日本語 / English）

- 左パネル最上部の **「EN」/「日本語」ボタン** をクリックすると、その場で全画面の表示言語が切り替わります。
- キーボードの <kbd>L</kbd> キーでも切り替えられます。
- 選択した言語はストレージに保存され、次回起動時にも維持されます。
- URL パラメータ `?lang=en` または `?lang=ja` で初期言語を指定することもできます。

切り替わる対象: パネル見出し・プリセット名と説明・パラメータ名と選択肢・カメラ名・HUD・テレメトリー表・イベントログ・3D 空間内のパッドラベル（`A 出発` / `A Start`、`B 目的地` / `B Target`）・結果ダイアログ・出力される CSV の列名と値。

## 3. シミュレーションの設定

### 配置

真上から見た配置です（x は東、y は北、単位 m）。

```
            C1(95,55)        C3(165,40)
 A(-220,0) ──── ルート（高度 25 m）──────────── B(220,0)
                     C2(125,-55)     C4(185,-35)
```

| 地点 | 内容 |
|---|---|
| **A（出発）** | D0 の出発地。真上に高度 25 m まで上昇してからルートに入ります |
| **B（目的地）** | 目的地。半径 15 m の**防護エリア**があり、D0 が入ると迎撃機は攻撃をやめて離脱します |
| **ルート** | `A(-220, 0)` → `(-110, 45)` → `(20, -35)` → `(130, 10)` → `B(220, 0)` の折れ線（高度 25 m） |
| **C1〜C4** | 迎撃機 d1〜d4 の待機地点。待機高度は C1: 22 m・C2: 30 m・C3: 18 m・C4: 26 m（シードにより ±5 m） |

### 機体

| 機体 | 内容 |
|---|---|
| **D0（白・青）** | 質量 1.84 kg、ロータ 1 基あたり最大推力 13 N（推力重量比 約 2.9） |
| **d1〜d4（赤）** | 同じ機体にプロペラガード付き（当たり判定が少し広い）、ロータ最大推力 15 N |

### ルール

- ドローン同士が接触すると、**両方が墜落**します（速度に関係なく）。迎撃機同士がぶつかって相討ちになることもあります。
- 2 m/s を超える速さで地面に当たるか、大きく傾いて接地すると墜落です。
- **成功（Success）**: D0 が防護エリアに到達し、B に着陸する。
- **失敗（Failed）**: D0 が墜落する、または 180 秒以内に着陸できない。

迎撃機は地上レーダーで D0 の位置を常に知っている想定です。D0 が攻撃開始距離（既定 110 m）に入ると、予測した会合点に向けて突入します。

| 項目（日本語 / English） | 意味 |

| **計画クリアランス** / Planned Clearance | 回避計画が見込んでいる、迎撃機との最小距離 |
| **最接近** / Closest Pass | これまでで最も近づいた迎撃機とその距離 |
| **D0 質量推定** / D0 Mass Est. | 制御器が飛行中に推定した質量と、実際の質量 |
| **風（D0 位置）** / Wind (at D0) | D0 の位置での風速。突風中は「突風 / Gust」と表示 |

### 3D 画面の表示

パネルの「カメラ」欄のチェックで表示を切り替えます。

| 表示 | 意味 |
|---|---|
| **航跡** (Flight trails) | 青 = D0、赤 = 迎撃機 d1〜d4 |
| **D0 の認識** (D0 perception) | **黄色の網目の球** = D0 が推定している迎撃機の位置（半径 = 安全距離）。最も危険な機体はオレンジ、見失っている間は薄く表示。**黄色の扇形** = カメラの視野と検知距離（カメラを使う方式のとき）。**矢印** = D0 が選んだ速度（緑 = ルート飛行、オレンジ = 回避中） |
| **迎撃機の狙い点** (Interceptor aim lines) | 攻撃中の迎撃機から、予測した会合点への赤い破線 |

## 5. シナリオ（8 種類のプリセット）

パネルの「1. シナリオ」から選ぶと、条件がまとめて設定されます（シードは現在の値を維持します）。

| シナリオ（日本語 / English） | 認識方式 | 条件 |
|---|---|---|
| **リアルタイム把握** / Real-Time Share | リアルタイム（理想） | 無風・標準機体 |
| **目視のみ** / Visual Only | 目視 | 無風・標準機体。前方カメラ（視野 120°・70 m）のみ |
| **強風** / Strong Wind | リアルタイム（理想） | 北西から 9 m/s、突風 +5 m/s、乱流 0.25 |
| **重い機体** / Heavy Craft | リアルタイム（理想） | D0 に未知の追加質量 +1.5 kg |
| **強風＋重量＋目視** / Hard: Visual | 目視 | 南南西から 8 m/s、突風 +4 m/s、乱流 0.25、D0 に +1.2 kg |
| **強風＋重量＋リアルタイム** / Hard: Real-Time | リアルタイム（現実的） | 同上。位置共有は 1 Hz・遅れ 0.5 s・誤差 3 m・欠落 10 % |
| **強風＋重量＋目視＋リアルタイム** / Hard: Sensor Fusion | 目視＋リアルタイム | 同上。位置共有と前方カメラをカルマンフィルタで融合 |
| **回避なし（比較）** / No Evasion (Baseline) | 回避しない | 無風・標準機体。迎撃機に撃墜される比較用 |

後半の 3 つの厳しい条件（Hard）は、同じ環境・機体条件で認識方式だけを変えてあるため、「カメラだけ」「現実的な位置共有だけ」「両方のセンサー融合」の違いを直接比較できます。

条件を手で変えると、シナリオ名は「カスタム / Custom」になります。

## 6. 条件の設定

パネルの「2. 条件」で変えます。**条件を変えると、その場で最初からやり直し**になります。

### D0（逃げる機体）

| 項目（日本語 / English） | 範囲 | 既定 | 説明 |
|---|---|---|---|
| **障害物の認識** / Obstacle Perception | — | リアルタイム | 次章を参照 |
| **巡航速度** / Cruise Speed | 5〜15 m/s | 10 | ルートを飛ぶ速さ |
| **回避時の最高速度** / Max Evade Speed | 6〜20 m/s | 14 | 回避するときに出してよい速さ |
| **追加質量（重い機体）** / Extra Mass | 0〜3 kg | 0 | 制御器には知らせません。飛行中に質量を推定して適応します。重いほど推力の余裕が減り、急な回避ができません |
| **安全距離** / Safe Distance | 1〜8 m | 3 | 迎撃機との間に確保しようとする距離 |
| **カメラ視野** / Camera FOV | 40〜360° | 120 | 前方カメラの水平視野（垂直は ±35° 固定） |
| **目視の検知距離** / Visual Range | 20〜150 m | 70 | これより遠い機体はカメラで見つけられません |

### リアルタイム位置共有

「リアルタイム」と「目視＋リアルタイム」で使います。既定は理想値（毎フレーム・誤差なし）です。

| 項目（日本語 / English） | 範囲 | 既定 | 説明 |
|---|---|---|---|
| **更新周期** / Broadcast Rate | 0.5〜20 Hz | 20 | 位置情報が届く頻度 |
| **遅れ** / Comms Latency | 0〜2 s | 0 | 届いた情報がどれだけ古いか |
| **位置誤差** / Position Error | 0〜10 m | 0 | GNSS などの位置の誤差（1σ） |
| **欠落率** / Packet Loss | 0〜90 % | 0 | 届かない情報の割合 |

### d1〜d4（迎撃機）

| 項目（日本語 / English） | 範囲 | 既定 | 説明 |
|---|---|---|---|
| **攻撃速度** / Attack Speed | 6〜20 m/s | 12 | 突入するときの速さ（シードにより ±0.8 m/s） |
| **攻撃開始距離** / Trigger Distance | 30〜250 m | 110 | D0 がこの距離に入ると攻撃開始（シードにより ±15 m） |
| **追加質量** / Extra Mass | 0〜3 kg | 0 | 迎撃機に載せる重さ |
| **迎撃機同士の衝突回避** / Mutual Avoidance | — | あり | 迎撃機どうしが 6 m 以内に近づくと離れようとします。オフにすると迎撃機同士の同士討ちが増えます |

### 環境

| 項目（日本語 / English） | 範囲 | 既定 | 説明 |
|---|---|---|---|
| **風速** / Wind Speed | 0〜15 m/s | 0 | 平均風速（高度 60 m 基準、地表に近いほど弱い対数分布） |
| **風向** / Wind Direction (From) | 0〜359° | 北 (N) | 風が**吹いてくる**方向 |
| **突風** / Wind Gust | 0〜10 m/s | 0 | 数秒続く突風の強さ（不定期に発生） |
| **乱流** / Turbulence | 0〜0.6 | 0 | 平均風速に対する乱れの強さ |
| **乱数シード** / Random Seed | 1〜50 | 1 | 下記を参照 |

**乱数シード**を変えると、風の乱れと突風のタイミング、カメラ・位置共有の誤差と検知・欠落、迎撃機ごとの待機高度・攻撃速度・攻撃開始距離・離陸時刻のばらつきが変わります。同じシードと同じ条件なら、毎回同じ結果が再現されます。

## 7. 認識方式（4 モード）

D0 が迎撃機をどう知るかを選びます。

### 1. リアルタイム位置把握（Real-Time Position Share）

位置共有（Remote ID・UTM・地上レーダーなど）で、**全方向・距離に関係なく**全機の位置と速度を受け取ります。

- 既定（理想値）では、真の位置・速度がそのまま分かります。
- 更新周期・遅れ・誤差・欠落を設定すると、届いた情報から位置と速度を推定し、次の情報が届くまでは予測で補います。終盤に迎撃機が急に向きを変えると、情報の遅れの分だけ反応が遅れます。

### 2. 目視（前方カメラ / Visual）

D0 のカメラに**写った機体だけ**を認識します。

- 視野（既定 120°）と検知距離（既定 70 m）の外は見えません。遠いほど見つけにくくなります（検知距離ちょうどで約 4 割）。
- 方向は正確ですが、距離は写った大きさから推定するので誤差が大きく（距離の約 6 %）、0.1 秒の遅れがあります。
- 見えた位置からカルマンフィルタで位置と速度を推定し、見失っても 4 秒間は予測で追い続けます。推定が不確かなほど、安全距離を広めに取ります。
- 脅威がないときはカメラを左右に振って見回し、脅威を見つけたらその方向にカメラを向けます。
- 弱点は、死角（後方・真横）から来る機体です。

### 3. 目視＋リアルタイム（Visual + Real-Time Fusion）

位置共有とカメラの両方を、1 つのカルマンフィルタにまとめて推定します。

- 遠くの機体や死角の機体は位置共有で把握し、その方向にカメラを向けます。
- 近づいた機体はカメラで、遅れと誤差の小さい位置を得ます。
- 位置共有に遅れや誤差がある現実的な条件で、両者を組み合わせた高い生存率を発揮します。

### 4. 回避しない（No Evasion）

迎撃機を無視してルートどおりに飛びます。比較用です。

## 8. 実行と操作・ショートカット

| ボタン / キー | 動作 |
|---|---|
| **▶ 開始** / <kbd>Space</kbd> | 全機の自動運転を開始。実行後は「▶ 最初から / ▶ Restart」になり、押すと同じ条件で最初からやり直します |

| **カメラ** / <kbd>C</kbd> | 下表の 4 種類を順番に切り替え |
| **EN / 日本語** / <kbd>L</kbd> | 表示言語を日本語と英語で切り替え |

|---|---|
| **追従** / Chase | D0 の後ろから追いかける |
| **迎撃機** / Interceptor | D0 に最も近い攻撃中の迎撃機の後ろから追いかける |
| **自由** / Orbit | マウスドラッグで回転・右ドラッグで移動・ホイールでズーム（注視点は D0 に追従） |
| **全体** / Overview | 配置全体を上空から見渡す |

試行が終わると約 1.8 秒後に結果画面が出ます。終了後も 6 秒ほどは物理計算が続き、墜落した機体が落ちていく様子を見られます。

## 9. 結果と CSV 保存

### 結果画面

成功 / 失敗とその理由、飛行時間、飛行距離、迎撃機の最接近、墜落した迎撃機の数、主な条件を表示します。

- **📄 CSV 保存 / Save CSV**: それまでの全試行を CSV で保存
- **もう一度 / Run Again**: 同じ条件で最初から実行
- **閉じる / Close**: 結果画面を閉じる

### 試行結果の履歴と保存先

試行が終わるたびに、自動で 1 行ずつ記録されます（途中でリセットした試行は記録されません）。

- パネル下の「試行結果」に件数と直近 30 件を表示します。
- 記録はローカルストレージに保存され、アプリを再起動しても残ります。
- **macOS デスクトップ版**では、「CSV 保存」を押すと Mac の **「ダウンロード（`~/Downloads`）」フォルダ** に `escape_drone_trials_日付_時刻.csv` が直接保存され、左下のイベントログに保存先のフルパスが表示されます。ブラウザ版では通常のファイルダウンロードになります。

### CSV の列（全 36 列）

1 試行 1 行です。UTF-8（BOM 付き）なので Excel でそのまま文字化けせずに開けます。表示言語が英語のときは英語ヘッダー・英語表記で出力されます。

| 区分 | 列 |
|---|---|
| **試行** | 日時、プリセット、シード |
| **条件** | 認識方式、風速、風向、突風、乱流、D0 追加質量、迎撃機追加質量、D0 巡航速度、D0 回避最高速度、迎撃機攻撃速度、攻撃開始距離、安全距離、カメラ視野、目視検知距離、位置共有周期・遅れ・誤差・欠落率、迎撃機相互回避 |
| **結果** | 結果（成功 / 失敗）、理由、飛行時間、D0 飛行距離、最接近距離、最接近機、回避回数、墜落した迎撃機数、D0 質量推定、D0 実質量、d1〜d4 の最終状態（「健在」または「墜落: D0 と接触」など） |

## 10. ヘッドレス実行（大量試行）

画面を出さずに、Node.js で多数の試行をまとめて高速実行できます（ソース同梱時）。

```sh
cd escape_drone
```

## 11. 物理・制御・回避アルゴリズムのしくみ

### 物理（`src/sim.ts`）

- 5 機を 1 つの MuJoCo モデルで **2 ms（500 Hz）** ごとに剛体力学計算します。
- 各機は 4 つのロータを持ち、推力には一次遅れ（時定数 `0.035 s`）があります。
- 空気抵抗は、風（対数高度分布＋Ornstein-Uhlenbeck 乱流＋突風）に対する相対速度から計算します。
- 地面との接触や機体同士の接触は、MuJoCo の厳密な接触判定をそのまま使います。

### 制御（各機共通・幾何学的 SE(3) 制御）

- 位置・速度の指令から必要な推力と姿勢（Lee et al. 幾何学的姿勢制御）を求め、4 つのロータ推力に配分します。
- **外乱オブザーバ（DOB）**: 実際の加速度とロータが生む加速度の差から風などの水平外力をリアルタイムに推定し、打ち消します。
- **オンライン質量推定**: 推力と鉛直方向の加速度から未知の質量を飛行中に推定し、追加質量に適応します。
- 推力が飽和するときは鉛直方向（高度維持）を優先し、残りを水平方向の加速と回避に配分します。

### D0 の回避（`src/pilot.ts`）

1. ルート上の 18 m 先を目標に、巡航速度で進む基準速度を求めます。
2. 迎撃機が 90 m 以内にいると、水平方向（15° 刻み・24 方向）× 速さ（4 段階）× 上下速度（3 段階）の候補速度ベクトルを生成します。
3. 候補ごとに、D0 がその速度で 3 秒間飛んだ場合と、迎撃機が比例航法（会合点予測）で D0 を追いかけてくる動きを先読み計算します。
4. 安全距離（推定不確かさに応じたマージン加算）を割り込む度合い、ルートからのずれ、地面との近さ、指令の急変を合計したコストが最小の候補速度を 20 Hz で選びます。

### 迎撃機 d1〜d4 の誘導

- 自分の攻撃速度で D0 と出会える点（会合点）を予測し、そこへ向けて全速で突入します（最大 4 秒先まで先読み）。
- 「迎撃機同士の衝突回避」がオンのときは、味方機が 6 m 以内に近づくと反発速度を加えます。

## 12. 制約と注意・困ったとき

- **本シミュレーションの結果だけで、実機の飛行安全性を保証することはできません。** 空力・センサーのモデルは簡略化しています。
- 画面での 1 回ごとの結果は乱数シード（突風のタイミングや初期配置の微差）に左右されます。認識方式や条件の優劣を定量比較するときは、シードを変えて複数回試行してください。

| 症状 | 対処 |
|---|---|
| macOS で初回起動時に警告が出る | Finder で `EscapeDrone` を **右クリック（Control + クリック）→「開く」** を選んでください |
| 試行結果の履歴をリセットしたい | 左パネル下部「試行結果」の **「消去 / Clear」** ボタンを押してください |
| 動きが重い | 再生速度を `×1` 以下にするか、「航跡」のチェックを外してください |
