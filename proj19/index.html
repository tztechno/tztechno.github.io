SYSTEM FEATURES // 主な特徴

⚙️

完全ブラウザ実行AI

Hugging Faceからモデルを初回ダウンロードした後は、すべての文章生成（鑑定文）処理があなたのブラウザ内で行われます。外部のAPIサーバーに依存しないため、回線混雑やサーバーエラーによるフリーズがありません。

一度展開したネイタルチャートに対して、さらに質問を重ねることができます。「アセンダントが示す私の第一印象は？」「今年のトランジットを活かす行動は？」など、納得いくまで問いかけられます。

TECHNICAL SPEC // 技術構成

サイバーホロスコープは、高度なブラウザ内実行基盤を設計することにより、サーバーコストを極限まで削減し、ユーザーの絶対的なプライバシー保護とローカルならではの低レイテンシを実現しています。

wllama + WebAssembly

C++で記述された超高速推論エンジン「llama.cpp」をWebAssemblyにコンパイルし、ブラウザ上でネイティブに近い処理速度を実現。Web Workerで推論スレッドを完全に独立させることで、AIが複雑な鑑定文を作成している最中も、ブラウザのチャート展開演出やチャット操作が一切カクつくことなくスムーズに動作します。

GGUFモデルのスマートキャッシュ

初回起動時にのみ、Hugging FaceのパブリックCDNから量子化された約2GBのモデルファイル（Qwen2.5-3B-Instruct-Q4_K_M）をダウンロードします。ダウンロードされたモデルはブラウザ内のキャッシュストレージに自動的に保存されるため、2回目以降のアクセスではロードをスキップし、一瞬で鑑定システムが起動します。

FAQ // よくある質問

Q: なぜ3回しか無料で鑑定できないのですか？

本アプリケーションは完全に個人のデバイス上で推論を行いますが、初回起動時にパブリックネットワークからモデル（約2GB）をロードします。また、開発やシステムの品質維持のため、無制限鑑定を行う場合には500円のワンタイムライセンス（買い切り）の購入をお願いしております。

Q: 入力した生年月日時・出生地や悩みのデータは運営側に送信されますか？

いいえ、送信されません。本システムは、ブラウザ内のローカルニューラルネットワークで推論モデルを稼働させており、一切の生年月日時、出生地、会話テキスト、鑑定結果をサーバーへ送信したり、データ収集に利用したりすることはございません。

Q: スマートフォンでも動作しますか？

はい、比較的新しいスペックのiOSまたはAndroid端末のChromeやSafariブラウザであれば動作可能です。ただし、3B（30億パラメータ）のモデルを展開するため、端末の物理メモリ（RAM）が最低でも4GB以上（推奨8GB以上）あるとスムーズに動きます。古いスマートフォンではメモリ不足によりブラウザが強制終了する場合があります。

Q: オフラインでも鑑定できますか？

はい、一度モデルをダウンロードし、キャッシュへの保存が完了すれば、その後は完全に機内モードなどのインターネット環境のない「オフライン」の状態でも出生図を展開し、AIの鑑定を生成することができます。ただし出生地名から座標を割り出す初回の地名検索のみ、ネットワーク接続が必要です。
