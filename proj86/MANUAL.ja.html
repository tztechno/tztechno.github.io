Flight Viewer ユーザーマニュアル（日本語）

フライトデータ（CSV）を読み込み、CesiumJS の 3D 地球儀の上で 3D の機体を記録の時刻どおりに飛ばして再生するアプリです。

  • 対応 OS：macOS 11 以降（Apple Silicon）
  • 必要なもの：インターネット接続（地図と地形の取得）。アカウント登録・API キーは不要
  • 表示言語：日本語 / English（パネル右上のボタンで切り替え）

1. インストール

  1. Flight Viewer_x.y.z_aarch64.dmg を開き、Flight Viewer を「アプリケーション」へドラッグします。
  2. 初回は「開発元を確認できない」と表示されます（Apple の公証を受けていないため）。
    • macOS 14 以前：Finder でアプリを右クリック →「開く」
    • macOS 15 以降：一度開こうとしたあと、「システム設定 → プライバシーとセキュリティ」の下にある「このまま開く」を押す

2. CSV を開く

  • 左パネルの「📂 CSV を開く」、またはウィンドウへ CSV をドラッグ＆ドロップします。
  • 「追加で開く」にチェックすると、表示中の便に重ねて追加します。複数の便は色分けされます。
  • 「表示中の便」で、表示／非表示（チェック）、選択（クリック）、閉じる（×）ができます。

読み込める CSV

内容 列名の例 備考
時刻（必須） time timestamp unix_time utc datetime UNIX 秒／ミリ秒、ISO 8601、2026-11-01 17:49:00、2026/11/01 17:49:00。タイムゾーン無しは UTC
緯度・経度（必須） latitude/lat、longitude/lon/lng、または position（"緯度,経度"） 10 進数の度
高度 altitude_ft alt_m altitude baro_altitude_m 列名に _m → メートル、ft → フィート、それ以外はフィート（パネルで変更可）
便名・機体 ID callsign flight、icao24 hex registration 機体 ID ごとに別の便として扱います
地上 on_ground true/1/yes の行は高度 0
出来事 note event remark 空でない行が「出来事」になります

Flightradar24 の CSV と、Flight Dashboard の軌跡 CSV はそのまま読み込めます。1 便につき有効な点が 2 点以上必要です。

3. 再生

  • 画面下の再生バー：再生／一時停止（Space）、速度 ×0.25〜×300、表示する時間帯
  • 高度グラフ：全便の高度の推移。クリック・ドラッグでその時刻へ。▼ は出来事の位置
  • [ ] で 10 秒戻る／進む（Shift で 60 秒）
  • 選択中の便の高度・対地速度・昇降率・方位・位置を常に表示します

時間帯

最初の位置と日付から現地の時間帯を推定します（日本・米国本土は夏時間を含めて判定、それ以外は経度から推定）。UTC・JST・EDT・EST・PDT・PST・CEST・CET にも切り替えられます。

出来事

CSV の note 列に書いた内容が「出来事」一覧に時刻順に並びます。クリックするとその 5 秒前へ移動し、再生中に通過するとバナーで表示します。

4. 視点

視点 操作
自由 左ドラッグ＝移動、ホイール＝ズーム、Ctrl＋ドラッグ＝傾き・回転、ダブルクリック＝その地点へ寄る、W/S/A/D・R/F・矢印＝飛行（Shift で高速）
追尾 選択中の機体を画面中央に捉え続けます
後方 機体の後ろから追います。ドラッグか矢印で見回し、ホイールで距離
操縦席 機体の位置から進行方向を見ます。ドラッグか矢印で見回し

ボタン：真上／斜め／水平／北を上／全体表示。機体をクリックするとその便を選択します。

5. 表示の設定

  • 地図：衛星写真／ダーク／ライト／OpenStreetMap
  • 地形（標高）を立体表示：日本は国土地理院、海外は AWS Terrain Tiles
  • 全経路を薄く表示、高度の「カーテン」（地面まで垂らした壁）、便名・高度ラベル
  • 機体の大きさ：見やすく（最小 40px）／実寸

6. 録画

「● 録画開始」で地図部分を動画として記録し、「■ 録画停止」で保存します。「時刻・高度を映像に焼き込む」で、日時と選択中の便の情報を映像に書き込みます。保存先は「ダウンロード」フォルダです。

7. 困ったときは

症状 対処
「緯度・経度の列が見つかりません」 列名を latitude longitude（または lat lon）にしてください
高度がおかしい（約 3 倍／1/3） パネルの「高度の単位」をフィート／メートルに切り替えてください
時刻が数時間ずれる タイムゾーンの無い時刻は UTC として扱います。CSV に +09:00 などを付けるか、表示する時間帯を切り替えてください
旋回が角張って見える 点と点の間を直線で結ぶため、記録の間隔が粗いと角張ります

8. データについて

  • 地図：Esri、OpenStreetMap contributors／地形：国土地理院 標高タイル、AWS Terrain Tiles
  • フライトデータは、お手元の CSV を読み込みます。アプリがフライトデータを取得・販売するものではありません。CSV の利用は各データ提供元の規約に従ってください。
  • 再生される位置は記録の精度に依存します。運航や事故調査などの判断には使用できません。
