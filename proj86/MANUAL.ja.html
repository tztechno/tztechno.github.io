Flight Dashboard ユーザーマニュアル（日本語）

世界中の飛行機を、リアルタイムに 3D の地球儀の上で表示するデスクトップアプリです。 空港の上空や地上から離着陸を眺めたり、機体に乗った視点で追いかけたり、過去のフライトデータ（CSV）を再生したりできます。

  • 対応 OS：macOS 11 以降（Apple Silicon）／ Windows 10・11（64 ビット）
  • データ：OpenSky Network（航空機の位置）、Esri / OpenStreetMap（地図）、国土地理院・AWS Terrain Tiles（地形）
  • 表示言語：日本語 / English（パネル右上のボタンで切り替え）

1. インストール

macOS

  1. Flight Dashboard_x.y.z_aarch64.dmg を開き、Flight Dashboard を「アプリケーション」へドラッグします。
  2. 初回は Finder でアプリを 右クリック →「開く」 を選びます（Apple の公証を受けていないため、ダブルクリックでは警告が出ます）。

Windows

  1. Flight Dashboard_x.y.z_x64-setup.exe を実行します。
  2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」 を選びます。
  3. インストーラーの案内に従ってインストールします。

2. 初回起動と OpenSky の認証情報

起動すると「OpenSky の認証情報」画面が開きます。

選択 1 日に使えるクレジット 説明
Client ID / Client Secret を入力して「確認して保存」 4,000 OpenSky のアカウントページで API クライアントを作成して入力します。保存前に OpenSky で認証できるか確認します
「匿名で使う」 400 登録不要。たまに見る程度なら十分です
  • 認証情報は、このパソコンのアプリ設定フォルダ（settings.json）に保存されます。ほかのユーザーからは読めない権限で保存し、外部へ送るのは OpenSky の認証時だけです。
  • あとから変更するには、画面左上の 「匿名アクセス ⚙」／「OpenSky 認証済み ⚙」 を押すか、メニューの「OpenSky の認証情報…」（⌘,）を選びます。

クレジットの目安

1 回の更新で消費するクレジットは、取得する範囲の広さで決まります（狭い範囲 1 ／〜全世界 4）。パネルの「取得範囲」の下に、今の設定での 1 日あたりの消費量の目安が表示されます。上限を超える設定は黄色で警告されます。

例 1 日の上限までに使える時間
空港付近（1 クレジット）を 15 秒間隔・認証あり 約 16.7 時間
全世界（4 クレジット）を 15 秒間隔・認証あり 約 4.2 時間
空港付近を 30 秒間隔・匿名 約 3.3 時間

3. 画面の見かた

  • 左のパネル：表示中の機体数・最終更新・次の更新・残りクレジット、各種設定。☰ で表示／非表示
  • 地図：飛行機のアイコン（機首方向に回転、高度で色分け：緑＝低い → 赤紫＝高い）
  • 機体をクリック：右下に詳細（便名・国籍・種別・高度・速度・方位・昇降率・位置・スコーク）

4. リアルタイム表示の設定

項目 内容
更新間隔 5〜300 秒（匿名は 10 秒以上）。「⏸ 一時停止」「↻ 今すぐ更新」
取得範囲 「表示範囲」（画面に映る範囲だけ取得・節約）／「全世界」
機体位置を速度から補間 更新の合間も速度と方位から滑らかに動かします
地上の機体も表示 地上走行中・駐機中の機体（受信できたもののみ）
地図 ダーク／ライト／OpenStreetMap／衛星写真
地形（標高）を立体表示 山や谷を立体に。日本は国土地理院 10 m メッシュ
便名 / ICAO24 で検索 例：JAL123、ANA、86d4a1

5. 視点

自由視点

  • マウス：左ドラッグ＝移動、ホイール／右ドラッグ＝ズーム、Ctrl＋左ドラッグ／中ドラッグ＝傾き・回転
  • ダブルクリック＝その地点へ寄る、Shift＋ダブルクリック＝その地点の地上視点
  • キーボード：W/S 前後、A/D 左右、R・E 上昇、F・Q 下降、矢印で見回し、Shift で高速
  • ボタン：真上／斜め／水平／北を上／日本／世界

機体に乗る

機体をクリック →「🛫 コックピット」または「🎥 後方追尾」。ドラッグか矢印で見回し、ホイールで距離（後方追尾）、Esc で終了。 「追尾」にチェックすると、地図表示のまま機体を画面中央に捉え続けます。

6. 空港を見る

  1. 「空港を見る」で空港を選ぶと、斜め上空からの視点に移動します（羽田・成田・関西・伊丹・中部・新千歳・福岡・那覇ほか海外 10 空港）。
  2. 空港付近では、機体が 実寸の 3D モデル（大型・中型・小型で大きさが変わる）で表示されます。リアルタイムの機体は色・輪郭・便名ラベルで強調されます。 ※ 衛星写真に写っている駐機機は撮影時のもので、リアルタイムの機体ではありません。
  3. ボタンで視点を切り替えます：上空から（🛩 斜め／🛰 真上）、地上から（🛬 進入路の下／🛫 滑走路脇）。

地上視点の操作

  • ドラッグ＝見回し、ホイール＝望遠（最大約 30 倍）、機体クリック＝目で追う（自動追跡）
  • 高さ：スライダー（1.7 m〜3,000 m、対数目盛）または「地上」「展望デッキ」「300m」「1500m」。R/F キーでも調整
  • WASD＝歩いて移動、ダブルクリック＝その地点へ移動、「↻ 後ろを向く」、Esc＝終了
  • 「🧭 現在地から見る」：現在地の上空を見上げます（位置情報の許可が必要）
  • 「📍 画面中央から見る」：地図の中央の地点に立ちます

7. 軌跡を CSV に保存

機体をクリックした詳細パネルの「軌跡 CSV」から：

  • ⬇ 観測履歴：アプリを開いてから取得した位置（速度・昇降率など含む）。クレジット消費なし
  • ⬇ 離陸からの全経路：OpenSky の記録から離陸以降の経路を取得（1 回 4 クレジット）

保存先は「ダウンロード」フォルダです。

8. フライトデータの再生（CSV）

「📂 CSV を開く」、またはウィンドウへ CSV をドラッグ＆ドロップすると、リアルタイム表示を止めて再生モードになります。

  • 再生／一時停止（Space）、速度 ×1〜×300、スライダーで時刻移動、追尾、全体表示、「再生を終了」
  • 複数ファイルを同時に開くと色分けして重ねて再生します
  • 対応形式：Flightradar24 の CSV、このアプリの軌跡 CSV、時刻・緯度・経度の列がある CSV

CSV の要件（概要）

内容 列名の例 備考
時刻（必須） time timestamp unix_time utc UNIX 秒／ミリ秒、ISO 8601。タイムゾーン無しは UTC
緯度・経度（必須） latitude/lat、longitude/lon、または position（"緯度,経度"） 10 進数の度
高度 altitude_ft alt_m altitude 列名に _m → メートル、それ以外はフィート（パネルで変更可）
便名・機体 ID callsign、icao24 機体 ID ごとに別の便として扱います

9. 録画

「● 録画開始」で地図部分を動画として記録し、「■ 録画停止」で保存します（macOS：MP4／WebM、Windows：WebM）。 「日時と機体数を映像に焼き込む」で、画面右下に日時を表示した状態で記録します。保存先は「ダウンロード」フォルダです。

10. 表示言語

パネル右上の EN／日本語 ボタンで切り替えます。選んだ言語は次回以降も使われます。 設定画面はアプリ画面と同じ言語で開きます。メニューバーは OS の言語に従います。

11. 困ったときは

症状 原因と対処
v1.1.1 以前から更新したら、認証情報の入力画面が出た v1.1.2 から保存先を変えたためです。Client ID / Client Secret をもう一度入力してください（キーチェーンの確認は出なくなりました）
「レート制限中です」と表示される その日のクレジットを使い切りました。間隔を長くするか「表示範囲」にしてください（日付が変わると回復）
空港の地上に機体がいない 受信ボランティアのアンテナから空港の地上が見通せない場合、地上の機体は受信できません（例：伊丹）。空中の機体は表示されます
機体がまばら・急に消える 受信網の範囲外です。海上や山間部では受信できないことがあります
「現在地から見る」が使えない 初回に出る位置情報の許可で「許可」を選んでください。拒否した場合は macOS の「システム設定 → プライバシーとセキュリティ → 位置情報サービス」（Windows は「設定 → プライバシーとセキュリティ → 位置情報」）で許可します
地形に針のようなノイズ 最新版では修正済みです

12. データとプライバシー

  • 航空機の位置：OpenSky Network（ボランティアの受信網による ADS-B データ。非商用・研究目的での利用が前提）
  • 地図：Esri、OpenStreetMap contributors／地形：国土地理院 標高タイル、AWS Terrain Tiles
  • アプリは OpenSky・地図・地形の各サービスにのみ接続します。入力した認証情報は OS の保管場所に保存され、外部へ送信されるのは OpenSky の認証時だけです。
