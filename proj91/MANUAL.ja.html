Fault Propagation — 使用マニュアル（日本語）

English manual

Fault Propagation（地震動 伝播・評価シミュレーター） は、断層パラメータの CSV から、世界のどこでも地震の揺れの広がりと、指定した陸上の地点の揺れ（震度・最大加速度・最大速度・波形・応答スペクトル）を評価するデスクトップアプリです。

画面右上の JP / EN ボタンで日本語と英語を切り替えられます。

1. 画面の構成

場所 内容
ヘッダー 経過時間、陸域の最大震度、状態、JP / EN 切替
左パネル 1. 震源断層 / 2. 計算範囲と地盤 / 3. 揺れの伝播 / 4. 陸上の評価地点 / 5. 表示レイヤー
地図 地形、震度などの分布、断層 (すべり量で色分け)、破壊開始点 (★)、P/S 波の波面、評価地点
下部グラフ 選んだ地点の加速度・速度波形、応答スペクトル、地点比較

地図はホイールでズーム、ドラッグで移動します。「🔍 計算範囲」で計算範囲全体、「🌐 世界」で世界全体を表示します。地図にマウスを乗せると、その場所の標高・Vs30・断層最短距離・震度・PGV/PGA・P/S 波の到達時刻が表示されます。

2. 断層を与える

同梱の断層モデル

「同梱の断層モデル」から選ぶと、地形の取得 → 地盤の推定 → 震度分布の計算 → 周辺の都市の評価 → 最も揺れの強い地点の波形合成 まで自動で行います（数秒〜十数秒）。

2016年 熊本地震 本震 (USGS) 日本・内陸
2011年 東北地方太平洋沖地震 (USGS) 日本・海溝型
2023年 トルコ・シリア地震 (USGS) 世界・内陸
2019年 米国リッジクレスト地震 (USGS) 世界・内陸
2025年 カムチャツカ半島沖地震 / 2010年 チリ・マウレ / 2015年 チリ・イジャペル / 2004年 スマトラ島沖 (USGS) 世界・海溝型

断層 CSV を読み込む

「📄 断層CSV読込」を押すか、ファイルを地図にドロップします。1 行が 1 枚の矩形断層です。

# hypocenter_lon=136.75, hypocenter_lat=37.23, hypocenter_depth_km=12
# rupture_velocity_km_s=2.5
name,lon,lat,top_depth_km,length_km,width_km,strike_deg,dip_deg,rake_deg,slip_m
F1,136.62,37.20,0.5,30,15,40,50,110,3.2
列 意味
lon, lat 断層面の地表投影の中心 (度)
top_depth_km 断層上端の深さ (km)。代わりに center_depth_km (中心深さ) も可
length_km, width_km 長さ・幅 (km)
strike_deg, dip_deg, rake_deg 走向・傾斜・すべり角 (度)
slip_m すべり量 (m)。代わりに slip_cm も可
  • # で始まる行はコメントです。hypocenter_lon / lat / depth_km で破壊開始点、rupture_velocity_km_s で破壊伝播速度を指定できます（省略時は、すべり分布の重心付近を破壊開始点とし、2.5 km/s とします）。
  • コメントに Mw 9.05 のように書かれていれば、その Mw を使います（なければ剛性率 40 GPa で計算）。
  • 「⬇ 断層CSV書出」で現在の断層を同じ書式で保存できます（書式見本として使えます）。

簡易断層を置く

「📐 簡易断層を置く」で Mw・走向・傾斜・すべり角・上端深さを入れ、「地図をクリックして断層を置く」を押して地図をクリックします。長さ・幅は Wells & Coppersmith (1994) のスケーリング則、すべり量は Mw から決まります。

震源の詳細設定

「⚙ 震源の詳細設定」で Mw、地震のタイプ（地殻内 / プレート間 / プレート内、既定は自動判定）、破壊開始点、破壊伝播速度を変えられます。「🎯 破壊開始点を地図で指定」で地図から選ぶこともできます。変更後は「この設定で再計算」を押します。

3. 計算範囲と地盤

項目 内容
計算範囲の広さ 断層の周囲どこまで計算するか（自動は Mw に応じて ±1°〜±5°）
格子の細かさ 軽量 / 標準 / 高精細
地盤の推定 変動帯（日本・環太平洋など）/ 安定大陸。地形勾配から Vs30 を推定する式の区分

地形は AWS Terrain Tiles から必要な範囲だけ取得します（インターネット接続が必要）。一度取得したタイルは保存され、次回は再取得しません。

4. 揺れの伝播

  • ▶ 再生 で、地震発生からの揺れの広がりをアニメーション表示します。破壊フロント（白の点線）、P 波（青の破線）、S 波（赤）の波面と、その時刻の震度の広がりが表示されます。再生が終わると最大震度の分布に戻ります。
  • ↺ 0秒へ / ⏭ 最終 と時刻スライダーで、好きな時刻を表示できます。スペースキーでも再生・一時停止できます。
  • 表示する量: 揺れの伝播 / 最大震度（震度階級）/ 最大 MMI / PGV / PGA / 地盤 Vs30。
  • 「最大値は揺れが届いた範囲だけ表示」をオンにすると、最大値の表示が S 波の到達とともに広がります。

5. 陸上の評価地点

  • 断層を読み込むと、計算範囲にある主な都市が自動で追加されます（「🏙 周辺の都市」でさらに追加）。
  • 「＋ 地図で追加」を押して地図をクリックするか、名前・緯度・経度を入れて「追加」します。海域の点を選ぶと警告が出ます。
  • 地点を選ぶと、その地点の 3 成分波形を合成して詳細を表示します。
表示 内容
計測震度・震度階級 距離減衰式の値と、合成波形から気象庁の方法で求めた値
PGV / PGA / MMI 最大速度・最大加速度（水平 2 成分の大きい方）・改正メルカリ震度
断層最短距離 / 震源距離 破壊域（すべり量が最大の 10% 以上）までの最短距離と、破壊開始点からの距離
P 波・S 波の到達、S−P 地震発生からの秒数
震度 4 相当以上 合成波形で震度 4 相当以上の強さが続いた時間
地盤 Vs30 地形から推定した値。手入力で上書きでき、「推定値に戻す」で戻せます

「合成波形を距離減衰式に合わせて補正（推奨）」がオンのときは、合成波形の水平最大速度と PGA/PGV 比を距離減衰式の値に合わせます。

8. 計算方法

項目 方法
面的な揺れ 司・翠川 (1999) の距離減衰式で工学的基盤 (Vs=600 m/s) の最大速度、藤本・翠川 (2006) の地盤増幅、藤本・翠川 (2005) で計測震度、Worden et al. (2012) で MMI。PGA は司・翠川 (1999)
地盤 地形勾配から Vs30 を推定 (Wald & Allen 2007)
到達時刻 要素ごとの破壊時刻 + 走時（P 6.0 / S 3.5 km/s、150 km 以遠は 8.0 / 4.6 km/s）
波形 確率論的有限断層法（ω² 震源・幾何減衰・Q(f)=180 f^0.45・κ=0.035）
計測震度 気象庁の方法（3 成分にフィルター → ベクトル和が 0.3 秒以上続く値）

9. 注意

  • 距離減衰式は平均的な揺れを表します。実際の揺れは常用対数で ±0.2〜0.3 程度（概ね 0.6〜1.7 倍）ばらつきます。
  • Mw 8.3 を超える地震は、距離減衰式では Mw 8.3 として評価します。
  • 地形から推定する Vs30 は目安です。埋立地・谷底の軟弱地盤や堆積盆地による増幅は表現できません。
  • 合成波形は統計的に作ったもので、破壊の向きによる効果（ディレクティビティ）や長周期の表面波は含みません。
  • 本アプリは学習・検討用です。防災上の判断には公的機関の評価を参照してください。

10. 困ったとき

  • 計算が始まらない・地形を取得できない: インターネット接続を確認してください。地形は AWS Terrain Tiles から取得します。
  • CSV を読み込めない: 見出し行の列名を確認してください（top_depth_km か center_depth_km、slip_m か slip_cm が必要です）。エラーの行番号と内容が表示されます。
  • 計算が重い: 「格子の細かさ」を軽量にするか、「計算範囲の広さ」を狭くしてください。
