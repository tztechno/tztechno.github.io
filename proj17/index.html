SYSTEM FEATURES // 主な特徴

🔒

完全ローカル実行（漏洩ゼロ）

Hugging Faceからモデルを初回ダウンロードした後は、すべての文章生成（解釈）処理があなたのブラウザ内で行われます。外部のAPIサーバーにデータを送信しないため、機密情報や極めてプライベートな悩みでも安全に入力可能です。

🧠

プロンプトの自己設計 (Step 0)

入力された相談内容（EVENT）をAI自身がメタ分析し、その相談がどのような分野のものかを判定。それに最適化された「課題特定用プロンプト」と「対策生成用プロンプト」をその場で自動生成し、後続のステップで実行します。

📊

課題の構造化 ＆ チャット対話

AIが抽出した複数の課題とそれぞれの対策案を、直感的なテーブル（表）形式で美しく整理。さらに、生成されたコンテキストを引き継いだままAIチャットでアイデアをさらに深掘り・壁打ちすることができます。

TECHNOLOGY STACK // 技術構成

      
Webブラウザ上で安全かつ高度なAI推論を実現する技術群

      
      

        
        

          
Wasm

          
WebAssembly 推論制御

          

            wllama.js を活用し、本来デスクトップアプリやクラウド上でしか動作しない llama.cpp の推論エンジンをWebAssemblyにコンパイル。ブラウザ上で極めて高速なニューラル推論を実行します。
          

        


        
        

          
Qwen

          
Qwen2.5 ニューラルモデル

          

            Alibaba Groupが開発し、高い日本語性能と合理性を誇るオープンモデル Qwen2.5-Instruct のGGUF量子化モデル（4bit）を使用。高い精度を保ちながらスマートな容量でダウンロード可能です。
          

        


        
        

          
Worker

          
Web Workers 非同期並列

          

            重いAIモデルの読み込みや文章の推論計算をUIスレッドとは別のバックグラウンドスレッド（Web Worker）で実行。AIの動作中もブラウザの描画やユーザーのキー入力が一切重くなりません。

FAQ // よくある質問

      
      

        
        

          
          

            

              本システムは最新のWeb標準技術「WebAssembly」を採用しています。クラウドにデータを送信して推論する従来のAI（ChatGPTなど）とは異なり、AIモデル自体をブラウザにダウンロードし、あなたのPCのCPUやGPUだけで動かすため、データを完全にローカルに留めることができます。
            

          

        


        
        

          
          

            

              「本物AIモード」の実行時には、初回のみ約2.0GBのAIモデルデータをダウンロードする必要があるためです。ダウンロードしたモデルはブラウザのストレージ（IndexedDB/Cache Storage）にキャッシュされるため、2回目以降はダウンロードなしで即時起動します。
            

          

        


        
        

          
          

            

              「疑似体験モード」はスマートフォンでも快適に動作します。「本物AIモード」は、メモリ容量が少ない一部のスマートフォンやタブレットではブラウザがクラッシュする恐れがあります。快適にご利用いただくためには、メモリ（RAM）が8GB以上搭載されたPCのブラウザ（Chrome / Edge / Safari）での実行を推奨します。
            

          

        


        
        

          
          

            

              決済完了後、購入確認画面からアプリへ自動的に戻ります。その際、決済トークンが自動的にブラウザ（ローカルストレージ）に記録され、制限なしでフル機能をご利用いただけるようになります。
