# Shizuoka Fault（静岡 活断層・南海トラフ地震シミュレーター）— 使用マニュアル

静岡市とその周囲の活断層、および南海トラフのプレート境界を、国土地理院の地形・建物・航空写真の 3D 表示に重ね、
断層が動いて地震が起きたときの

- 揺れの強さ（計測震度・最大地動速度 PGV・最大加速度 PGA）
- 地表に現れる断層のずれ（横ずれ・縦ずれ段差）と、南海トラフの動きによる地殻の上下変動
- 建物 1 棟ごとの被害（断層変位による損壊・全壊・半壊・一部損壊）
- 揺れによる斜面崩壊と、崩れた土砂の流下（土石流）

を計算して表示するデスクトップアプリです。八代版（Yatsushiro Fault）と同じ計算エンジンを、静岡市周辺のデータに置き換えて作っています。

> **津波は扱いません** — 南海トラフ地震では断層（プレート境界）の動きによる揺れと地殻変動だけを計算します。津波の高さ・到達・浸水は計算しません。沿岸の避難の判断には使えません。

> **注意** — 結果は、公開データと簡略化した計算式による **想定の一例** です。実際の被害や、国・静岡県・静岡市の公式の被害想定とは一致しません。
> 防災上の判断には、静岡市のハザードマップや公式の情報を使ってください。

## 1. 起動方法

| 版 | 起動のしかた |
|---|---|
| デスクトップ版（macOS） | `ShizuokaFault_<版>_aarch64.dmg`（または `ShizuokaFault.dmg`）を開き、`ShizuokaFault.app` を「アプリケーション」へドラッグして起動（初回は右クリック →「開く」） |

- Apple Silicon 搭載の Mac（GPU / WebGL2 対応）が必要です。GPU を使って計算します。
- 既定の 7 地区、広域の地形、活断層・南海トラフの小断層モデル、土砂災害警戒区域、地名、町丁界のデータはアプリに同梱されているので、インターネットがなくても表示・計算できます。住所から新しいタイルを作るときだけ接続が必要です。

## 2. 画面の構成

### 表紙
最初に表紙が表示されます。読み込みが終わったら **開始**（または Enter）を押します。右側の一覧から地区を選んで始めることもできます。
左上の **表紙** ボタンで、いつでも表紙に戻れます。

### 画面の各部

| 場所 | 内容 |
|---|---|
| 左の操作パネル | 1. 地域 / 2. 活断層図・地震シナリオ / 3. 表示切り替え / 4. 計算 / 5. 詳細設定 / 6. ハザードマップ / 7. 録画 |
| 中央 | 3D 表示（地形・建物・活断層図・揺れの色分け・土砂） |
| 左上の **☰ メニュー** | 左の操作パネル全体を開く・閉じる |
| 左上の情報欄（HUD「状況」） | 地区名、経過時間、地震の規模と最大震度、建物被害の推計、崩壊面積 |
| 右上 | 凡例（表示している内容に合わせて切り替わります） |
| 左下 | 広域マップ（静岡市・駿河湾周辺 86 × 83 km の陰影図と、断層別に色分けしたトレース。クリックで場所を選択） |
| 下部 | 再生バー（計算結果のコマ送り）と、地点の時間変化のグラフ |

### 折り畳み
画面のどの部分も折り畳めます。開閉の状態はアプリに記憶されます。

| 折り畳むもの | 操作 |
|---|---|
| 左の操作パネル全体 | 3D 画面左上の **☰ メニュー** で開閉（パネル右上の **✕** でも閉じる） |
| 操作パネルの各セクション（1.〜7.） | 見出し（▾ / ▸ の付いた行）を押す |

### 日本語 / English
左上の **English** / **日本語** ボタンで、画面・凡例・地点情報の言語を切り替えます。

## 3. 地域（タイル）を選ぶ・作る

### 既定の地区から選ぶ
「1. 地域」のリストから選びます。どれも 2 km 四方・2 m 格子（100 万セル）です。

| 地区 | 特徴 |
|---|---|
| 静岡駅・駿府城公園 | 静岡平野の中心市街地。南海トラフ地震の揺れと建物被害を見る |
| 登呂・中田 | 安倍川下流の低地。平らな低地での揺れの増幅を比べる |
| 大谷・高松 | 有度丘陵の南西麓。1935 年静岡地震で最も被害が大きかった地区 |
| 清水駅・清水港 | 駿河トラフに近い港湾の市街地。地殻変動の比較に |
| 由比・薩埵峠 | 由比地すべりと東海道の急斜面。地震時の斜面崩壊 |
| 蒲原東部・富士川西岸 | 富士川河口断層帯の南端。活断層図のトレースがタイルを通る。断層のずれと揺れ（一部は富士市） |
| 梅ケ島・大谷崩 | 1707 年宝永地震で崩れたとされる大谷崩。山地の地震時崩壊 |

情報欄には、タイル内でいちばん近い活断層までの距離と、断層から 20 m・100 m・300 m 以内の面積が表示されます。

### 住所・地名から新しいタイルを作る
1. 「住所・地名から新しいタイルを作る」を開き、住所や地名を入れて **検索**（例: 静岡市葵区追手町、由比、蒲原、梅ケ島）
2. 候補から選び、タイルの大きさ（1 / 2 / 3 km 四方）を選ぶ
3. **このタイルを作成して表示** を押す（インターネット接続が必要。地形・建物・航空写真を取得して数十秒〜数分）

左下の広域マップをクリックして場所を選ぶこともできます。作ったタイルはリストに **★** 付きで残ります。

## 4. 活断層図を見る

「2. 活断層図・地震シミュレーション」の上部で設定します。

| 設定 | 内容 |
|---|---|
| 活断層トレースの不透明度 | 活断層の線を地表に重ねる濃さ。0 で非表示 |
| 断層直上変位帯(20m)・近傍警戒帯(100m)を表示 | 断層から 20 m 以内を赤、100 m 以内を橙で塗る |
| 3D地表断層段差の強調倍率 | 地震で生じる縦ずれ段差を 3D 地形で何倍に強調して見せるか |

| 記号 | 意味 |
|---|---|
| 赤い線（実線・破線とひげ記号） | 国土地理院「活断層図（都市圏活断層図）」の活断層。実線は位置が明確、破線はやや不明確 |
| 紫の帯 | 概略トレース。活断層図がない海域・伏在断層などに、地震本部の評価や論文を目安に手で置いた線。**位置の誤差は ±1 km 以上**あり、帯の幅は誤差の大きさではない |

国土地理院の活断層図は北緯 35.07 度付近までで、**静岡平野・有度丘陵には調査済みのトレースがありません**。静岡市の中心部では、断層の近さよりもプレート境界までの距離と地盤が揺れを左右します。

| 断層 | トレースの元 | 広域マップの色 |
|---|---|---|
| 富士川河口断層帯 | 活断層図 | 赤 |
| 身延断層 | 活断層図（一部 概略） | 橙 |
| 北伊豆断層帯 | 概略（一部 活断層図） | 紫 |
| 駿河トラフ | 概略 | 青 |
| 1935 年静岡地震の震源断層（伏在） | 概略（武尾ほか 1979 のモデルが目安） | 緑 |

## 5. 地震シナリオを選ぶ

「地震シナリオ」から選ぶと、規模などの値がまとめて設定されます。
起動時は「断層活動なし」です。地震も雨もない平常時の状態なので、建物は色分けされません。地震を見るときは、下の表のシナリオを選んでください。

| シナリオ | 動く断層 | 規模 | 内容 |
|---|---|---|---|
| 断層活動なし（既定） | なし | — | 地震も雨もない平常時。起動時の状態 |
| 南海トラフ巨大地震 最大クラス | 駿河湾〜日向灘のプレート境界 | Mw9.1 | 内閣府（2012）の設定ルールから再構成。大すべり域は駿河湾〜紀伊半島沖 |
| 1854 年 安政東海地震型 | 駿河トラフ〜東南海 | M8.4 | 駿河湾奥まで破壊。駿河湾西岸の隆起との比較に |
| 1707 年 宝永地震型 | 遠州灘〜土佐沖（駿河湾を除く場合） | M8.6（Mw8.7 として計算） | 離れた震源域からの長い揺れ。大谷崩との比較に |
| 富士川河口断層帯＋駿河トラフ 連動 | 富士川河口断層帯・駿河トラフ | M8.0 程度 | 長期評価のケース a（西側が 1〜2 m 隆起）。ケース b（約 10 m）は縦ずれを変えて試す |
| 富士川河口断層帯 陸上部の単独活動 | 富士川河口断層帯 | M7.2 程度 / Mw6.8 | 長期評価の単独活動の場合（数 m 隆起） |
| 1935 年 静岡地震型 | 有度丘陵付近の伏在断層 | M6.4 / Mw6.2 | 市の直下の地震。地表にずれは出ない。発生機構には諸説あり |
| 身延断層の地震 | 身延断層 | M7.0 程度 / Mw6.7 | 葵区北部の山地との比較に |
| 北伊豆断層帯の地震 | 北伊豆断層帯 | M7.3 程度 / Mw6.9 | 1930 年北伊豆地震型。約 50 km 離れた内陸地震の比較に |
| 複合災害：豪雨の後の南海トラフ地震 | 駿河湾〜日向灘 | Mw9.1 | 1 時間 75 mm の雨が止んだ直後に地震が起きる最悪のケース |
| 比較用：豪雨単独 | なし | — | 1974 年七夕豪雨の雨だけ。地震による被害との比較用 |

活断層の規模は地震調査研究推進本部の長期評価の値を目安にしています。
M は気象庁マグニチュード、Mw はモーメントマグニチュードです。計算には Mw を使います。内陸の大地震では Mw が M より 0.3〜0.5 ほど小さいのが普通です。

### 南海トラフのシナリオで表示されるもの
プレート境界のシナリオを選ぶと、シナリオの下に **震源域の図**（小断層をすべり量で色分け、青丸が静岡市）が出ます。結果の要約と地点の情報には、**プレート境界までの距離** と **地殻の上下変動**（+ が隆起、− が沈降）が加わります。

地殻の上下変動は 2 km 四方のタイルではほぼ一様なので、3D 地形には段差として描きません。数値で表示します。

### 値を変える

| 項目 | 意味 |
|---|---|
| 地震規模 Mw | 大きいほど広い範囲が強く揺れる。南海トラフでは、すべり量（地殻変動）も Mw に合わせて増減する |
| 断層上端の深さ (km) | 0 で断層が地表まで破れる。深くするほど地表のずれは小さくなり、1 km 以上では地表破断なし（南海トラフのシナリオでは揺れの計算に使わない） |
| 横ずれ変位量 (m) | 断層に沿った水平のずれ |
| 縦ずれ段差・撓曲変位量 (m) | 断層をはさんだ上下のずれ（3D 地形に段差として表示）。負の値にすると隆起側が沈降する |
| 断層近傍パルス増幅率 | 断層の近く（約 1 km 以内）で揺れを強める倍率（破壊の進む向きに強い揺れが集まる効果） |
| 強震継続時間 (秒) | 強い揺れが続く時間。斜面崩壊の計算と地震波のアニメーションに使う |

値を変えると、揺れ・建物被害・広域の震度がすぐに計算し直されます。
**⚡ 断層破断・地震波3Dアニメーション再生** を押すと、断層から地震波が広がって地面が揺れる様子が再生されます。

### 断層CSVを読み込む・書き出す
用意されたシナリオのほかに、矩形の断層モデルを CSV で読み込んで地震を計算できます。南海トラフアプリ・八代版（Yatsushiro Fault）と同じ形式で、国土地理院が地震後に公表する震源断層モデルなどをそのまま使えます。

1. **📄 断層CSV読込** を押してファイルを選ぶ
2. 読み込めると、シナリオのリストに **📄 CSV: ファイル名 (Mw…)** が加わって選ばれ、すぐに揺れ・建物被害が計算されます
3. 誤りがある場合は、行番号と理由が赤字で表示され、読み込みません

CSV は 1 行に断層 1 枚で、次の列を持ちます（列の順番は自由。見出しは日本語の「経度」「走向」なども可）。

| 列 | 意味 |
|---|---|
| name | 断層の名前（省略可） |
| lon, lat | 断層面を地表に投影した長方形の **中心** の経度・緯度 |
| top_depth_km | 断層面の上端の深さ (km)。代わりに center_depth_km（面の中心の深さ）も可 |
| length_km, width_km | 断層の長さ（走向方向）と幅（傾斜方向） (km) |
| strike_deg, dip_deg, rake_deg | 走向・傾斜角・すべり角（度） |
| slip_m | すべり量 (m)。slip_cm（cm）も可 |

```
# hypocenter_lon=138.45, hypocenter_lat=34.98, hypocenter_depth_km=8
name,lon,lat,top_depth_km,length_km,width_km,strike_deg,dip_deg,rake_deg,slip_m
A,138.45,34.98,3,11,8,75,80,170,0.9
```

- `#` で始まる行は注記です。`hypocenter_lon=…` の形で震源を書くと説明に表示されます。
- Mw は全断層のすべり量と面積から求めます（剛性率 40 GPa）。
- 断層の中心が静岡市から 800 km 以内、最大 5000 行まで読み込めます。
- 読み込んだ CSV は、アプリを閉じるまで、タイルを切り替えても選ばれたまま残ります。

**揺れの計算**: 各地点から断層面までの最短距離を使います。深さ 10 km 以深を中心とする低角（35° 以下）の逆断層のモデルは、プレート境界型として計算します（司・翠川の式のプレート間地震の項）。
**地表のずれ**: 最も浅い断層の上端を地表まで延ばした線に沿って計算します。広域マップには断層面の地表投影（紫の四角）と、地表トレース（紫の破線）を描きます。

**⬇ 断層CSV書出** を押すと、選んでいるシナリオの断層モデルを同じ形式で保存します（書式の見本としても使えます）。

| 選んでいるシナリオ | 書き出される内容 |
|---|---|
| CSV で読み込んだモデル | そのモデル（すべり量は入力欄の Mw に合わせて増減） |
| 南海トラフ・安政・宝永・駿河トラフのシナリオ | アプリが組み立てたプレート境界の小断層（すべり角 90°） |
| 活断層のシナリオ | 活断層のトレースを直線で近似した矩形断層（傾斜 80°、幅 15 km） |

### 結果の要約
シナリオの下に次の結果が表示されます。

- 最大計測震度（震度階級）、最大 PGV / PGA
- 地表の断層変位の最大値、震度 7 の面積
- 地震時に不安定になる斜面の面積（括弧内は、揺れがなくても不安定な面積）と、断層変位帯の面積
- 建物被害推計（断層変位・全壊・半壊・一部損壊・無被害の棟数と割合のバー）

## 6. 揺れと建物被害を見る

「3. 3D表示切り替え」で、地表と建物の色分けを選びます。

### 地表の表示

| 表示 | 内容 |
|---|---|
| 航空写真（＋活断層図） | 国土地理院の航空写真に活断層図を重ねる（起動時の表示） |
| 想定震度分布 | 震度 4 以下〜震度 7 を気象庁の階級で色分け。同じ階級の中でも揺れが強いほど濃く、計測震度 0.1 ごとに等震度線（0.5 ごとの階級の境は太線）を引く |
| 最大地動速度 PGV | 地面が揺れる速さの最大値 (cm/s) |
| 活断層距離・地表変位危険帯 | 断層からの距離で色分け |
| 斜面の安全率 FS | 1 未満が崩れる状態。地震中は揺れの力を含めた値 |
| 土壌の飽和度 / 傾斜 / 標高段彩 | 土の湿り具合、斜面の角度、標高 |

広域（周辺・遠景）の地形も、震度・PGV・断層距離の表示に合わせて色分けされます。

### 建物の色分け

| 表示 | 内容 |
|---|---|
| 地震・断層変位・土砂 総合被害判定 | 紫=断層変位による損壊、赤=全壊、橙=半壊、黄=一部損壊、白=無被害・軽微 |
| 建物の揺れ（震度階級） | 建物の位置の震度 |
| 土砂の埋没深 / 衝撃圧 | 斜面崩壊の計算後、土砂に埋まった深さ・土砂が当たった力 |
| 白 | 色分けなし |

そのほか、土砂の見え方、航空写真の影の補正、3D 建物・ラベル・周辺地形の表示、計算後の最大堆積深の表示を切り替えられます。

## 7. 地震による斜面崩壊・土石流を計算する

1. 地区とシナリオを選ぶ
2. 「4. 地震時斜面崩壊・土石流の計算」の **▶ 地震・土砂崩壊の計算開始** を押す
3. 地震波が断層から広がり、揺れの強い急斜面から崩れて、土砂が谷や住宅地へ流れ下ります
4. 土砂が止まると計算が終わり、結果がまとめて表示されます

雨のない地震だけのシナリオは、計算時間 3 分（揺れ＋土砂が止まるまで）で、2 km 四方なら Mac の GPU によって 20〜60 秒ほどで終わります。
豪雨を含むシナリオは雨の時間ぶん計算するため長くなります。

| ボタン・設定 | 内容 |
|---|---|
| ⏸ 一時停止 / ↺ リセット | 計算を止める / 最初の状態に戻す |
| 計算速度 | 1 画面更新あたりの計算ステップ数。大きいほど速いが画面がかくつく |
| 安全係数 (CFL) | 時間刻みの安全率。通常は 0.5 のまま |

計算が終わると、下の再生バーで時間を戻したりコマ送りしたりできます。

### 結果の内容
地震被害の要約に加え、斜面崩壊の箇所数と面積、最初の崩壊時刻、崩れた土砂の量、土砂が届いた範囲、堆積の深さ・最大流速、
土砂が届いた建物・埋まった建物・強い衝撃を受けた建物の棟数が表示されます。

### 詳細設定（5. 土質・降雨・崩壊条件）
通常は変える必要はありません。

- **降雨条件と地震との前後関係**: 雨の量・時間と、雨がいつ始まるか（下の「雨と地震のタイミング」を参照）
- **土質**: 土層の厚さ、粘着力、内部摩擦角、透水係数、初期飽和度など。初期飽和度は雨が降る前の土の湿り具合で、計算開始までに 12 時間排水されるため、地震の時点の湿り具合とは同じになりません
- **土石流**: 崩れた土砂の流れやすさ（摩擦係数など）
- **崩壊源の追加指定**: 斜面をクリックして、決まった時刻に強制的に崩す場所を追加できる

### 雨と地震のタイミング
「雨の開始・地震に対して」に時間を入れると、雨と地震の順番と間隔を変えられます。どの地震シナリオでも雨を設定できます。

| 入力 | 動き |
|---|---|
| 0 | 雨と地震が同時に始まる |
| マイナス（例: −3） | 地震の 3 時間前に雨が降り始める。雨の途中や、雨が止んだ後に地震が起きる状態を作れる |
| プラス（例: +6） | 地震の 6 時間後に雨が降り始める |

1. 先に地震シナリオを選ぶ（選び直すと、雨・雨の開始・初期飽和度はそのシナリオの値に戻る）
2. 雨の種類と強さ、雨の開始を設定する。入力欄の下に、地震までの雨量などの要約が表示される
3. 計算を始める

計算は雨と地震の早いほうから始まります。下のグラフの紫の線が地震の時刻で、地震より前の時間帯は建物に被害の色が付きません。

地震より前の雨は、揺れの瞬間の土の水分に反映されます。一方、地震より後の雨には、揺れで斜面が緩む効果が入っていないため、危険性は低めに出ます。

## 8. 地点をクリックして調べる

3D 画面をクリックすると、その地点の情報が表示されます。

- 断層までの距離と、どちら側か（隆起側・山地側 / 沈降側・盆地側）、その場所の地図記号
  - 地震シナリオを選んでいるときは **動く断層までの最短距離**（そのシナリオで動く断層まで。揺れ・建物被害・揺れの到達時刻もこの距離から計算）
  - 地震がないときは **活断層までの最短距離**（地図上のいちばん近い活断層まで）
- 震度（計測震度）、PGV、PGA、地表の断層変位量と上下のずれ
- **揺れの到達時刻**（地震発生から何秒後か）、強い揺れの続く時間、斜面にかかる水平震度 kh の最大値。CSV で読み込んだ断層では、断層面までの最短距離も
- **この地点の揺れの波形**（加速度 gal・速度 cm/s）。再生中は時刻の線が動きます
- 土層の厚さと安全率（ふだん・地震時の最小・雨で飽和したとき）
- 建物をクリックした場合は、建物の種類・階数・被害判定・断層からの距離と、**揺れによる被害の確率**（全壊・半壊以上・一部損壊以上）
- 計算後は、土砂の深さ・速さの時間変化を下のグラフに表示

> 揺れの波形は **模式波形** です。このアプリは揺れの最大値（PGA・PGV）を計算しており、波形そのものは計算していません。最大値が計算値と一致するように、揺れの継続時間の中で作った波形です。断層の近く（約 3 km 以内）では速度のパルスを加えています。

### 地点の揺れのデータを保存する
計算後、地点情報の下の **📄 この地点の結果をCSVで保存（条件つき）** を押すと、その地点のデータを CSV で保存します。

| 部分 | 内容 |
|---|---|
| 地点 | 位置・地盤高・傾斜、断層までの距離、計測震度・PGV・PGA、断層変位と上下のずれ、揺れの到達時刻・継続時間・kh の最大値、地震時の最小安全率。建物なら被害判定と被害の確率 |
| 計算条件 | 降雨・地震シナリオ（Mw・断層上端の深さ・ずれの量・パルス増幅率・継続時間）・土質など |
| 結果 | 崩壊の時刻・深さ、土砂の最大深さ・速さ・衝撃圧 |
| 時間変化（コマごと） | 降雨強度、累積雨量、土の飽和度、水平震度 kh、安全率（前のコマからの最小）、土砂の深さ |
| 揺れの模式波形（0.01 秒ごと） | 地震発生からの秒、加速度 (gal)、速度 (cm/s)、水平震度 kh |

## 12. 計算の考え方

### 活断層までの距離
陸の断層は国土地理院の活断層図のタイル画像から赤い断層線の位置を取り出し、海域・伏在断層などは概略トレースを使います。各セル（2 m）から、シナリオで動く断層までの距離を求めます（地点情報の「動く断層までの最短距離」。揺れ・建物被害・揺れの到達時刻はすべてこの距離を使います）。断層の向きから、断層のどちら側か（ここで扱う断層は西側を隆起側とし、1935 年の断層のみ北側）も区別しています。

### 南海トラフ（プレート境界）
内閣府（2012）の設定ルール（主部断層の平均すべり 10 m、大すべり域 20 m、超大すべり域 40 m、面積 約 14 万 km²）から、トラフ軸に沿った 165 枚の矩形の小断層を組み立てています。公式の小断層データは使っていません。駿河湾内はプレートが急に深くなるため、静岡市の下で USGS Slab1.0 の深さ（約 15〜18 km）に近づくよう帯の幅を狭めています。歴史地震のシナリオは、この一部の小断層を、それぞれの Mw になるようすべり量を調整して使う簡略モデルです。

- **揺れ**: 深さ 10 km 以深のプレート境界までの最短距離から、司・翠川（1999）のプレート間地震の式で基盤の PGV を求める。連動シナリオでは活断層の式と比べて大きいほうを使う
- **地殻の上下変動**: Okada（1985）の式を全小断層で足し合わせる
- **津波**: 計算しない

### 揺れ
- **基盤の揺れ**: 断層からの距離と Mw から、司・翠川 (1999) の距離減衰式で工学的基盤（Vs = 600 m/s）の PGV を求める
- **地盤による増幅**: 平らな低地（軟らかい堆積層）ほど揺れが大きく（約 2 倍）、山の急斜面（固い岩盤）ほど小さくする。地形の傾きは周囲約 50 m の平均を使う（道路の法面や擁壁などの細かな段差では変えない）
- **断層近傍の効果**: 断層から約 1 km 以内の揺れの集中（パルス）、断層の上盤側の増幅、盆地の縁（断層から数百 m の盆地側）での増幅（「震災の帯」）
- **震度**: PGV から計測震度に換算（翠川ほか 1999: I = 2.68 + 1.72 log PGV）
- **PGA**: PGV の 8.5〜11 倍（急斜面ほど大きい）

### 地表の断層変位
断層上端の深さが浅いほど地表に大きなずれが現れ、断層線から離れるほど小さくなります（幅 20 m 程度）。縦ずれは断層をはさんで上下に分かれ、3D 地形に段差として表示されます。

### 建物被害
- 建物の位置の PGV から、被害率曲線（対数正規分布）で全壊・半壊以上・一部損壊以上の確率を求める
  - 木造など一般の建物（普通建物）: 全壊の中央値 165 cm/s、半壊以上 105 cm/s、一部損壊以上 55 cm/s
  - 堅ろう建物・高層建物・4 階以上: 全壊 300 cm/s、半壊以上 200 cm/s、一部損壊以上 100 cm/s
- 確率に従って 1 棟ずつ被害区分を決める（何度計算しても同じ結果になる乱数を使用）
- 断層線から 15 m 以内で変位が 0.3 m 以上の建物は「断層変位による損壊」とする（位置があいまいな概略トレースでは判定しない）

### 斜面崩壊・土石流
- 土の中の水と斜面の安全率は、土砂災害シミュレーターと同じ計算（無限長斜面の安全率）
- 地震中は、揺れの水平の力（水平震度 kh = 0.15 × PGA / 重力加速度、最大 0.3）を加えて安全率を計算する
  - 揺れの瞬間の最大値は一瞬しか働かないため、斜面が 5〜10 cm 以上すべる目安（Jibson 2007）に相当する値を使う
  - 揺れの最中は土の強度に余裕があるとして、安全率を 1.3 倍して判定する
- 地震波は断層から約 1.8 km/s で広がり、届いた所から順に揺れ始める（到達時刻 = 動く断層までの最短距離 ÷ 1.8 km/s）
- 断層直上（約 30 m 以内）では、地表の破断で土の強さが下がる
- 崩れた土砂は土石流として流れ下り（Voellmy 摩擦）、緩い所で止まって堆積する

## 13. 注意・制約

- **想定の一例であること**: 揺れの式・被害率曲線・斜面の判定は簡略化したものです。地盤の詳しい調査結果（ボーリングなど）や、建物の建築年・構造は反映していません。
- **建物の情報**: 建物は国土地理院の建物外形で、構造は「普通建物 / 堅ろう建物 / 高層建物」の区分だけです。建築年（耐震基準）は区別していません。
- **活断層の位置**: 活断層図は表示用の画像なので、線の太さや記号の大きさの分だけ位置に幅があります。概略トレースは手で置いた線で、測量データではありません。断層変位による損壊の棟数は多めに出る傾向があります。
- **南海トラフ**: 距離減衰式の適用範囲（Mw8.3 程度まで）を超えて Mw9.1 に使っています。地盤の増幅も地形からの推定で、長周期の揺れや液状化は反映していません。歴史地震のシナリオの震源域・すべり量は史料に合わせ込んだものではなく、地殻変動の値は目安です。
- **建物被害は多めに出ます**: 南海トラフ最大クラスでは、静岡駅タイルのほぼ全域が震度 7 になり、建物の約半数が全壊と判定されます。被害率曲線が兵庫県南部地震の値（古い木造を含む建物構成）で、建物の耐震化を反映していないことと、距離減衰式を適用範囲の外まで使っていることによります。棟数は上限に近い目安として見てください。
- **1935 年静岡地震**: 断層の位置は概略で、発生機構（地殻内かプレート内か）にも諸説あります。高松・大谷の飛び地的な被害は再現を保証しません。
- **タイルの範囲**: 揺れは周辺も含めて計算しますが、斜面崩壊と土石流はタイルの中だけを計算します。
- **余震・火災・液状化・津波** は計算していません。静岡平野・清水の低地は液状化や津波の危険が大きい地域ですが、本アプリの結果には含まれません。
- 計算の速さは Mac の GPU によって大きく変わります。

## 14. 困ったとき

| 症状 | 対処 |
|---|---|
| 計算が遅い・画面がかくつく | 「計算速度」を下げる。タイルを 1 km 四方で作る |
| デスクトップ版が開けない | アプリを右クリック →「開く」。それでも開かない場合は「システム設定 → プライバシーとセキュリティ」で許可する |
| 新しいタイルが作れない | インターネット接続を確認する。国土地理院のサーバーが混んでいるときは時間をおいて再試行する |
| 建物の色が変わらない | 「3D建物を表示」がオンか、「建物の色分け」が白になっていないか確認する |
| 震度の表示が一面同じ色 | 断層の近くでは 2 km 四方のほぼ全体が同じ震度階級（多くは震度6強〜7）になる。濃淡と等震度線で、どこがより強く揺れるかを見る |
| 地震波のアニメーションが見えない | 地表の表示を「航空写真」以外（震度など）にすると見やすい。視点を引いて全体を見る |
| 録画が保存されない | 計算を最後まで終えてから録画する |
| 断層CSVが読み込めない | 赤字の行番号と理由を確認する。lon/lat は断層面の地表投影の **中心**、深さは top_depth_km か center_depth_km（`depth` だけの列名は上端か中心か分からないため不可） |
| 地点の CSV ボタンが押せない | 斜面崩壊・土石流の計算を実行してから押す |
