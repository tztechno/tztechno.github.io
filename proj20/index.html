SYSTEM FEATURES // 主な特徴

🃏

本格クロンダイク・ルール実装

場札（タブロー）・組札（ファウンデーション）・山札（ストック）・捨て札（ウェイスト）からなる標準的なクロンダイク・ソリティアのルールをフルスクラッチで実装。色違い降順の場札移動、同スート昇順の組札積み上げまで忠実に再現しています。

🤖

自動再生デモモード

「自動再生デモ」をワンクリックで起動すると、有効な手が見つかる限りカードが自動的に進みます。詰みを検知すれば自動停止、クリアすれば紙吹雪演出で祝福。手を考えずに観賞用として眺めることもできます。

🔓

登録不要・買い切り課金

アカウント登録やサブスクリプションは一切なし。まずは無料で5回プレイでき、続けて遊びたい場合のみStripe決済で¥100（税込）の買い切りライセンスを購入するだけのシンプル設計です。

TECHNICAL SPEC // 技術構成

CyberSolitiaはReact + TypeScript製のクライアントサイド・ゲームエンジンと、Netlify Functionsによるサーバーレスな決済処理を組み合わせ、軽量かつサーバーコストを抑えた構成で動作しています。

DECK & DEAL
52枚のカードをシャッフルし、7列のタブローへ配札。
GAME LOGIC
色違い降順・同スート昇順など、移動可否をクライアント側で判定。
AUTOPLAY ENGINE
350msごとに有効な一手を探索し、詰みを検知するまで自動進行。
STRIPE CHECKOUT
Netlify Functionsがワンタイム決済セッションを発行・検証。

React 19 + TypeScript + Vite

ゲーム盤面の描画コンポーネントと、山札シャッフル・移動判定・自動探索といったゲームロジックを明確に分離して実装。すべての演算はブラウザ内で完結し、外部サーバーへ盤面データが送信されることはありません。

Stripe + Netlify Functions

買い切りライセンスの決済はStripe Checkoutで処理し、Netlify Functions上のサーバーレス関数が決済セッションの発行・検証を担当。プレイ回数と購入状態はブラウザのlocalStorageに保存され、余計な個人情報を保持しません。

FAQ // よくある質問

Q: 無料で何回遊べますか？

ブラウザごとに5回まで無料でプレイできます。上限に達すると、¥100（税込）の買い切りライセンスを購入することで無制限にプレイできるようになります。

Q: アカウント登録は必要ですか？

不要です。プレイ回数や購入状態はブラウザのlocalStorageに保存される仕組みのため、メールアドレスやパスワードの登録なしでそのまま遊べます。ブラウザや端末を変更すると無料プレイ回数はリセットされます。

Q: 「自動再生デモ」とは何ですか？

有効な手が見つかる限り、エンジンが自動でカードを進め続けるモードです。詰みを検知すると自動的に停止し、クリアすれば紙吹雪の演出とともにお知らせします。手動プレイの参考としても、眺めて楽しむ用途としてもお使いいただけます。

Q: スマートフォンでも遊べますか？

はい、Chrome や Safari などの標準的なモバイルブラウザで動作します。ただし画面が小さい端末ではカードの視認性が下がる場合があるため、より快適に遊びたい場合はPCやタブレットでのプレイを推奨します。

Q: 購入したライセンスは他の端末でも使えますか？

ライセンスの購入状態はブラウザのlocalStorageと決済セッションIDに紐づいて管理されます。別のブラウザや端末に切り替えた場合は、現状は改めて購入いただく必要があります。
