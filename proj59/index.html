CORE FEATURES

最先端技術が融合するドライビング体験

高精細な3D都市モデル、緻密なコーナリング物理、昼夜・雨天のダイナミックな環境変化を余すところなく体験できます。

リアルな東京3D都市モデル

実測データから生成されたレインボーブリッジ、東京タワー、林立する高層ビル群、複雑な高架ジャンクションを圧倒的スケールで再現。沿道の有名施設には名前も表示。

Project PLATEAU WebGL 2.0

3段階のドライビング制御

安全な高速巡航をこなす完全自動（AUTO）、加速スリルを味わう半自動（SEMI）、腕が試される完全手動（MANUAL）をワンキーで切り替え。

Auto / Semi / Manual Lateral-G Control

ダイナミック天候＆グリップ変化

昼・夕暮れ・夜のライティング遷移に加え、雨天時にはリアルな路面反射とウェットコンディション（グリップが65%に低下）をシミュレート。夜はヘッドライトが点灯。

Day / Sunset / Night Wet Physics

4視点マルチカメラ

後方追従、低重心なコックピット視点、コース全体を見渡す上空カメラ、マウスで自由自在に見回せるフリーカメラを搭載。

Chase / Cockpit Overhead / Free Orbit

本格HUD・テレメトリ解析

横Gメーター、カーブごとの推奨安全速度サジェスト、ミニマップ、セクター別ラップタイム計測などレーシング計器を完備。

Real-time HUD Lap Analytics

クロスプラットフォーム

PC・スマートフォン・タブレットのブラウザですぐに遊べるWebGL版に加え、Apple Silicon Mac / Windows 向けのネイティブデスクトップアプリも提供。

Web / macOS / Windows / Mobile Tauri Native App

Touch Controls iOS / Android
COCKPIT IMMERSION

ノーズの上の低いコクピット視点と
リアルタイム・レーシングHUD

地面すれすれの視点で味わうスピード感。画面下の速度計にアクセル・ブレーキ、横G、コーナーごとの安全速度の目印を表示し、安全速度を超えると警告します。左上にはギア・エンジン回転数・区間名も表示します。

  • 横Gリミッター（0.5G〜2.2G）に応じたリアルタイム安全速度インジケーター
  • トラクションコントロール（TCS）＆ アンチロックブレーキ（ABS）常時稼働
  • ベストラップ保存機能＆不正ショートカット自動検知システム
NEW · PLATEAU LANDMARKS

PLATEAUの建物情報から
沿道の有名施設を名前で表示

首都高から見える周囲の建物のうち、フジテレビ、東京ビッグサイト、汐留の高層ビル群、東京タワー、東京スカイツリーなど約30の有名施設に名前を表示。名前と高さはProject PLATEAUの建物データ（建物名・計測高さ）から取得しています。

  • 「B」キー（スマホは B ボタン）で表示をON/OFF。設定はブラウザに保存
  • 名前は建物が見えている間だけ表示。ビルの陰やトンネルでは自動で消えるので迷わない
  • 名前の付く施設は遠くても建物を必ず表示。PLATEAUに塔がない東京スカイツリーも再現
NEW · NIGHT DRIVE

夜はヘッドライトが点灯、
前方の路面を照らして走る

時間帯を「夜」にすると、マシンのヘッドライトが自動で点灯。暗い高架や橋の上でも、前方の路面とカーブの先を照らしながら走れます。

  • 夜間は自動点灯、HUDに「ヘッドライト点灯」を表示
  • コクピット視点でも自然に見える、ロービーム風の配光
  • 窓明かり・道路照明・街明かりと合わせて、東京の夜を再現
NEW · MOBILE

スマートフォン・タブレットでも
タッチ操作でプレイ可能に

タッチ端末で開くと、画面に操作ボタンが自動で表示されます。キーボードと同じコマンドを、指でタップして操作できます。

  • M / V / R / P / L / N / T / Y / B と [ ] のコマンドボタン（機能名つき）
  • ◀ ▶ でハンドル、▲ ▼ でアクセル・ブレーキ。押している間だけ効き、同時押しにも対応
  • 横向き・縦向きの両方に対応したボタン配置
DRIVING STYLES

あなたの好みに合わせた3つの走行モード

走行中いつでも「M」キーひとつで切り替え可能。景色を楽しみたい初心者からタイムアタックに挑む上級者まで。

AI CRUISE

完全自動モード (AUTO)

AIが最適なレーシングラインと横Gリミッターに基づき、ステアリングと加減速を完全自動で制御。急なカーブの手前でも壁に接触しない安全な速度まで自動減速します。東京の街並みを眺めたい方に最適です。

ステアリング 完全自動（レーシングライン追従）
速度コントロール 完全自動（目標速度 50〜320 km/h 設定可能）
操作キー ↑ / ↓ 目標速度調整, [ / ] 横G上限調整
おすすめ対象 景観を楽しみたい方、3D都市モデルを鑑賞したい方
ACCEL & BRAKE

半自動モード (SEMI)

ハンドル操作は自動ライン追従に任せ、アクセルとブレーキの操作をドライバー自身が担当。安全速度表示を見極めながら、コーナー手前でどこまで突っ込めるかのブレーキング勝負を楽しめます。

ステアリング 自動（完全自動と同じ理想ライン）
速度コントロール 手動（アクセル＆ブレーキ）
操作キー W / ↑ アクセル, S / ↓ ブレーキ
おすすめ対象 手軽にスピード感とスリルを味わいたい方
FULL CONTROL

完全手動モード (MANUAL)

ステアリング、アクセル、ブレーキのすべてを自らの手でコントロール。速度に応じてハンドルの切れ角が最適化され、ABSとトラクションコントロールが限界領域でのマシン挙動を支えます。

ステアリング 手動（速度感応型ステアリングアシスト）
速度コントロール 手動（フルスロットル＆フルブレーキ）
操作キー A / D / ← / → ハンドル, W / S / ↑ / ↓ 加減速
おすすめ対象 最速ラップレコード更新を目指すエキスパート

WEATHER & TIME

リアルタイム環境シミュレーション

時間帯や天候によって路面コンディションと景観が劇的に変化します。夜はヘッドライトが前方を照らし、雨天時はブレーキングと横G管理が勝敗を分けます。

TIME OF DAY (時間帯 - Tキー)
WEATHER CONDITIONS (天候 - Yキー)
タイヤグリップ率 (Tire Grip) 100%
視界明瞭度 (Visibility) 85%
コーナリング安全速度目安 240 km/h

雨天時はタイヤグリップが65%まで低下し、制動距離が大幅に伸びます。自動運転モードも安全のため自動で巡航速度を抑えます。
