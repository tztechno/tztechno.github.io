RainViewer 3D — 使用マニュアル（日本語）

English manual

RainViewer 3D は、3D 地球儀（CesiumJS）の上に雨雲レーダーや気象衛星の画像を重ねて表示するアプリです。

  • 今の雨雲: RainViewer の降水レーダー（直近 2 時間＋30 分先の予測）
  • 過去の雨や雲: NASA GIBS の衛星データ（2000 年から今日まで、日付と時刻を指定）
  • 気圧・風速・気温: OpenWeatherMap の地図（無料の API キーが必要）

画面は 日本語と英語 を切り替えられます。

注意 — 表示される画像や CSV の値は、公開されているタイル画像から読み取った推定値です。 防災上の判断には、気象庁など公式の情報を使ってください。

1. 起動方法

インターネット接続が必要です（地図・レーダー・衛星画像をその場で取得します）。

版 起動のしかた
Mac（.dmg） RainViewer3D_1.0.0_aarch64.dmg を開き、RainViewer3D を「アプリケーション」フォルダへドラッグして起動します。
Windows（.exe） RainViewer3D_1.0.0_x64-setup.exe を実行してインストールします。インストールせずに使う場合は RainViewer3D_portable.exe をそのまま実行します。
ブラウザ版 rain_viewer フォルダで python3 -m http.server 8088 を実行し、ブラウザで http://localhost:8088/index.html を開きます。

初めて開くときの警告（「開発元を確認できません」など）は、13. 困ったとき を見てください。

2. 言語の切り替え（日本語 / English）

  • 画面右上の 言語ボタン（文字アイコンの横に「EN」または「日本語」と表示）を押します。
  • キーボードの L でも切り替えられます。
  • 選んだ言語は次回の起動時にも使われます。
  • 最初の起動では、パソコン（ブラウザ）の言語設定に合わせて選ばれます。
  • ブラウザ版では URL に ?lang=en または ?lang=ja を付けて言語を指定することもできます。

切り替わるもの: ボタン・メニュー・凡例・通知メッセージ・地球儀上の都市名・保存する画像の文字。 CSV の列名（time_utc, lat, lon …）は、言語に関係なく英語のままです。

3. 画面の構成

場所 内容
上部（ヘッダー） 地域ジャンプボタン、LIVE / 過去指定の表示、表示中の時刻（UTC）、操作ボタン（カレンダー・画像保存・CSV・更新・設定・言語・ヘルプ・全画面）
左上（レイヤーバー） 表示する気象・衛星レイヤーの切り替え。「レイヤー」の文字を押すと折りたためます。
右下（凡例） 色と値の対応（降水量 mm/h、気圧 hPa など）。右上の矢印で最小化できます。
下部（時刻パネル） 観測時刻、モード切り替え（LIVE・直近2h / 過去日時指定）、タイムスライダー、再生ボタン
右側（設定パネル） ベースマップ、不透明度、配色、国境線などの表示設定（S で開閉）

時刻は UTC（協定世界時） が基本で、日本時間（JST = UTC+9）を横に併記しています。

4. LIVE モード（直近 2 時間＋予測）

起動直後のモードです。RainViewer の雨雲レーダーを表示します。

  • 下部パネルの 「LIVE・直近2h」 を選ぶと、このモードになります。
  • タイムスライダー: 直近 2 時間（10 分間隔）と、30 分先までの予測（ナウキャスト）を選べます。
  • ▶（再生）: コマを順に自動で進めます。もう一度押すと止まります（Space）。
  • ⏮ / ⏭: 10 分ずつ前後に動かします（← / →）。
  • 「最新へ」: 最新の観測コマに戻ります。
  • データは約 5 分ごとに自動で更新されます。すぐ更新したいときは 更新 ボタン（R）を押します。

予測のコマを表示しているときは、時刻の横に「+10分 予測」のように表示されます。

5. 過去日時指定モード（カレンダー）

過去の日付・時刻の雨や雲を表示します（NASA GIBS のデータを使います）。

  1. 下部パネルの 「過去日時指定」 を押します（ヘッダーのカレンダーボタンや T でも切り替え可）。
  2. 日付 (UTC) と 時刻 (UTC) を選びます。右側に日本時間（JST）が表示されます。
  3. 雨雲レイヤーを選んでいる場合は、自動的に GPM IMERG 全球降水 の画像に切り替わります。

コマ送り・再生

ボタン 動き
-1日 / +1日 1 日前 / 1 日後
-3h / +3h 3 時間前 / 3 時間後
⏮ / ⏭ 1 コマ前 / 1 コマ後（ひまわり 10 分、IMERG 30 分、可視光衛星 1 日）
▶ タイムラプス再生（もう一度押すと停止）
時刻スライダー その日の 00:00〜23:50 UTC を移動

降水間隔（IMERG）

  • 30分刻み (時刻連動): 指定した時刻の 30 分ごとの降水
  • 1日合成 (日次平均): その日 1 日分をまとめた降水

過去の台風・豪雨プリセット

「過去の台風・豪雨プリセット」から事例を選ぶと、日付・時刻・レイヤー・地域が一度に設定されます。 例: 令和元年東日本台風（台風 19 号）、令和 2 年 7 月豪雨（熊本豪雨）、平成 30 年 7 月豪雨（西日本豪雨）など。

選べる期間

データ 期間 間隔
ひまわり赤外線雲 直近 2〜3 か月ほど（NASA 側で古いデータから順に消えます） 10 分
GPM IMERG 全球降水 2000 年 6 月〜 30 分 / 1 日
MODIS 可視光衛星 2000 年 2 月〜 1 日

最新の数時間〜1 日ほどは、NASA 側でまだデータが用意されていないことがあります（画像が出ない場合は少し前の日時を選んでください）。

6. 気象・衛星レイヤー

左上のレイヤーバー、または設定パネルで選びます（W で順番に切り替え）。

レイヤー 内容 データ API キー
雨雲・降水 雨雲レーダー（過去日時では GPM IMERG） RainViewer / NASA 不要
ひまわり赤外線雲 気象衛星ひまわりの赤外線画像。白いほど雲頂が高く冷たい NASA GIBS / 気象庁 不要
全球降水 (IMERG) 衛星から推定した全世界の降水強度 NASA GIBS / JAXA 不要
衛星雲 (可視光) 人の目で見た色に近い衛星写真（1 日 1 枚） NASA GIBS (MODIS) 不要
気圧 (hPa) 海面気圧 OpenWeatherMap 必要
風速 (m/s) 地上の風速 OpenWeatherMap 必要
気温 (°C) 地上の気温 OpenWeatherMap 必要

NASA のレイヤーを選ぶと、自動的に過去日時指定モードに切り替わります。

8. 画像（PNG）の保存

カメラボタン、下部パネルの 「保存」、または P で、今見ている地球儀を PNG 画像として保存します。

画像には次の情報が書き込まれます。

  • 左下: 表示中の時刻（UTC）、日本時間、レイヤー名、地域、カメラの位置と高度
  • 右下: 凡例（色と値の対応）

ファイル名の例: RainViewer3D_radar_2026-11-07_0010UTC.png

保存先

  • デスクトップ版（Mac / Windows）: 「ダウンロード」フォルダ。同じ名前のファイルがあるときは (2) を付けて保存し、上書きはしません。保存先のパスは通知に表示されます。
  • ブラウザ版: ブラウザのダウンロード先

9. 降水データの CSV 保存

CSV ボタン、または C で、今画面に映っている範囲 の降水データを CSV ファイルに保存します。 「雨雲・降水」または「全球降水 (IMERG)」レイヤーを表示しているときだけ使えます。

列 内容
time_utc データの時刻（UTC）
lat, lon 緯度・経度
dbz レーダー反射強度（LIVE の RainViewer のみ）
precip_mm_h 降水強度（mm/h）
precip_type rain（雨）/ snow（雪）
source データの出どころ
  • 格子は最大 300 × 300 点です。広い範囲ほど点の間隔が粗くなります。
  • 値はタイル画像の色から逆算した推定値です。
    • LIVE: RainViewer の色表で dBZ に戻し、Marshall-Palmer 式（雨 Z=200R^1.6、雪 Z=2000R^2）で mm/h に換算
    • 過去日時 / IMERG: NASA GIBS のカラーマップで mm/h の階級に変換
  • 保存先は PNG と同じです。

10. 設定パネル

ヘッダーの設定ボタン（S）で開きます。

項目 内容
表示中の気象・衛星レイヤー レイヤーの切り替え（レイヤーバーと同じ）
OpenWeatherMap API 設定 API キーの入力・保存・削除
地球ベースマップ Dark Earth（暗い地図、気象データが見やすい）/ Blue Marble（衛星写真）
レイヤー不透明度 気象レイヤーの濃さ（15〜100%）
雨雲配色パレット 雨雲レーダーの色（Universal Blue、TITAN など）。LIVE の雨雲レイヤーのみ
補間スムージング / 降雪カラー識別 雨雲をなめらかに表示 / 雪を別の色で表示
国境線・主要都市マーカー・大気グロー・自転 地球儀の表示効果

11. OpenWeatherMap API キーの設定

気圧・風速・気温のレイヤーには、OpenWeatherMap の 無料の API キー が必要です。

  1. OpenWeatherMap の登録ページ でアカウントを作ります（クレジットカード不要）。
  2. マイページの [API keys] タブにある 32 文字のキーをコピーします。
  3. 気圧などのレイヤーを選ぶと入力画面が開くので、キーを貼り付けて「保存してレイヤーを表示」を押します（設定パネルからも入力できます）。
  • キーはこのパソコン（ブラウザ）の中だけに保存されます。
  • 発行したばかりのキーは、使えるようになるまで数分〜2 時間ほどかかることがあります。
  • 削除するときは設定パネルの「キー削除」を押します。

13. 困ったとき

症状 対処
Mac で「開発元を確認できないため開けません」と出る アプリを 右クリック →「開く」 を選びます。または「システム設定 → プライバシーとセキュリティ」の「このまま開く」を押します。それでも開けないときは、ターミナルで xattr -cr /Applications/RainViewer3D.app を実行します。
Windows で「PC を保護しました」と出る 「詳細情報」→「実行」 を押します。
地球儀が真っ黒、画像が出ない インターネット接続を確認し、R で再取得します。
過去日時で雨や雲が表示されない その日時のデータがまだ公開されていない可能性があります。1〜2 日前の日時を選んでください。ひまわりは直近 2〜3 か月ほどのデータしかありません（過去の台風はGPM IMERG の降水で見てください）。
気圧・風速・気温が出ない API キーを確認してください。発行直後は有効になるまで時間がかかります。
CSV ボタンを押しても保存されない 「雨雲・降水」か「全球降水 (IMERG)」レイヤーに切り替えてから押してください。
保存したファイルが見つからない デスクトップ版は「ダウンロード」フォルダに保存されます。通知に保存先のパスが表示されます。

14. データ出典

  • リアルタイム雨雲レーダー: RainViewer API
  • 過去の降水・ひまわり赤外線・衛星画像: NASA GIBS（JAXA GPM IMERG / 気象庁 ひまわり 8・9 号 / NASA Terra MODIS）
  • 気圧・風速・気温: OpenWeatherMap Weather Maps
  • ベースマップ・境界線: Esri World Dark Gray / World Imagery / World Boundaries and Places
  • 3D 地球儀エンジン: CesiumJS
