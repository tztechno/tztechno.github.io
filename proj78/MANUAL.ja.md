# Yatsushiro Fault（八代 日奈久断層帯・内陸型地震シミュレーター）— 使用マニュアル

熊本県八代市を通る **布田川・日奈久断層帯** の活断層（国土地理院「活断層図」と八代市「断層地図」）を、国土地理院の地形・建物・航空写真の 3D 表示に重ね、
活断層が動いて内陸型地震が起きたときの

- 揺れの強さ（計測震度・最大地動速度 PGV・最大加速度 PGA）
- 地表に現れる断層のずれ（横ずれ・縦ずれ段差）
- 建物 1 棟ごとの被害（断層変位による損壊・全壊・半壊・一部損壊）
- 揺れによる斜面崩壊と、崩れた土砂の流下（土石流）

を計算して表示するアプリです。宝塚版（Takarazuka Fault）と同じ計算エンジンを、八代市周辺のデータに置き換えて作っています。

> **注意** — 結果は、公開データと簡略化した計算式による **想定の一例** です。実際の被害や、国・熊本県・八代市の公式の被害想定とは一致しません。
> 防災上の判断には、八代市の防災マップ（ハザードマップ）や公式の情報を使ってください。

## 1. 起動方法

| 版 | 起動のしかた |
|---|---|
| デスクトップ版（macOS） | `YatsushiroFault_<版>_aarch64.dmg` を開き、`YatsushiroFault.app` を「アプリケーション」へドラッグして起動 |
| デスクトップ版（Windows） | `YatsushiroFault_<版>_x64-setup.exe` を実行してインストール（「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」） |
| Web 版 | 配布された URL をブラウザ（Chrome / Edge / Safari の最新版）で開く |
| 開発用 | `yashiro_fault_desktop` フォルダで `npm install` → `npm run dev` → `http://localhost:5178/` |

- WebGL2 が使える PC が必要です。GPU を使って計算します。
- 既定の 7 地区はアプリに同梱されているので、インターネットがなくても表示・計算できます。住所から新しいタイルを作るときだけ接続が必要です。

## 2. 画面の構成

### 表紙
最初に表紙が表示されます。読み込みが終わったら **開始**（または Enter）を押します。右側の一覧から地区を選んで始めることもできます。
左上の **表紙** ボタンで、いつでも表紙に戻れます。

### 画面の各部

| 場所 | 内容 |
|---|---|
| 左の操作パネル | 1. 地域 / 2. 活断層図・地震シナリオ / 3. 表示切り替え / 4. 計算 / 5. 詳細設定 / 6. ハザードマップ / 7. 録画 |
| 中央 | 3D 表示（地形・建物・活断層図・揺れの色分け・土砂） |
| 左上の情報欄（HUD） | 地区名、経過時間、地震の規模と最大震度、建物被害の推計、崩壊面積 |
| 右上 | 凡例（表示している内容に合わせて切り替わります） |
| 左下 | 広域マップ（八代・日奈久断層帯周辺 60 × 64 km の陰影図と、区間別に色分けした活断層。クリックで場所を選択） |
| 下部 | 再生バー（計算結果のコマ送り）と、地点の時間変化のグラフ |

## 3. 地域（タイル）を選ぶ・作る

### 既定の地区から選ぶ
「1. 地域」のリストから選びます。どれも 2 km 四方・2 m 格子（100 万セル）です。

| 地区 | 主な活断層・特徴 |
|---|---|
| 日奈久温泉 | 日奈久区間の断層が温泉街の背後（山麓）を通る。断層直上の変位と山麓の斜面崩壊 |
| 宮地・妙見 | 八代神社（妙見宮）・宮地の山麓を日奈久区間が通る。平野と山地の境界 |
| 八代市街地 | 断層から西へ約 3 km の八代平野。断層線はタイル外で、揺れと建物被害の比較用 |
| 二見 | 日奈久区間の南西端。八代海区間の地震との比較に |
| 千丁・鏡東部 | 日奈久区間の北部が平野の東縁を通る。山麓の集落と土石流 |
| 東陽町小浦 | 日奈久区間の東側の副断層と山間の集落・地すべり地形 |
| 坂本 | 球磨川沿いの急斜面と集落。断層から約 4 km 離れた地点の地震時崩壊 |

情報欄には、タイル内でいちばん近い活断層までの距離と、断層から 20 m・100 m・300 m 以内の面積が表示されます。

### 住所・地名から新しいタイルを作る
1. 「住所・地名から新しいタイルを作る」を開き、住所や地名を入れて **検索**（例: 八代市日奈久、妙見町、鏡町、坂本町）
2. 候補から選び、タイルの大きさ（1 / 2 / 3 km 四方）を選ぶ
3. **このタイルを作成して表示** を押す（インターネット接続が必要。地形・建物・航空写真を取得して数十秒〜数分）

左下の広域マップをクリックして場所を選ぶこともできます。作ったタイルはリストに **★** 付きで残ります（Web 版ではそのブラウザの中だけに保存されます）。

## 5. 地震シナリオを選ぶ

「内陸型地震・活断層活動シナリオ」から選ぶと、規模などの値がまとめて設定されます。
起動時は「断層活動なし」です。地震も雨もない平常時の状態なので、建物は色分けされません。地震を見るときは、下の表のシナリオを選んでください。

| シナリオ | 動く断層 | 規模 | 内容 |
|---|---|---|---|
| 断層活動なし（既定） | なし | — | 地震も雨もない平常時。起動時の状態 |
| 日奈久区間の地震 | 日奈久区間 | M7.5 / Mw7.0 | 八代市の山麓を通る区間の直下型地震。地表に断層が現れる |
| 日奈久断層帯 全区間連動 | 高野－白旗・日奈久・八代海区間 | M7.8〜8.1 / Mw7.4 | 3 区間（約 80 km）が同時に動く最大級のケース |
| 八代海区間の地震 | 八代海区間 | M7.3 / Mw6.9 | 海底の断層。八代市内に地表のずれは出ず、南部の沿岸で揺れが強い（津波は計算しない） |
| 2016年 熊本地震（本震）型 | 布田川区間・高野－白旗区間 | M7.3 / Mw7.0 | 熊本地震の本震の破壊を再現し、八代市での揺れを比べる |
| 浅部直下・地表断層変位集中型 | 高野－白旗・日奈久区間 | M7.2 / Mw6.8 | 地図上の断層線で地表にずれが現れる場合。断層直上の被害を見る |
| 複合災害：豪雨の後の地震 | 日奈久区間 | M7.5 / Mw7.0 | 1 時間 75 mm の雨で土が湿った状態で地震が起きる最悪のケース |
| 比較用：豪雨単独 | なし | — | 令和2年7月豪雨（球磨川流域）型の雨だけ。地震による被害との比較用 |

規模（M）は地震調査研究推進本部の長期評価の値を目安にしています。
M は気象庁マグニチュード、Mw はモーメントマグニチュードです。計算には Mw を使います。内陸の大地震では Mw が M より 0.3〜0.5 ほど小さいのが普通です（2016 年熊本地震の本震は M7.3、Mw7.0）。

### 値を変える

| 項目 | 意味 |
|---|---|
| 地震規模 Mw | 大きいほど広い範囲が強く揺れる |
| 断層上端の深さ (km) | 0 で断層が地表まで破れる。深くするほど地表のずれは小さくなり、1 km 以上では地表破断なし |
| 横ずれ変位量 (m) | 断層に沿った水平のずれ |
| 縦ずれ段差・撓曲変位量 (m) | 断層をはさんだ上下のずれ（3D 地形に段差として表示） |
| 断層近傍パルス増幅率 | 断層の近く（約 1 km 以内）で揺れを強める倍率（破壊の進む向きに強い揺れが集まる効果） |
| 強震継続時間 (秒) | 強い揺れが続く時間。斜面崩壊の計算と地震波のアニメーションに使う |

値を変えると、揺れ・建物被害・広域の震度がすぐに計算し直されます。
**⚡ 断層破断・地震波3Dアニメーション再生** を押すと、断層から地震波が広がって地面が揺れる様子が再生されます。

### 結果の要約
シナリオの下に次の結果が表示されます。

- 最大計測震度（震度階級）、最大 PGV / PGA
- 地表の断層変位の最大値、震度 7 の面積
- 地震時に不安定になる斜面の面積（括弧内は、揺れがなくても不安定な面積）と、断層変位帯の面積
- 建物被害推計（断層変位・全壊・半壊・一部損壊・無被害の棟数と割合のバー）

## 6. 揺れと建物被害を見る

「3. 3D表示切り替え」で、地表と建物の色分けを選びます。

### 地表の表示

| 表示 | 内容 |
|---|---|
| 航空写真（＋活断層図） | 国土地理院の航空写真に活断層図を重ねる（起動時の表示） |
| 想定震度分布 | 震度 4 以下〜震度 7 を気象庁の階級で色分け。同じ階級の中でも揺れが強いほど濃く、計測震度 0.1 ごとに等震度線（0.5 ごとの階級の境は太線）を引く |
| 最大地動速度 PGV | 地面が揺れる速さの最大値 (cm/s) |
| 活断層距離・地表変位危険帯 | 断層からの距離で色分け |
| 斜面の安全率 FS | 1 未満が崩れる状態。地震中は揺れの力を含めた値 |
| 土壌の飽和度 / 傾斜 / 標高段彩 | 土の湿り具合、斜面の角度、標高 |

広域（周辺・遠景）の地形も、震度・PGV・断層距離の表示に合わせて色分けされます。

### 建物の色分け

| 表示 | 内容 |
|---|---|
| 地震・断層変位・土砂 総合被害判定 | 紫=断層変位による損壊、赤=全壊、橙=半壊、黄=一部損壊、白=無被害・軽微 |
| 建物の揺れ（震度階級） | 建物の位置の震度 |
| 土砂の埋没深 / 衝撃圧 | 斜面崩壊の計算後、土砂に埋まった深さ・土砂が当たった力 |
| 白 | 色分けなし |

そのほか、土砂の見え方、航空写真の影の補正、3D 建物・ラベル・周辺地形の表示、計算後の最大堆積深の表示を切り替えられます。

## 7. 地震による斜面崩壊・土石流を計算する

1. 地区とシナリオを選ぶ
2. 「4. 地震時斜面崩壊・土石流の計算」の **▶ 地震・土砂崩壊の計算開始** を押す
3. 地震波が断層から広がり、揺れの強い急斜面から崩れて、土砂が谷や住宅地へ流れ下ります
4. 土砂が止まると計算が終わり、結果がまとめて表示されます

雨のない地震だけのシナリオは、計算時間 3 分（揺れ＋土砂が止まるまで）で、2 km 四方なら PC によって 20〜60 秒ほどで終わります。
豪雨を含むシナリオは雨の時間ぶん計算するため長くなります。

| ボタン・設定 | 内容 |
|---|---|
| ⏸ 一時停止 / ↺ リセット | 計算を止める / 最初の状態に戻す |
| 計算速度 | 1 画面更新あたりの計算ステップ数。大きいほど速いが画面がかくつく |
| 安全係数 (CFL) | 時間刻みの安全率。通常は 0.5 のまま |

計算が終わると、下の再生バーで時間を戻したりコマ送りしたりできます。

### 結果の内容
地震被害の要約に加え、斜面崩壊の箇所数と面積、最初の崩壊時刻、崩れた土砂の量、土砂が届いた範囲、堆積の深さ・最大流速、
土砂が届いた建物・埋まった建物・強い衝撃を受けた建物の棟数が表示されます。

### 詳細設定（5. 土質・先行降雨・崩壊条件）
通常は変える必要はありません。

- **先行降雨・複合豪雨条件**: 地震の前後に降る雨の量・時間（シナリオを選ぶと自動で設定）
- **土質**: 土層の厚さ、粘着力、内部摩擦角、透水係数、初期飽和度など。初期飽和度を上げると、雨の後の湿った斜面で地震が起きる状態になる
- **土石流**: 崩れた土砂の流れやすさ（摩擦係数など）
- **崩壊源の追加指定**: 斜面をクリックして、決まった時刻に強制的に崩す場所を追加できる

## 8. 地点をクリックして調べる

3D 画面をクリックすると、その地点の情報が表示されます。

- 活断層までの距離と、どちら側か（隆起側・山地側 / 沈降側・盆地側）、その場所の地図記号
- 震度（計測震度）、PGV、PGA、地表の断層変位量と上下のずれ
- 土層の厚さと安全率（ふだん・地震時の最小・雨で飽和したとき）
- 建物をクリックした場合は、建物の種類・階数・被害判定・断層からの距離
- 計算後は、土砂の深さ・速さの時間変化を下のグラフに表示

**CSV** ボタンで、その地点の値を CSV で保存できます。

## 9. 土砂災害ハザードマップと比べる

「6. 土砂災害警戒区域の重ね合わせ」で、重ねるハザードマップ（国土地理院）の土砂災害警戒区域（イエロー）・特別警戒区域（レッド）を重ねます（熊本県の指定。土石流・急傾斜地の崩壊・地すべり）。
計算で土砂が届いた範囲と、警戒区域との重なりが集計されます。
左下の広域マップには、活断層図と警戒区域の両方が重なって表示されます。

## 12. 計算の考え方

### 活断層までの距離
陸の断層は国土地理院の活断層図のタイル画像から赤い断層線の位置を取り出し、海域・伏在部（八代海区間・宇土区間・宇土半島北岸区間）は八代市の断層地図の画像を経緯度線で位置合わせして取り出しています。各点を八代市の断層地図の区間に振り分け、各セル（2 m）から最も近い断層までの距離を求めます。
シナリオで動く区間だけを使って距離を計算し直します。断層の向きから、断層のどちら側か（日奈久断層帯では南東の山地側、ほかの区間では北西側が +）も区別しています。

### 揺れ
- **基盤の揺れ**: 断層からの距離と Mw から、司・翠川 (1999) の距離減衰式で工学的基盤（Vs = 600 m/s）の PGV を求める
- **地盤による増幅**: 平らな低地（軟らかい堆積層）ほど揺れが大きく（約 2 倍）、山の急斜面（固い岩盤）ほど小さくする。地形の傾きは周囲約 50 m の平均を使う（道路の法面や擁壁などの細かな段差では変えない）
- **断層近傍の効果**: 断層から約 1 km 以内の揺れの集中（パルス）、断層の上盤側の増幅、盆地の縁（断層から数百 m の盆地側）での増幅（「震災の帯」）
- **震度**: PGV から計測震度に換算（翠川ほか 1999: I = 2.68 + 1.72 log PGV）
- **PGA**: PGV の 8.5〜11 倍（急斜面ほど大きい）

### 地表の断層変位
断層上端の深さが浅いほど地表に大きなずれが現れ、断層線から離れるほど小さくなります（幅 20 m 程度）。縦ずれは断層をはさんで上下に分かれ、3D 地形に段差として表示されます。

### 建物被害
- 建物の位置の PGV から、被害率曲線（対数正規分布）で全壊・半壊以上・一部損壊以上の確率を求める
  - 木造など一般の建物（普通建物）: 全壊の中央値 165 cm/s、半壊以上 105 cm/s、一部損壊以上 55 cm/s
  - 堅ろう建物・高層建物・4 階以上: 全壊 300 cm/s、半壊以上 200 cm/s、一部損壊以上 100 cm/s
- 確率に従って 1 棟ずつ被害区分を決める（何度計算しても同じ結果になる乱数を使用）
- 断層線から 15 m 以内で変位が 0.3 m 以上の建物は「断層変位による損壊」とする

### 斜面崩壊・土石流
- 土の中の水と斜面の安全率は、もとの土砂災害シミュレーターと同じ計算（無限長斜面の安全率）
- 地震中は、揺れの水平の力（水平震度 kh = 0.15 × PGA / 重力加速度、最大 0.3）を加えて安全率を計算する
  - 揺れの瞬間の最大値は一瞬しか働かないため、斜面が 5〜10 cm 以上すべる目安（Jibson 2007）に相当する値を使う
  - 揺れの最中は土の強度に余裕があるとして、安全率を 1.3 倍して判定する
- 地震波は断層から約 1.8 km/s で広がり、届いた所から順に揺れ始める
- 断層直上（約 30 m 以内）では、地表の破断で土の強さが下がる
- 崩れた土砂は土石流として流れ下り（Voellmy 摩擦）、緩い所で止まって堆積する

## 13. 注意・制約

- **想定の一例であること**: 揺れの式・被害率曲線・斜面の判定は簡略化したものです。地盤の詳しい調査結果（ボーリングなど）や、建物の建築年・構造は反映していません。
- **建物の情報**: 建物は国土地理院の建物外形で、構造は「普通建物 / 堅ろう建物 / 高層建物」の区分だけです。建築年（耐震基準）は区別していません。
- **活断層の位置**: 活断層図は表示用の画像なので、線の太さや記号の大きさの分だけ位置に幅があります。八代市の断層地図は小縮尺（1 画素 約 90 m）のため、そこから取った海域・伏在部の断層は ±100 m 程度の誤差があります（国土地理院の活断層図と重ねて平均のずれ約 180 m を補正済み）。断層変位による損壊の棟数は多めに出る傾向があります。
- **八代海区間・熊本地震型シナリオ**: 震源断層の大部分は広域マップやタイルの外にあり、八代市での揺れは断層までの距離から求めています。津波は計算していません。
- **タイルの範囲**: 揺れは周辺も含めて計算しますが、斜面崩壊と土石流はタイルの中だけを計算します。
- **余震・火災・液状化・津波** は計算していません。
- 計算の速さは PC の GPU によって大きく変わります。

## 14. 困ったとき

| 症状 | 対処 |
|---|---|
| 画面が真っ黒・「WebGL2」のエラー | WebGL2 に対応したブラウザ（Chrome / Edge / Safari 最新版）を使う。GPU のドライバを更新する |
| 計算が遅い・画面がかくつく | 「計算速度」を下げる。タイルを 1 km 四方で作る |
| デスクトップ版が開けない | アプリを右クリック →「開く」。それでも開かない場合は「システム設定 → プライバシーとセキュリティ」で許可する |
| 新しいタイルが作れない | インターネット接続を確認する。国土地理院のサーバーが混んでいるときは時間をおいて再試行する |
| 建物の色が変わらない | 「3D建物を表示」がオンか、「建物の色分け」が白になっていないか確認する |
| 震度の表示が一面同じ色 | 断層の近くでは 2 km 四方のほぼ全体が同じ震度階級（多くは震度6強）になる。濃淡と等震度線で、どこがより強く揺れるかを見る |
| 地震波のアニメーションが見えない | 地表の表示を「航空写真」以外（震度など）にすると見やすい。視点を引いて全体を見る |
| 録画が保存されない | 計算を最後まで終えてから録画する |
