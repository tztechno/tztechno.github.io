南海トラフ津波広域伝播シミュレーター 操作マニュアル

Nankai Trough Tsunami Simulator - User Manual (Japanese)

1. はじめに

本ソフトウェアは、地震による海底の地殻変動から津波の初期波形を求め、日本列島周辺の海域で津波が広がる様子を物理シミュレーションする対話型ツールです。アプリ名は「南海トラフ」ですが、計算範囲は日本全国（東経125.6°〜152.9°、北緯22.0°〜48.0°）で、南海トラフ以外の地震（2011年東北地方太平洋沖地震など）も扱えます。

2段階シミュレーションの構想

  1. フェーズ1（広域伝播：本システム）
    • 地震の断層モデルから津波の発生と伝播を計算し、各地の沖合観測点で水位・流速・流向・到達時刻を求めます。
  2. フェーズ2（市街地の津波遡上シミュレーションとの連携）
    • 本システムが出力する沖合の水位・流速の時系列（CSV）を、高解像度の市街地遡上シミュレーションの境界条件として使います。

重要

本システムの波高は、水深数十〜数千mの沖合の観測点での値です。海岸での津波高や遡上高は、浅い海で波が高くなる効果（浅水変形）によりこれより大きくなります。沿岸の被害想定には、フェーズ2の市街地シミュレーションや公的な想定をご利用ください。

2. 動作環境と起動方法

2.1 Webブラウザ版

  • 対応ブラウザ: Google Chrome、Microsoft Edge、Apple Safari、Mozilla Firefox（最新版）
  • 起動:
    cd nankai_trough
npm install
npm run dev
    ブラウザで http://localhost:5173/ を開きます。
  • ファイルの保存先: CSV・動画はブラウザの通常のダウンロード先に保存されます。

2.2 デスクトップ版（Tauri: macOS / Windows）

  • macOS: NankaiTroughTsunami_<版>_aarch64.dmg を開き、アプリをアプリケーションフォルダへドラッグします。
  • Windows: NankaiTroughTsunami_<版>_x64-setup.exe を実行します（GitHub Actions のワークフロー .github/workflows/build-windows.yml で生成）。
  • ソースからのビルド:
    cd nankai_trough_desktop
npm install
npm run tauri dev    # 開発モードで起動
npm run tauri build  # 配布用ビルド (dmg / exe)
  • ファイルの保存先: CSV・動画は**「ダウンロード」フォルダ**に直接保存され、画面右下に保存先が通知されます。同名のファイルがある場合は ファイル名 (1).csv のように番号が付きます。

2.3 データの準備（開発者向け）

アプリが使うデータは public/ にあり、次のスクリプトで作り直せます（nankai_trough/ で実行）。

データ 作成コマンド 内容
bathymetry.bin / bathymetry_meta.json node scripts/process_bathymetry.mjs ../japan.tif 6 海底地形 (japan.tif, 15秒メッシュ) を係数6で平均化した1.5分メッシュ (約2.8km, 1093×1040格子)。係数を8にすると約3.7kmメッシュで計算が軽くなります
bathymetry_osaka_bay.bin / _meta.json node scripts/process_bathymetry.mjs ../japan.tif 1 --bounds 134.55,135.55,34.0,34.75 --name osaka_bay 大阪湾・紀伊水道北部の高解像度領域 (15秒メッシュのまま切り出し、240×180格子)
slab.bin / slab_meta.json python3 scripts/process_slab.py <深さグリッド.grd> ... プレート境界の深さ・走向・傾斜 (0.1度格子)。USGS Slab1.0 / Slab2 の kur・izu・ryu 地域の深さグリッドを指定。numpy・scipy が必要

変更したデータは、デスクトップ版の nankai_trough_desktop/public/ にもコピーしてください。

4.1 内閣府 南海トラフ巨大地震（ケース①〜⑤）

内閣府「南海トラフの巨大地震モデル検討会」第二次報告（2012年）の津波断層モデルを、報告書に書かれた設定ルールから概略再現したものです。

  • 想定震源域: 駿河湾〜日向灘、トラフ軸からプレート境界の深さ約37kmまで（面積 約14万km²、Mw9.1、平均すべり量 約10〜11m）
  • すべり量: 背景領域 約9m、大すべり域 約20m（平均の2倍）、超大すべり域 約40m（平均の4倍、トラフ沿い）。大すべり域は全体面積の約20%で、深さ約20kmからトラフ軸までに置きます。
  • ケースの違い: 全域が破壊する点は共通で、大すべり域の位置だけが異なります。
    ケース 大すべり域・超大すべり域の位置
    ① 駿河湾〜紀伊半島沖
    ② 紀伊半島沖
    ③ 紀伊半島沖〜四国沖
    ④ 四国沖
    ⑤ 四国沖〜九州沖
  • 破壊の伝わり方: 破壊開始点（大すべり域の中心付近、深さ約20km）から 2.5km/s で破壊が広がり、各地点の地殻変動は 1分かけて生じます（全域同時ではありません）。
  • 地図表示: 小断層をすべり量に応じた濃さの赤で塗り分けます（濃いほど大きくすべる）。
  • 公式モデルとの違い: 公式の小断層データ（約5kmメッシュ）は申請制のため、プレート形状を一様な傾斜の帯で近似し、プレートの沈み込み速度に比例したすべり配分や大すべり域境界の平滑化は省略しています。ケース⑥〜⑪（分岐断層・大すべり域2箇所）は未実装です。
  • 最大クラスの津波高の考え方: 政府の「最大クラスの津波高」は、各地点で全ケースのうち最も高い値をとったものです。ケースを順に計算し、地点ごとに最大値を比べてください。

注記

旧来の中央防災会議（2003年）のモデルは、過去5地震（宝永・安政東海・安政南海・昭和東南海・昭和南海）の津波記録を包絡するように作られたモデルです。内閣府（2012年）のモデルは、過去の地震の寄せ集めではなく、科学的知見に基づく「最大クラス」の想定です。

4.2 地図上のマークの意味

マーク 意味
赤い点線の長方形 ＋ ★ 断層セグメントの地表投影と、その中心点（震央ではありません）
赤い塗り分け（枠線なし） 内閣府モデルの小断層（濃いほどすべり量が大きい）
赤丸に白い × 震源（気象庁）または内閣府モデルの破壊開始点
中抜きの赤丸に × 参考: 同じ型の歴史地震の推定震央（想定地震のため公式の震源がないもの）

震源・破壊開始点のマークは「震源断層」レイヤーと連動して表示されます。歴史地震の震源は表示のみで、計算には使いません（内閣府モデルの破壊開始点は破壊伝播の計算に使います）。

5. 震源断層の設定

5.1 マグニチュードとすべり量

  • マグニチュード (Mw): 7.5〜9.3。動かすと、対応するすべり量が「平均すべり量」に反映されます。
  • 平均すべり量 (Slip): 2.0〜50.0m。
  • 波源を再生成: 設定を波源に反映し、時刻0に戻します。複数の断層からなるプリセットでは、すべり分布（大すべり域など）の比率を保ったまま平均すべり量が指定値になるよう全体を比例させます。

5.2 震源クリック指定（プレート境界に沿った自動設定）

  1. マグニチュードを選びます（断層の大きさはマグニチュードから決まります）。
  2. 🎯 震源クリック指定 を押し、地図上の震源にしたい場所をクリックします。
  3. クリック地点のプレート境界の深さ・走向・傾斜を USGS Slab（プレート境界形状モデル）から読み取り、プレート境界に沿った逆断層を自動で置きます。海溝側が隆起し、陸側が沈降する向きになります。
    • 断層の大きさ: プレート間地震のスケーリング則（Strasser et al., 2010）で決めます（例: Mw8.0 → 長さ約160km×幅約84km、Mw9.0 → 約614km×189km）。
    • すべり量: 地震モーメント（剛性率 40GPa）がマグニチュードに合うよう計算します。
    • 断層の上端が地表に出る場合は、上端が深さ1kmになるよう陸側へずらします。
  4. 次の場合は、自動設定の代わりに カスタム断層パラメータ欄の値（手動） を使い、その理由を表示します。
    • プレート境界データの範囲外（日本海、陸域の内陸など）
    • プレート境界が深さ60kmより深い（プレート間地震としては深すぎる）
    • 「プレート境界の形状 (USGS Slab) から自動設定」のチェックを外している

5.3 カスタム断層パラメータ（手動調整）

震源クリック指定をすると「📐 カスタム断層パラメータ」欄が開き、配置された断層の値が表示されます。

項目 範囲 説明
走向 (°) 0〜360 断層の向き（北から時計回り）。傾斜する向きは走向の右手側
傾斜 (°) 1〜90 断層面の傾き
すべり角 (°) -180〜180 90 が純粋な逆断層
長さ (km) / 幅 (km) — 断層面の大きさ（幅は傾斜方向に沿った長さ）
上端深さ (km) 0.5〜100 断層面の上端の深さ

値を変えて この値で波源を再生成 を押すと、その断層で波源を作り直します（すべり量は現在のマグニチュードと断層面積から再計算）。カスタム震源は全域同時に破壊します。

「2. 伝播シミュレーション」で操作します。

操作 説明

  • 画面上部の 経過時間 と地図左下の 地震発生から H:MM:SS は、地震発生からの時間です。
  • 内閣府モデルでは破壊が広がる数分間、地殻変動が順次加わっていきます。

7. 地図の操作と表示

7.1 操作

  • ホイール: ズーム（カーソル位置を中心に拡大・縮小）
  • ドラッグ: 表示範囲の移動
  • 🔍 震源域へ: 選択中のシナリオの震源域に合わせて表示
  • ⤢ 全国表示: 解析領域全体を表示
  • カーソルを合わせる: 左上に経緯度、水深（陸は標高）、その地点の現在の水位が表示されます
  • 地図の縦横比は保たれます（ウィンドウの形に合わせて伸び縮みしません）。

8.2 観測地点の操作

  • ＋ 指定点追加: 押してから地図の海域をクリックすると観測地点を追加します。追加した地点は ✕ で削除できます。
  • チェックボックス: グラフの重ね合わせ表示と CSV 一括出力の対象を選びます（全選択・全解除あり）。
  • 詳細フォーカス地点: グラフ見出しの統計を表示する地点です。リストのカードや地図上の地点をクリックしても切り替わります。
  • ↺ 初期化: 既定の20地点に戻します。
  • ※ 田老沖・宮古湾口沖は、市街地シミュレーション「MIYAKO TSUNAMI」の田老地区・宮古湾の計算域の流入境界のすぐ外側に置いた地点です。この2地点の CSV をそれぞれの地区の波源として使えます。
  • 高解像度領域の中にある地点（既定の大阪湾5地点や、その範囲に追加した地点）は、細かい格子の値を記録します。
  • リストの各地点には、最大波高と第1波の到達時刻（分）が表示されます。

8.3 波形グラフ

  • 横軸は地震発生からの経過時間、縦軸は水位 η (m) です。
  • 表示切替: ☑ 選択地点（チェックした地点を重ねる）/ 🎯 単一フォーカス / 🌐 全地点
  • 見出しの統計:
    • 第1波到達: 水位変動の大きさが初めて0.15m以上になった時刻
    • 最大波高: その地点の最大水位
    • 波侵入方向: 最大水位のときの流れの向き（16方位と度数）

注記

震源域の真上や近くの観測地点では、地震直後の地殻変動そのもので水位が0.15m以上変わるため、第1波到達が「0分0秒」になることがあります（全域同時破壊のシナリオ）。内閣府モデルのように破壊が伝播するシナリオでは、破壊が届いた時刻が到達時刻になります。

9. アニメーションの動画保存（MP4）

動画の保存方法は2通りあります。

方法 向いている場面
9.1 計算結果の書き出し（🎬 動画を書き出し） 計算した結果を、決まった長さの動画にしたいとき（推奨）
9.2 再生しながら録画（🎥 MP4録画） 画面で見ている再生をそのまま録画したいとき

9.1 計算結果の書き出し（🎬 動画を書き出し）

  1. シナリオと計算上限時間を選びます（「一括高速計算」などで計算済みでも構いません）。
  2. 「動画の長さ」（10秒 / 20秒 / 40秒 / 60秒）を選び、🎬 動画を書き出し を押します。
  3. 地震発生から計算上限時間までを自動で計算し直しながら動画を作り、完了すると保存されます。進み具合は画面上部の状態表示に％で出ます。
  • 計算は毎回同じ結果になるため、書き出した動画は計算済みの結果と同じです（「一括高速計算」は途中の画面を保存しないので、動画にするために計算し直します）。
  • シミュレーション時間を等間隔に区切ってフレームにするので、動画の長さは選んだ長さになります。例: 120分の計算を20秒の動画にすると、600フレーム（1フレームあたり12秒分）。
  • 書き出しにかかる時間は、120分の計算でおよそ1〜2分です（PCの性能による）。
  • 書き出し中は、計算条件を変える操作（再生・シナリオ選択など）はできません。⏹ 書き出しを中止 を押すと、そこまでの動画を保存して中止します。

9.2 再生しながら録画（🎥 MP4録画）

  1. 再生速度と計算上限時間を選びます。
  2. 🎥 MP4録画 を押すと、録画しながらシミュレーションが始まります（計算済みの場合は最初から）。
  3. ⏹ 録画停止・保存 を押すか、計算上限時間に達すると、動画ファイルが保存されます。

  • 動画には地図の表示内容（ズーム・表示範囲もそのまま）、シナリオ名、地震発生からの経過時間、津波高の凡例が入ります。

  • 形式: MP4 (H.264)、30fps、最大 1920×1080。MP4 に対応していない環境では WebM で保存し、その旨を表示します。

  • 描画1フレームが動画の1フレームになるため、動画の長さは再生速度で決まります（録画中は再生速度どおりに計算します）。

10. CSV出力（市街地シミュレーションとの連携）

「3. 各地の沖合到達予測」の下部のボタンで、チェックした観測地点ごとにCSVファイルを出力します（チェックがない場合は全地点の出力を確認します）。先にシミュレーションの再生か一括高速計算を行ってください。

10.1 出力内容（📋 全期間データ）

  • 地震発生（t=0）から、計算が進んだ時刻までの全データ（約3秒間隔。120分なら約2,400行）。
  • Time_sec は地震発生からの時間です。市街地シミュレーションでもそのまま地震発生からの時刻として使えます。
  • 計算が設定時間（例: 120分）に達する前に出力すると、途中までのデータになることを確認します。沿岸の主要な波は地震の20〜30分後に来ることが多いので、最後まで計算してから出力してください。
  • ファイル名: tsunami_boundary_full_<観測点ID>.csv

11. 物理モデルの概要

注記

式の導出や離散化の詳細は PHYSICS_MODEL.md を参照してください。

  1. 初期波源（Okada 1985）: 矩形断層のすべりによる海底の鉛直変位を半無限弾性体の解析解で求め、海面の初期変位とします。Okada (1985) の検算値と一致することを確認しています。depthKm は断層面の上端の深さです。計算範囲の外縁はコサイン型に滑らかに打ち切ります。
  2. 破壊伝播（内閣府モデル）: 破壊開始点からの距離 ÷ 2.5km/s の時刻から、1分かけて変位を加えます。
  3. 浅水流方程式: 2次元の非線形長波方程式を Arakawa C グリッド上で解きます。南北に26度の範囲を扱うため、緯度ごとに東西の格子間隔を変え、連続の式に球面座標の補正を入れています。
  4. 格子・時間刻み: 1.5分メッシュ（約2.8km）、時間刻み約3秒（CFL条件を満たすよう自動調整）。
    • 高解像度領域（入れ子格子）: 大阪湾・紀伊水道北部（東経134.55°〜135.55°・北緯34.0°〜34.75°）だけは15秒メッシュ（南北約460m・東西約380m）で計算します。毎ステップ、全国の格子の水位を細かい格子の外周に補間して与え、内側を同じ方程式で解きます（一方向の入れ子。細かい格子の結果は全国の格子に戻しません）。鳴門海峡・友ヶ島水道・明石海峡は、それぞれ約10格子で表されます。
  5. 海底摩擦: マニングの粗度係数 0.025（半陰解法）。
  6. 数値ノイズ抑制: 急な海底斜面で生じる格子規模の振動を、4次 Shapiro フィルターで抑えます（津波の主な波長はほとんど減衰させません）。
  7. 外洋境界: 外周約100 kmの吸収層と放射条件で、計算範囲の外へ出た波が反射して戻らないようにしています。
  8. 観測点の値: 周囲の海のセル4つから双線形補間で求めます。

12. 制約と注意事項

  • 沖合の値: 本システムの波高は沖合（水深数十m以深）の値で、海岸での津波高・遡上高ではありません。
  • 格子の粗さ: 約2.8kmメッシュのため、湾や港の内部、狭い海峡の地形は表現できません。大阪湾・紀伊水道北部だけは約400mの高解像度領域で計算しますが、それでも港の中の岸壁や防波堤までは表せません。
  • 高解像度領域の海岸: 細かい格子では水深数mの岸近くのセルまで計算するため、岸で反射して高くなった水位が表示されることがあります（陸への遡上は計算しないため、岸を壁として扱っています）。
  • 断層モデルの簡略化: プリセットや震源クリック指定の断層は、一様なすべりの矩形断層（またはその組み合わせ）です。内閣府モデルも公式データではなく概略再現です。
  • 震源クリック指定: プレート境界は1枚の平面で近似するため、長大な断層（Mw9クラスで約600km）では実際の曲がったプレート境界との差が大きくなります。プレート境界データは現在 USGS Slab1.0 です。
  • 考慮していない現象: 陸の浸水・遡上、潮汐、コリオリ力、波の分散性。
  • 遠方の小さな変位: Mw9クラスの震源では、数百km離れた海域にも数cmの地殻変動が表示されることがあります（計算上正しい値です）。
  • 計算範囲の外周: 外周約100 kmは波を吸収する層なので、その中の水位は実際より小さくなります。観測地点は外周から離れた場所に置いてください。
  • 計算時間: 全国範囲（約110万格子）を計算するため、120分の計算に約1分かかります。

13. よくある質問（FAQ）

  • Q. 「一括高速計算」と「再生」の違いは？

    • A. 再生は画面を描画しながら進めます。一括高速計算は描画を省いて計算上限時間まで一気に計算するので、CSVを出力したいときに便利です。

  • Q. 任意の地点の津波データがほしいときは？

    • A. 「＋ 指定点追加」を押してから、地図上の海域をクリックしてください。計算の途中でも追加でき、その時点から記録します。

  • Q. 市街地シミュレーションにはどのCSVを使えばよい？

    • A. 全期間データ（tsunami_boundary_full_<観測点ID>.csv）を使ってください。Time_sec が地震発生からの時間なので、そのまま境界条件として使えます。計算は最後まで進めてから出力してください。

  • Q. 内閣府のケース①〜⑤を全部まとめたシナリオはないの？

    • A. 各ケースはどれも「駿河湾〜日向灘の全域が破壊する Mw9.1 の巨大地震」で、違いは大すべり域の位置だけです。全ケースの大すべり域を同時に置くと政府の想定を超えるため、用意していません。政府の最大クラスの津波高は、地点ごとに全ケースの最大値をとったものです。

  • Q. 震源クリック指定で日本海側をクリックすると？

    • A. プレート境界データの範囲外か、プレート境界が深すぎるため、カスタム断層パラメータ欄の値（手動）で断層を置きます。日本海東縁の地震などは、走向・傾斜などを手動で設定してください。

  • Q. デスクトップ版で保存したファイルはどこ？

    • A. 「ダウンロード」フォルダです。保存すると画面右下に保存先が表示されます。
