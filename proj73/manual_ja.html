南海トラフ津波広域伝播シミュレーター 操作マニュアル

1. はじめに・システム概要

本ソフトウェアは、南海トラフ巨大地震および連動型地震を想定し、任意の断層破壊シナリオから海底地殻変動を算出し、外洋から日本沿岸各地に至る津波の広域伝播をリアルタイムに物理シミュレーションする対話型シミュレーターです。

開発目的と2段階シミュレーション構想

  1. フェーズ1（広域海洋伝播シミュレーション：本システム）:
    南海トラフ沿いの任意の場所で地震が発生した際、沿岸の各主要観測点（室戸岬沖、潮岬沖、駿河湾口、浜松沖、尾鷲沖、足摺岬沖、日向灘沖、紀伊水道など）における津波波高・流速ベクトル・流向・到達時間を高精度にシミュレーションします。
  2. フェーズ2（市街地津波遡上シミュレーションとの連携）:
    本システムから出力される時系列境界条件（CSV形式）を入力データとして使用し、宮古島等で実績のある高解像度市街地津波遡上シミュレーション（陸上構造物・街路への浸水計算）へとシームレスに接続します。

2. 動作環境とインストール

Webブラウザ版

Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge に対応しています。

cd nankai_trough
npm install
npm run dev

ブラウザで http://localhost:5173/ にアクセスします。

デスクトップ版（Tauri）

  • macOS: 公式ストアで配布される NankaiTroughTsunami.dmg を開き、アプリケーションフォルダにドラッグ＆ドロップして起動します。
  • Windows: ワークフローによりビルドされるインストーラー（.exe）からセットアップ可能です。

3. 画面構成と基本操作

3.1 操作パネル（左列）

  • 地震シナリオ選択: 南海トラフ全域連動 (M9.1)、東南海地震単独 (M8.2)、南海地震単独 (M8.4)、東海地震単独 (M8.0)。
  • パラメータ調整: マグニチュード（Mw 7.5〜9.3）、すべり量（Slip 2.0〜30.0m）。「波源を再計算して初期化」で瞬時に反映。
  • 地図クリックモード: 任意の場所をクリックして震源断層を再配置、または新しい観測地点（紀伊水道、伊勢湾など）を追加。
  • シミュレーション制御: 再生/一時停止、速度（1x〜20x）、上限時間（30分〜180分）、「一括高速計算」（120分を数秒で計算）。

3.2 海洋シミュレーションマップ（中央）

  • 海底地形（GEBCO）水深カラーマップ（浅海: 水色、海溝: 濃紺）と陸地陰影。
  • リアルタイム津波波面（赤: 隆起・波頭、青: 沈降・引き波）。
  • マウスホバーによる経緯度・水深・水位のリアルタイムHUD表示。

3.3 津波波形チャート（右列）

  • Chart.js によるリアルタイム時系列グラフ（選択地点重ね合わせ / 単一フォーカス / 全地点）。
  • 最大波高、ピーク到達時刻、第1波到達時刻、最大時主流向の自動統計解析。

4. 市街地遡上連携用 CSV エクスポート仕様

2つの出力方式

  1. 方式A: 全期間データ（Full Timeline CSV）:
    地震発生（t=0.0s）からの全期間（120分設定時は完全な1,801行）を出力。広域海洋の全体検証用。
  2. 方式B: 市街地連携用トリミング波形（Trimmed City CSV）:
    第1波到達の2分前（120秒前）を t=0.0s に正規化し、初期の無駄時間をカットした実効波形。Phase 2 市街地シミュレーターの沖合境界面入力に最適。

5. 物理モデルと数値安定化

  • Okada（1985）弾性転位モデル: 半無限弾性体表面の鉛直変位を解析的に算出。
  • 2次元非線形浅水流方程式（SWE）: Arakawa C-grid 上でスタガード差分、半陰解法マニング摩擦項により安定計算。
  • Shapiro フィルター（Laplacian平滑化）: 潮岬沖等の急深海底崖で生じる $2\Delta x$ 寄生格子ノイズ（1分周期振動・0.5m跳ね）を微小拡散で除去。長周期津波エネルギーを99.9%保持。
  • 空間双線形補間: 周囲4海洋セルの加重平均でサンプリングし、単一格子セルの数値跳ねを排除。
