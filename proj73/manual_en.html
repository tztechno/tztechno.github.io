Nankai Trough Tsunami Simulator - User Manual

1. Introduction & Overview

The Nankai Trough Tsunami Simulator is an interactive, physically-based numerical simulation software designed to model the generation and broad-scale ocean propagation of mega-earthquake tsunamis along the Nankai Subduction Zone.

Two-Phase Simulation Pipeline

  1. Phase 1: Broad-Scale Ocean Tsunami Propagation (This App):
    Computes seabed displacement from arbitrary Okada rupture faults and solves 2D shallow water equations across the Pacific basin toward the Japanese coastline. Accurately tracks wave elevations, velocity vectors ($u, v$), and arrival times at key coastal monitoring points.
  2. Phase 2: City Inundation & Run-up Coupling:
    Exports time-series boundary condition data (CSV format) directly into localized urban inundation and CFD solvers (such as validated models established in Miyako and other coastal regions).

2. Installation & Running

Web Browser Edition

Compatible with Google Chrome, Apple Safari, Mozilla Firefox, and Microsoft Edge.

cd nankai_trough
npm install
npm run dev

Open http://localhost:5173/ in your browser.

Desktop Application (Tauri v2)

  • macOS: Open NankaiTroughTsunami.dmg distributed from the official store and drag & drop to your Applications folder.
  • Windows: Setup via the production installer (.exe) built through automated CI workflows.

3. User Interface & Controls

3.1 Control Panel (Left Column)

  • Scenario Selector: Full Nankai Trough Megaquake (M9.1), Tonankai (M8.2), Nankai (M8.4), Tokai (M8.0).
  • Parameter Tuning: Mw slider (7.5 - 9.3) and Dislocation Slip slider (2.0m - 30.0m) with instantaneous Okada recomputation.
  • Map Click Modes: Reposition the rupture epicenter or dynamically instantiate custom observation stations (e.g., Kii Channel, Ise Bay).
  • Simulation Controls: Play/Pause, speed multipliers (1x to 20x), duration caps (30m to 180m), and "Fast-Forward" solving 120 minutes in seconds.

3.2 Simulation Map (Center Column)

  • GEBCO bathymetric color relief (cyan shelf to deep navy trenches) with land terrain shading.
  • Real-time wavefront overlays (Warm Red: surge crests, Cool Blue: recession troughs).
  • Real-time cursor HUD displaying exact coordinates, bathymetric depth, and instantaneous water elevation.

3.3 Waveform Charts (Right Column)

  • Chart.js multi-point time-series plots (Selected Overlay / Focus Point / All Points).
  • Automatic analytical statistics: peak surge height, peak arrival time, first arrival threshold, and dominant flow heading.

4. Phase-2 City Inundation CSV Export

Export Modes

  1. Mode A: Full Timeline Data (Full Timeline CSV):
    Continuous time series starting strictly from earthquake rupture ($t = 0.0\text{s}$) up to simulation end (1,801 rows at 4s intervals for 120 min). Ideal for macro-basin verification.
  2. Mode B: City-Inundation Trimmed Waveform (Trimmed City CSV):
    Normalizes time such that 2 minutes (120 s) prior to first wave arrival becomes $t = 0.0\text{s}$, capturing effective run-up dynamics while eliminating pre-arrival quiescent time.

5. Physical Modeling & Stabilization

  • Okada (1985) Dislocation Model: Analytical half-space elastic vertical deformation.
  • 2D Nonlinear Shallow Water Equations (SWE): Staggered leapfrog scheme on an Arakawa C-grid with semi-implicit Manning bottom friction.
  • Shapiro Filter: Mild Laplacian dissipation eliminating $2\Delta x$ high-frequency parasite grid oscillations (1-min slope noise off Shionomisaki) while preserving 99.9% of physical tsunami energy.
  • Spatial Bilinear Sampling: Weighted 4-cell marine interpolation preventing discrete integer step artifacts.
