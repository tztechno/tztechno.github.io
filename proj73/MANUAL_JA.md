# 南海トラフ津波広域伝播シミュレーター 操作マニュアル
**Nankai Trough Tsunami Simulator - User Manual (Japanese)**

---

## 1. はじめに・システム概要

本ソフトウェアは、南海トラフ巨大地震および連動型地震を想定し、任意の断層破壊シナリオから海底地殻変動を算出し、外洋から日本沿岸各地に至る津波の広域伝播をリアルタイムに物理シミュレーションする対話型シミュレーターです。

### 開発目的と2段階シミュレーション構想
1. **フェーズ1（広域海洋伝播シミュレーション：本システム）**:
   * 南海トラフ沿いの任意の場所で地震が発生した際、沿岸の各主要観測点（室戸岬沖、潮岬沖、駿河湾口、浜松沖、尾鷲沖、足摺岬沖、日向灘沖、紀伊水道など）における**津波波高・流速ベクトル・流向・到達時間**を高精度にシミュレーションします。
2. **フェーズ2（市街地津波遡上シミュレーションとの連携）**:
   * 本システムから出力される時系列境界条件（CSV形式）を入力データとして使用し、宮古島等で実績のある高解像度市街地津波遡上シミュレーション（陸上構造物・街路への浸水計算）へとシームレスに接続します。

## 2. 動作環境とインストール

### Webブラウザ版
* **対応ブラウザ**: Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge（最新版推奨）
* **実行方法**:
  ```bash
  cd nankai_trough
  npm install
  npm run dev
  ```
  ブラウザで `http://localhost:5173/` にアクセスします。

### デスクトップ版（Tauri）
* **macOS**:
  * プロジェクトルートの `NankaiTroughTsunami.dmg` を開き、アプリケーションフォルダにドラッグ＆ドロップして起動します。
* **Windows**:
  * GitHub Actions ワークフロー（`.github/workflows/build-windows.yml`）により、Windows用インストーラー（`.exe`）が自動生成されます。
* **ソースコードからのビルド**:
  ```bash
  cd nankai_trough_desktop
  npm install
  npm run tauri dev    # 開発モード起動
  npm run tauri build  # リリースビルド（dmg / exe）
  ```

## 3. 画面構成と基本操作

画面は **「左列：操作・設定パネル」**、**「中央：海洋シミュレーションマップ」**、**「右列：津波波形チャート・観測点詳細」** の3カラムで構成されています。

```
+------------------------+------------------------------------+--------------------------+
|  左パネル (Controls)   |     中央マップ (Simulation Map)    |  右パネル (Wave Chart)   |
| - 言語切替 (日/英)     | - 海底地形 (GEBCO水深カラー)       | - 水位変動リアルタイム   |
| - シナリオ選択         | - 津波波面 (隆起:赤 / 沈降:青)     |   波形グラフ (Chart.js)  |
| - Mw / すべり量調整    | - 波源断層矩形・震源アイコン       | - 重ね合わせ表示切替     |
| - 震源・観測点追加     | - 観測点ピン・最大波高バッジ       | - 到達時刻・流向統計     |
| - シミュレーション制御 | - マウスホバー情報 (水深・水位)    | - 連携用CSV出力ボタン    |
| - 観測地点一括管理     |                                    |                          |
+------------------------+------------------------------------+--------------------------+
```

### 3.1 左パネル（設定と制御）

1. **言語切替ボタン**:
   * `日本語` / `English` をワンクリックで切り替え可能。設定はブラウザ/アプリに保存されます。
2. **地震シナリオ選択**:
   * **南海トラフ全域連動 (M9.1)**: 駿河湾〜日向灘の4セグメントが一斉破壊する内閣府想定最大クラス。
   * **東南海地震単独 (M8.2)**: 熊野灘〜潮岬沖を波源とする1944年型。
   * **南海地震単独 (M8.4)**: 高知・室戸〜足摺沖を波源とする1946年型。
   * **東海地震単独 (M8.0)**: 駿河トラフ〜遠州灘を波源とする想定地震。
3. **断層パラメータの調整**:
   * **マグニチュード（Mw）**: 7.5 〜 9.3 の範囲でスライダー調整可能。すべり量がスケーリング則に従って自動連動します。
   * **すべり量（Slip）**: 2.0m 〜 30.0m の範囲で直接変更可能。
   * **「波源を再計算して初期化」**: パラメータ変更後に押下すると、Okadaモデルによる初期海面変位が即座に再計算されます。
4. **地図クリックモード**:
   * **震源位置を変更**: ボタンを押した後に地図上をクリックすると、任意の座標を主震源とする断層モデルを再配置します。
   * **観測地点を追加**: ボタンを押した後に地図上の海域をクリックすると、任意の場所に新しい観測点（例: 紀伊水道、伊勢湾など）をピンポイントで追加できます。
5. **シミュレーション実行制御**:
   * **再生 / 一時停止**: 時間進行のトグル。
   * **一括高速計算**: 描画処理をスキップし、設定上限時間（最大180分）までの物理計算を数秒で完了させます（CSV作成時に最適）。
   * **再生速度**: 1倍速 〜 20倍速。
   * **計算上限時間**: 30分 / 60分 / 120分 / 180分 から選択可能（デフォルト: 120分）。
   * **リセット**: 時間を t=0 に巻き戻し、初期海面変位状態に戻します。
6. **観測地点の一括管理**:
   * 各地点のチェックボックスでグラフ重ね合わせおよび一括CSV出力の対象を選択可能。
   * 「全選択」「全解除」「初期地点にリセット」ボタンを完備。

### 3.2 中央パネル（海洋マップ）

* **海底地形カラー**:
  * 陸地は緑〜灰色、浅海（水深<200m）は薄い水色、大陸棚斜面〜南海トラフ海溝軸（水深4,000m超）は濃紺でグラデーション表示。
* **リアルタイム津波波面**:
  * **赤色（暖色）**: 水位上昇（波頭・押し波）。
  * **青色（寒色）**: 水位降下（引き波）。
  * 振幅に応じて動的に透過ブレンド表示されます。
* **波源断層表示**:
  * 断層の走向（Strike）、傾斜（Dip）、すべり角（Rake）に基づくOkada地殻変動グリッドおよび断層枠を表示。
* **マウスホバー情報**:
  * マウスカーソル位置の経緯度、水深（海）または標高（陸）、およびリアルタイムの水位変動量（m）がフッターに表示されます。

### 3.3 右パネル（波形チャートと観測データ）

* **水位時系列グラフ（Chart.js）**:
  * 地震発生（t=0）からの水位変動推移をリアルタイムにプロット。
  * **グラフ表示モード**:
    * **選択地点重ね合わせ**: チェックを入れた複数地点を同時に同一グラフ上に重ねて比較。
    * **単一地点**: フォーカスしている1地点のみを詳細表示。
    * **全地点**: 登録されている全観測点を一括プロット。
* **観測統計サマリー**:
  * **最大波高（Max Wave Height）**: 到達した最大津波高（m）。
  * **最大波到達時刻（Peak Time）**: 最大波が記録された経過時間。
  * **第1波到達時刻（First Arrival）**: 水位変動が0.15mを超えた時刻。
  * **最大時主流向（Dominant Direction）**: 最大波高時の流速ベクトル方位（16方位および度数表示）。

## 4. 市街地遡上連携用 CSV エクスポート機能

本シミュレーターの最大の特徴は、**第2フェーズ（市街地津波シミュレーション）の境界条件としてそのまま入力できる高精度CSVデータ**を出力できる点です。

### 4.1 出力形式（2つの方式）

1. **方式A: 全期間シミュレーションデータ（Full Timeline CSV）**
   * **用途**: 地震発生の瞬間（$t=0\text{s}$）からの全体挙動の確認・広域解析用。
   * **特徴**: $t=0.0\text{s}$ からシミュレーション終了時刻まで、4秒刻み（計1801行 / 120分の場合）で完全に連続した時系列データを出力。
   * **ファイル名**: `tsunami_boundary_full_<観測点ID>.csv`

2. **方式B: 市街地連携用トリミング波形データ（City Inundation Trimmed CSV）**
   * **用途**: 市街地遡上シミュレーター（Phase 2）の沖合境界面への直接入力。
   * **特徴**: 第1波到達の**2分前（120秒前）を $t=0$ に正規化**し、初期の無変動期間をカットして主要波が通過するまでの実効波形のみを抽出。
   * **ファイル名**: `tsunami_boundary_city_<観測点ID>.csv`

### 4.2 CSVフォーマット仕様

```csv
# Tsunami Boundary Wave Condition for City Simulation (Phase 2)
# Location: 室戸岬沖 (高知) (Lon: 134.2, Lat: 33.2)
# Mode: Trimmed Effective Wave (Shifted to t=0 at 2-min before arrival)
# Original Absolute First Arrival: 642.0 s
# Original Absolute Max Surge: 6.82 m (at 1024.0 s)
# Time Offset: -522.0 s (Absolute_Time_sec = Time_sec + 522.0)
Time_sec,Elevation_m,U_velocity_m_s,V_velocity_m_s,Speed_m_s,Direction_deg
0.0,0.012,0.005,-0.002,0.005,111.8
4.0,0.035,0.015,-0.008,0.017,118.1
...
```

| カラム名 | 単位 | 内容・説明 |
|---|---|---|
| `Time_sec` | 秒 (s) | 経過時間（方式Aは地震発生基準、方式Bは到達2分前を0基準） |
| `Elevation_m` | メートル (m) | 静水面からの水位変動量（隆起: 正、沈降・引き波: 負） |
| `U_velocity_m_s` | m/s | 東西方向の流速（東向き: 正、西向き: 負） |
| `V_velocity_m_s` | m/s | 南北方向の流速（北向き: 正、南向き: 負） |
| `Speed_m_s` | m/s | 合成流速スカラー値 $\sqrt{u^2 + v^2}$ |
| `Direction_deg` | 度 (deg) | 流向（北: 0°, 東: 90°, 南: 180°, 西: 270°） |

## 5. 採用している物理モデルと数値安定化

1. **初期海面変位（Okada 1985 弾性転位モデル）**:
   * 断層パラメータ（走向、傾斜、すべり角、深さ、断層長、断層幅、すべり量）から、半無限弾性体表面の鉛直変位量を解析的に導出。
2. **浅水流方程式（2次元非線形SWE）**:
   * 連続の式: $\frac{\partial \eta}{\partial t} + \frac{\partial M}{\partial x} + \frac{\partial N}{\partial y} = 0$
   * 運動方程式: 半陰解法（Semi-implicit）Manning粗度摩擦項を組み込んだリープフロッグ法。
3. **スタガード格子（Arakawa C-grid）**:
   * 水位 $\eta$ をセル中心、流量フラックス $M, N$ をセル境界面に配置し、質量保存則を厳密に担保。
4. **Shapiro フィルター（Laplacian 平滑化）による数値ノイズ抑制**:
   * 潮岬沖などの急深な海底崖・大陸棚斜面で発生しやすい高周波寄生波（$2\Delta x$ 振動・周期1分ノイズ）を微小数値拡散により選択的に除去。物理津波の長周期波（周期10〜60分）の振幅は 99.9% 保持されます。
5. **空間双線形補間サンプリング**:
   * 観測地点の水位・流速を周囲4つの海洋セルの加重平均で算出することで、整数グリッドの段差に起因するステップ跳ねノイズを解消。

## 6. よくある質問 (FAQ)

* **Q. 「一括高速計算」と通常の「再生」の違いは何ですか？**
  * A. 通常の再生は毎フレーム画面を描画しながらアニメーション再生します。「一括高速計算」は描画を省略してバックグラウンドで120分（3,600ステップ）の物理計算を一気に実行するため、数秒で計算が完了し、即座に全期間のCSV出力が可能になります。
* **Q. 任意の地点（例: 徳島県阿南市沖、三重県尾鷲港口など）の津波データを取りたいときは？**
  * A. 左パネルの「＋ 観測地点を追加」をクリックし、地図上の海域をクリックしてください。その位置に新しい観測点が作成され、即座に $t=0$ からのデータ記録が開始されます。
* **Q. 市街地シミュレーションへの連携にはどちらのCSVを使えばよいですか？**
  * A. 市街地側の計算コストを抑え、第1波が迫ってくる直前からシミュレーションを開始したい場合は「方式B（市街地連携用トリミング波形）」を推奨します。地震発生直後からの引き波の全過程を再現したい場合は「方式A（全期間データ）」をご利用ください。
