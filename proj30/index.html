FAQ

よくある質問

本当に画像や動画は外部に送信されませんか？

はい。このツールはサーバーを持たない静的Webアプリで、物体検出の推論はすべて ONNX Runtime Web を使ってブラウザ内（お使いの端末）で実行されます。アップロードした画像・動画がネットワーク越しに送信されることはありません。

対応している物体の種類は？

COCOデータセットの80クラス（人、車、犬、猫、椅子など）に対応しています。

動画のダウンロード形式は？

ブラウザの MediaRecorder API の制約上、処理済み動画は WebM（VP9/VP8）形式で出力されます。MP4/H.264 での出力には対応していません。

無料枠を使い切ったらどうなりますか？

画像検出の実行・動画処理の開始をそれぞれ1回として、合計5回まで無料で利用できます。それ以降は¥100の買い切り購入で無制限に使えるようになります。購入は無料枠を使い切る前でも後でも、いつでも可能です。

スマートフォンでも使えますか？

モダンブラウザであれば動作しますが、端末の処理性能により推論速度は変わります。特に動画検出は処理負荷が高いため、PCでの利用を推奨します。
