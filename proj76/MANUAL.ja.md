# Hiroshima Landslide(広島 土砂災害シミュレーター)— 使用マニュアル

広島市の3D都市モデル(PLATEAU)の地形・建物・土砂災害警戒区域と、広域の標高データ(`hiroshima.tif`、SRTM)をもとに、雨で斜面の土が湿って崩れ、崩れた土砂が土石流として流れ下って街の建物を埋めていく様子を3Dで再現・録画するWebアプリケーションです。

- 降雨にともなう土の中の水位の上昇と、斜面の安全率(崩れにくさ)の低下をGPUで計算します
- 崩れた土砂が谷を流れ下り、扇状地に広がって建物を埋める範囲・深さ・勢い(衝撃圧)を計算します
- 斜面をクリックして「ここが崩れたら」という崩壊源を指定することもできます
- 広島県の土砂災害警戒区域(イエロー・レッド)と比較できます
- 好きなカメラアングル・カメラワークでMP4動画を作れます

計算方法やデータ処理の詳細は [README.md](README.md) を参照してください。

## 1. 起動方法

### デスクトップ版(macOS / Windows)
- **macOS**: `HiroshimaLandslide_<版>_aarch64.dmg` を開き、アプリを「アプリケーション」フォルダへドラッグします。初回は右クリック →「開く」で起動します(Apple Silicon 用)
- **Windows**: `HiroshimaLandslide_<版>_x64-setup.exe` を実行してインストールします(Windows 10 / 11)
- 録画・CSV・GeoTIFF は「ダウンロード」フォルダに保存されます。住所検索と新しいタイルの作成にはインターネット接続が必要です

### Web版(開発用)

```bash
cd hiroshima_landslide
npm install
npm run dev
```

ブラウザで `http://localhost:5176/` を開きます。WebGL2 と浮動小数点レンダーターゲットに対応したブラウザ(Chrome / Edge / Safari の最新版)が必要です。GPU の性能で計算速度が大きく変わります。

## 2. 画面の構成

### 表紙
最初に表紙が表示されます。読み込みが終わると「開始」ボタン(Enter キー)で本画面に移ります。右側の地域の一覧をクリックすると、その地域を開きます。左上の「表紙」ボタンでいつでも表紙に戻れます。

### 画面の各部
| 場所 | 内容 |
|---|---|
| 左のパネル | 1. 地域 〜 7. 録画 の設定 |
| 中央 | 3D表示。左上に日時・雨量・崩壊面積・土砂の量、右上に凡例 |
| 左下 | 広域マップ(hiroshima.tif 全域)。赤枠が表示中の地域。クリックで新しいタイルの場所を選べます |
| 下 | 再生ボタン・時刻スライダー・グラフ(雨量と、選んだ地点の安全率・土砂の深さ) |
| 右下 | クリックした地点の情報 |

パネル右上のボタンで日本語 / English を切り替えられます。

### 住所・地名から新しいタイルを作る
「住所・地名から新しいタイルを作る」を開き、住所や地名(例: 安佐北区口田南)を検索して候補を選び、大きさ(1/2/3 km)を決めて「このタイルを作成して表示」を押します。左下の広域マップをクリックして場所を選ぶこともできます。インターネットから地形(国土地理院 5m標高)、建物・土砂災害警戒区域(PLATEAU)、航空写真を取得して10〜20秒で作ります。作ったタイルはブラウザに保存され、一覧に「★」付きで出ます。

## 4. 降雨条件を決める

| パターン | 内容 |
|---|---|
| 2014年8月 広島豪雨型(三入, 模擬波形) | 8月19日21時から10時間。時間最大101mm・3時間217.5mm・24時間257mm に合わせた模擬波形 |
| 2018年7月 西日本豪雨型(広島, 模擬波形) | 7月5日0時から48時間、総雨量約430mm、6日夜に時間48mm のピーク |
| 観測値の貼り付け(1時間ごと mm) | 気象庁「過去の気象データ」などの1時間降水量を古い順に貼り付け。開始日時を入れると時刻表示に使います |
| 一定強度 / 中央集中型 / 線状降水帯型 / カスタム(10分ごと) | 仮想的な降雨 |

- **降雨後の計算時間**: 雨が止んだ後も計算する時間。地下水が遅れて谷に集まり、雨が止んだ後に崩れることもあります
- **保存間隔・降雨中(分)/ 土砂の移動中(秒)**: 再生・録画に使うコマの間隔。1回の計算で約800コマに収まるよう、土砂の移動が長く続くと自動で間隔を広げます

## 5. 土質・崩壊条件を決める

| 項目 | 既定値 | 意味 |
|---|---|---|
| 斜面の土層厚 | 1.5 m | 岩盤の上の土(まさ土)の厚さ。谷では厚く(最大1.6倍)、35°を超える急斜面では薄くします |
| 粘着力 c' | 8 kPa | 土の粘着力と木の根の補強の合計 |
| 内部摩擦角 φ' | 35° | 土の摩擦の強さ |
| 単位体積重量 γ | 18 kN/m³ | 土の重さ |
| 透水係数 k | 0.1 cm/s | 土の中の水の流れやすさ(森林土壌の大きな孔を含む値) |
| 浸透能 | 80 mm/h | 地面がしみ込ませられる雨の強さの上限 |
| 有効間隙率 | 0.3 | 水がたまる隙間の割合 |
| 初期飽和度 | 0.2 | 降雨前の土の湿り具合(先行降雨)。ここから12時間排水させた状態で降雨を迎えます |
| 進行性崩壊の FS | 1.1 | すぐ下が崩れたとき、安全率がこの値未満なら上の斜面も続けて崩れます |
| 降雨による崩壊を判定する | オン | オフにすると、指定した崩壊源だけが崩れます |

**土石流**: 摩擦係数 μ(大きいほど早く止まる。堆積する勾配の目安は atan μ)、乱流係数 ξ(小さいほど速度が落ちる)、体積倍率(崩れた土に水が加わった土石流の体積)、侵食係数 E(流れる土砂が河床の土を取り込む強さ)。

**崩壊源の指定**: 半径と発生時刻(開始から何分後)を決めて「＋ 斜面をクリックして追加」を押し、3D画面の斜面をクリックします(最大8か所、赤紫の輪で表示)。もう一度ボタンを押すと追加を終わります。「ここが崩れたら土砂はどこまで来るか」を調べるときは、「降雨による崩壊を判定する」をオフにすると指定した場所だけが崩れます。

パネルの下に、土層のある面積、降雨前の安全率、不安定なため薄くした土層の面積が表示されます。

## 6. 計算する

「▶ 計算開始」を押します。雨が降っている間は長い時間刻み(最大60秒)で土の中の水だけを計算し、どこかが崩れると自動で短い時間刻み(0.01〜0.5秒)に切り替えて土石流を計算します。土石流が止まると長い時間刻みに戻ります。計算中もカメラは自由に動かせます。

- **計算速度**: 1フレームあたりのステップ数。大きいほど速く進みます(画面の動きは重くなります)
- **安全係数(CFL)**: 土石流の時間刻みの安全率。大きいほど速いですが、不安定になりやすくなります

計算が終わると、崩壊の数・面積、崩壊した土砂の量、土砂の到達範囲・堆積面積、埋没した建物・衝撃圧が大きい建物の数が表示されます。崩壊は100 m²以上のまとまりを1か所として数えます。

## 7. 結果を見る

### 再生
下部の ▶ で再生、スライダーで時刻を選べます。再生は保存したコマ単位で進むので、何時間もの降雨は早送り、数分の土石流はゆっくり再生されます(再生速度: コマ/秒)。

### 地点をクリックする
3D画面をクリックすると、その地点の緯度経度・地盤高・傾斜・土層厚、降雨前と飽和時の安全率、崩壊した時刻、最大堆積深・到達時刻・最大流速・衝撃圧、土砂災害警戒区域を表示します。建物をクリックすると、周囲の最大堆積深と衝撃圧から「被害なし / 土砂が到達 / 床上相当の埋没 / 1階が埋没 / 損壊のおそれ」を表示します。

下のグラフには、雨量(青い棒)、その地点の安全率 FS(緑、赤い破線が FS=1)、土砂の深さ(茶)、崩壊した時刻(赤い縦線)が表示されます。「📄 この地点の結果をCSVで保存」で、計算条件と時系列(雨量・飽和度・安全率・土砂の深さ)を保存できます。

### 最大堆積深を表示する
「5. 表示」の「最大堆積深を表示(計算完了後)」で、計算中の最大の土砂の深さを表示します。計算後は「最大堆積深 GeoTIFF」「崩壊・侵食深 GeoTIFF」も保存できます(平面直角座標系III系, EPSG:6671)。

## 8. 表示を切り替える

| 項目 | 選択肢 |
|---|---|
| 地表 | 航空写真 / 標高段彩 / 土壌の飽和度 / 斜面の安全率 FS / 傾斜 |
| 土砂 | リアル(泥の色) / 堆積深の区分 |
| 建物 | 白 / 埋没深で色分け / 衝撃圧で色分け(計算後) |

崩壊・侵食した斜面は、土がなくなった分だけ地面が下がり、むき出しの土の色(茶)で表示されます。建物は土砂より下の部分が泥の色になります。そのほか、土砂の不透明度、航空写真の影の補正、建物・ラベル・周辺の地形の表示を切り替えられます。

視点の操作: 左ドラッグ=回転、右ドラッグ=移動、ホイール=カーソル位置へズーム、ダブルクリック=その地点を注目点に、L キー=視点固定。

## 9. 土砂災害警戒区域と比較する

「6. 土砂災害警戒区域」で、PLATEAU に含まれる区域(急傾斜地の崩壊・土石流・地すべり)を選ぶと、警戒区域(黄)・特別警戒区域(赤)を地表に重ねます。区域の面積と区域内の建物数、計算後は「土砂の到達範囲のうち区域内の割合」「0.5m以上埋没した建物のうち区域内の棟数」を表示します。警戒区域は地形から定めた区域で、計算結果とは別のものです。

## 10. 録画する

解像度(最大4K)、fps、動画の長さ、対象の時間範囲(開始・終了 分)、カメラ(現在の視点で固定 / キーフレームを補間 / 旋回)を選び、「● 録画して保存」を押します。「保存コマごとに等間隔で再生」をオンにすると土石流の部分がスローモーションに、オフにすると時刻に比例した速さになります。1フレームずつ描画して MP4(H.264)にエンコードするので、PCの速度に関係なく滑らかな動画になります。

## 11. 計算の考え方(要点)

1. **浸透と地下水**: 雨は浸透能までしみ込み、土層の中の地下水位を上げます。地下水は岩盤面に沿って斜面の下へ流れ(Darcy 則)、谷(0次谷)に集まります
2. **斜面の安定**: 無限長斜面の安全率 FS = [c' + (γD − γw·hw)cos²θ·tanφ'] / (γD·sinθcosθ)。地下水位 hw が上がると FS が下がり、1 を下回ると土層全体が崩れます
3. **土石流**: 崩れた土(×体積倍率)を、地表の勾配による重力と Voellmy 型の摩擦(Coulomb 摩擦 + 乱流抵抗)で流します。勾配が緩くなると止まって堆積します。急な河床では土を取り込んで量が増えます
4. **建物**: 屋根までの障害物として土砂をせき止め、周りに積もった土砂の深さ(埋没深)と、ぶつかった土砂の衝撃圧(ρv²)で被害の目安を判定します

詳細は [README.md](README.md) を参照してください。

## 12. 注意・制約

- 一様な土質を仮定した概略モデルで、個々の崩壊地点を予測するものではありません。「どの谷が崩れやすいか」「崩れた土砂がどこまで届くか」の傾向を見るためのものです
- 降雨パターンの「2014年8月」「2018年7月」は公表値に合わせた模擬波形です。実測値は「観測値の貼り付け」を使ってください
- 不飽和帯での浸透の遅れ、表面流、河川の流量、砂防ダム、巨礫の集中は扱いません
- 衝撃圧 30 kPa は木造家屋の損壊の大まかな目安です
- 周辺の広域地形(SRTM)は表示のみで、計算は詳細タイル(2m格子)の中だけで行います
