SYSTEM FEATURES

3D / 2D VIEW SWITCH

ボタンひとつで2D（フラットビュー）と立体的な3Dビューに切り替え可能。近未来の立体マトリクスでの没入体験をその手に。

START LEVEL SELECTION

新たに搭載された難易度セレクトにより、最初から高速落下するレベル10など任意の速度でスタート。10消去ごとに難易度が上昇します。

CYBER SYNTH AUDIO

ブラウザでリアルタイム生成されるWeb AudioベースのFMシンセサイザーを実装。ブロックの設置や回転のアクションを、独特の電子音響で彩ります。

GHOST POSITION INDICATOR

落下地点の予測線（ゴーストエディット）を表示。高速落下環境でもミスを最小限に抑えるナビゲーションシステム。
