01 // THE_GRID_LORE // グリッドの世界観

ネオンが降り注ぐセクター『ヘックス・ビレッジ』において、2つのライバル企業が分散型リソースネットワークの支配権を巡って抗争を繰り広げている。グリッドは価値あるパケットデータノードを生成する：パケット、レンガ（ハードウェア）、セキュリティ、メモリ、プロセッサ。

自らの組織を率いてネットワークの交点を占拠せよ。レーザーハイウェイでノードを接続するのだ。ただし、荒野のグリッドを彷徨い、セクターをロックダウンしてパケットを盗み出す「盗賊ウイルス」プログラムには注意せよ。貿易プログラムを最適化し、デュアルネットワーククロックを回して、12勝利ポイントを獲得してグリッドを永久にハックせよ。

02 // CYBER_GRID_PROTOCOLS // システムプロトコル

HEXAGONAL_MATRIX

頂点立ち（Pointy-Topped）の六角形タイルを採用したアキシアル座標系設計（19のリソースゾーン、54のノード、72のリンクベクトル）。高性能SVGグリッドレンダラーを搭載。

AI_NEURAL_SIMULATION

Easy、Medium、Hardの難易度を搭載したニューラルエンジンと対戦可能。Slow、Normal, Fast, Hyper速度でAI同士の戦術シミュレーションを観戦することも可能。

LINKED_DRONE_PROTOCOL

「商人と蛮族」の2人プレイ用ルール：2つの中立ドローン勢力の開拓地や街道を代理で配置し、相手の配置をブロックしたり盤面を操作したりする戦略的駆け引き。

TRADE_TOKEN_HACKS

トレードトークンを消費して相手をハック。相手のカードを強制的に奪って不要なデータを渡す「強制取引」や、盗賊ウイルスを安全な場所へ移動させるサイバーアクションを実行可能。
