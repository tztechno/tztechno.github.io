TECHNICAL SPEC // 技術構成

CyberSchnapsenはReact + TypeScript製のクライアントサイド・ゲームエンジンと、Netlify Functionsによるサーバーレスな決済処理を組み合わせ、軽量かつサーバーコストを抑えた構成で動作しています。

DEAL & TRUMP
20枚のカードを両者に5枚ずつ配札し、切り札を1枚公開。
TRICK LOGIC
切り札優先・同スート判定・フェーズ2のマストフォローをクライアント側で判定。
AI ENGINE Lv1–4
貪欲法からカードカウンティング、終盤の完全読み（ミニマックス探索）まで4段階。
STRIPE CHECKOUT
Netlify Functionsがワンタイム決済セッションを発行・検証。

React 19 + TypeScript + Vite

対戦盤面の描画コンポーネントと、配札・トリック判定・結婚宣言・AI探索といったゲームロジックを明確に分離して実装。すべての演算はブラウザ内で完結し、外部サーバーへ手札データが送信されることはありません。

Stripe + Netlify Functions

買い切りライセンスの決済はStripe Checkoutで処理し、Netlify Functions上のサーバーレス関数が決済セッションの発行・検証を担当。プレイ回数と購入状態はブラウザのlocalStorageに保存され、余計な個人情報を保持しません。

FAQ // よくある質問

Q: 無料で何回遊べますか？

ブラウザごとに5回まで無料でプレイできます。上限に達すると、¥100（税込）の買い切りライセンスを購入することで無制限にプレイできるようになります。

Q: アカウント登録は必要ですか？

不要です。プレイ回数や購入状態はブラウザのlocalStorageに保存される仕組みのため、メールアドレスやパスワードの登録なしでそのまま遊べます。ブラウザや端末を変更すると無料プレイ回数はリセットされます。

Q: 人と対戦することはできますか？

現在は「人 vs AI」と「AI vs AI（観戦）」のみに対応しています。シュナップセンは互いの手札を見せない前提のゲームのため、同じ画面を共有するローカル対戦は用意していません。まずはAI相手に本格ルールを楽しめます。

Q: AIのレベルはどう違いますか？

Lv1は基本の貪欲戦略、Lv2は山札クローズの判断が加わり、Lv3は場に出たカードを記憶して切り札を温存するなどより戦略的に、Lv4は山札が閉じた後の完全情報になった終盤をミニマックス探索でほぼ最適に解きます。人 vs AI・AI vs AIのどちらでもレベルを選択できます。

Q: スマートフォンでも遊べますか？

はい、Chrome や Safari などの標準的なモバイルブラウザで動作します。ただし画面が小さい端末ではカードの視認性が下がる場合があるため、より快適に遊びたい場合はPCやタブレットでのプレイを推奨します。

Q: 購入したライセンスは他の端末でも使えますか？

ライセンスの購入状態はブラウザのlocalStorageと決済セッションIDに紐づいて管理されます。別のブラウザや端末に切り替えた場合は、現状は改めて購入いただく必要があります。
