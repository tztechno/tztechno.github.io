# Kyoto Drone 操作マニュアル

PLATEAU の京都市の街並み（3D 建物 約 51 万棟）の中で、物理シミュレーション（MuJoCo）で動くドローンを飛ばすブラウザアプリです。出発地と目的地を選び、5 つのシナリオで「ぶつかる」「避けて飛ぶ」「風や荷物に耐える」「自分で操縦する」を体験できます。

English version: [MANUAL.en.md](MANUAL.en.md)

---

## 1. 起動

```sh
cd kyoto_drone
npm install
npm run data      # 初回のみ（約 20 秒）。京都市のデータを変換して public/data に置く
npm run dev
```

ブラウザで <http://localhost:5173> を開きます。読み込みが終わると、京都駅 烏丸口 → 清水寺 の「2. コース飛行」が選ばれた状態で始まります。

- 航空写真と地図選択の背景地図は、国土地理院からインターネット経由で読み込みます。オフラインでは地面が単色になります。
- PC のブラウザ（Chrome / Edge / Safari / Firefox の最新版）を推奨します。

## 2. 画面の見かた

| 場所 | 内容 |
|---|---|
| 左のパネル | 出発地・目的地、シナリオ、コース、条件、開始ボタン、カメラ。右上の「⟨」で閉じ、「☰」で開きます |
| 上中央 | シナリオ名と現在の状態（待機中・離陸・巡航・回避中・着陸完了・墜落 など） |
| 右上 | テレメトリー（経過時間、対地高度 / 海抜、速度、目的地までの距離、コース逸脱、風、推定質量、推力、傾き、飛行距離 / 電力） |
| 右下 | ミニマップ。読み込んだ範囲、ルート、機体の位置と航跡。クリックすると大きな地図が開きます |
| 左下 | イベントログ（離陸、障害物検知、着陸など） |
| 3D 画面 | 地名ラベル（寺社・駅・名所・山）。建物や山に隠れたラベルは表示されません |

### 言語の切り替え

パネル右上の **English / 日本語** ボタンで表示言語を切り替えます。パネル・HUD・メッセージ・地名（プリセットと 3D ラベル）がすべて切り替わります。選んだ言語はブラウザに保存されます。URL に `?lang=en` を付けて開いても英語になります。

## 3. 出発地・目的地を選ぶ

### プリセットから選ぶ

パネルの「1. 出発地・目的地」の 2 つのリストから選びます（緑 = 出発地、赤 = 目的地）。⇅ ボタンで入れ替えます。

プリセット（20 か所）: 京都駅 烏丸口、清水寺、二条城、八坂神社、伏見稲荷大社、東寺、西本願寺、東本願寺、三十三間堂、四条烏丸、四条大橋 (鴨川)、梅小路公園、京都御所、平安神宮、金閣寺、銀閣寺、下鴨神社、上賀茂神社、嵐山 渡月橋、醍醐寺

### 地図で選ぶ

「🗺 地図で選ぶ」（またはミニマップのクリック）で大きな地図が開きます。

1. 上のボタンで **出発地を選ぶ / 目的地を選ぶ** を切り替えます。開いた直後は出発地です。
2. 地図をクリックすると、その場所が出発地になり、続けて目的地の選択に切り替わります。
3. **決定して閉じる**（または Esc）で閉じます。**↺ 選び直す** で、地図を開いたときの地点に戻ります。

- ドラッグで移動、ホイール・ピンチ・＋－で拡大縮小。**地図 / 写真** で背景を切り替えます。
- 選べるのは PLATEAU 京都市データの範囲（嵐山〜醍醐寺、上賀茂〜伏見の約 17 km × 23 km）です。範囲外は暗く表示されます。
- 選んだ地点は、半径 30〜40 m 以内の平らな場所に自動で寄せられます。地点名は近くの施設名（「〇〇付近」）か緯度経度になります。

### 範囲の読み込み

出発地と目的地を決めると、2 点を囲む範囲（周囲 900 m の余裕つき）の建物・地形データを読み込みます。読み込み中は画面上部に「地域の建物・地形データを読み込み中…」と表示されます。

- 衝突判定は 2.5 m 格子です。10 km を超えるような長距離では 5 m 格子になり、建物の形が少し粗くなります。
- 長距離ルートの立案には数秒かかることがあります。

## 4. シナリオ

「2. シナリオ」で選びます。**▶ 開始**（Enter）で飛行を始めます。

### 1. 直線飛行（失敗の体験）

出発地の上空（既定は対地 20 m）から目的地の上空まで一直線に飛びます。障害物を考えないので、ほとんどの場合は建物や東山の斜面に衝突して落下します。「直線の対地高度」を上げると、ぶつかる場所が変わります。

### 2. コース飛行

建物を避けて立案したルート A・B・C のどれかに沿って飛び、目的地に着陸します。「4. 条件」の 4 つのボタンで飛行条件を選びます。

| 条件 | 内容 |
|---|---|
| 無風・荷物なし | 基本の飛行 |
| 強風・荷物なし | 平均風 + 突風 + 乱流。風向は既定でコースに対する横風 |
| 無風・荷物あり | ロープ（既定 1.5 m）で箱（既定 2.5 kg）を吊って運び、接地させて切り離してから着陸 |
| 強風・荷物あり | いちばん厳しい条件。既定の推力では飛び切れないことがあります |

荷物が建物や地面に強く当たる（2.5 m/s 超）か、1 秒以上引っかかると、その時点で失敗になります。

### 3. ルート立案

障害物を避けるルートを 3 通り自動で立案し、距離・最大対地高度・上昇量・所要時間を表で比べます。3D 画面は全体を見渡す視点になります。表の **飛ぶ** を押すと、そのルートで「2. コース飛行」に移ります。

| ルート | 方針 |
|---|---|
| A 高高度直行 | 地上約 80 m で建物の上を最短で |
| B 低空・道路沿い | 地上 45 m 以下で、なるべく道路や川の上を通る |
| C 別回廊 | B とは別の通りを低空で抜ける |

どのルートも、建物から水平 5 m・垂直 8 m 以上離れるように作られます。高度は航空法の 150 m 未満に収めています。

### 4. 自律回避

コックピット視点で、ルート上に置かれたクレーン・係留気球・横切る他機ドローンを前方センサーで検知します。そのあと「回避 → 安全確認 → コース復帰」を自動で行います。

- 画面中央の帯に「⚠ 障害物回避 / 安全確認中 / コース復帰中」が表示されます。
- 右下のセンサー表示は、横が方位 −90°〜+90°、縦が仰角です。赤は近い障害物、緑は空いた方向、白枠は選んだ回避方向を表します。
- 「センサー光線」にチェックを入れると、3D 画面に光線が表示されます。

### 5. マニュアル

キーボードかゲームパッドで自由に飛びます。目的地から 15 m 以内に着地すると到着になります。

| 操作 | キーボード | ゲームパッド（モード 2） |
|---|---|---|
| 前進 / 後退 | W / S | 右スティック 上下 |
| 左右移動 | A / D | 右スティック 左右 |
| 上昇 / 下降 | ↑ / ↓ | 左スティック 上下 |
| 旋回 | ← / →（Q / E も可） | 左スティック 左右 |

- **離陸**: ↑（左スティック上）でモーターが始動します。
- **停止**: 着地してから ↓ を押し続けると、モーターが止まります。

## 5. 条件・パラメータ

「4. 条件」のスライダーです。表示される項目はシナリオによって変わります。

| 項目 | 範囲 | 内容 |
|---|---|---|
| 巡航速度(上限) | 3〜15 m/s | 自動飛行の最高速度（既定 10） |
| 直線の対地高度 | 10〜80 m | 直線飛行の高度（既定 20） |
| 平均風速 | 0〜18 m/s | 強風時の平均風（既定 10） |
| 風向(から) | 16 方位 | 風が吹いてくる方向 |
| 突風(上乗せ) | 0〜12 m/s | 数秒続く突風の強さ（既定 6） |
| 乱流強度 | 0〜60 % | 風の細かな揺らぎ（既定 30 %） |
| 荷物の質量 | 0.5〜4 kg | 吊り荷の重さ（既定 2.5、機体は 1.8 kg） |
| ロープ長 | 0.5〜4 m | 吊りロープの長さ（既定 1.5） |
| モーター推力 | 8〜25 N × 4 | ロータ 1 つの最大推力（既定 13） |
| 再生速度 | ×1〜×8 | 表示の早送り。物理計算は常に 2 ms 刻み |

チェックボックス:

- **外乱オブザーバ(風の推定・補償)**: 風や荷物の振れによる力を推定して打ち消します。OFF にすると、風で流されやすくなるのを比べられます。
- **質量推定(荷物に適応)**: 荷物を持ったときの重さを推定して、高度を保ちます。

## 6. カメラと表示

「カメラ」のボタン、または C キーで切り替えます。

| モード | 内容 |
|---|---|
| 追従 | 機体の後ろから追いかけます |
| コックピット | 機体からの視点。姿勢指示器（水平線・方位・速度・高度）とセンサー表示つき |
| 真上 | 真上から見下ろします |
| 自由 | マウスで回転・ズーム・移動できます |

- **地名ラベル**: 3D の地名タグの表示 / 非表示
- **センサー光線**: 自律回避のセンサー光線の表示 / 非表示
- **効果音（飛行音・衝突音）**: ロータ音と衝突音の ON / OFF（設定はブラウザに保存）。ロータ音は 4 つのモーターの推力に合わせて音程と音量が変わり（上昇や突風、荷物で高く・大きくなる）、カメラが機体から離れると小さくなります。衝突音は衝突速度に応じた強さで鳴ります。音は画面を一度クリックするかキーを押すと出るようになります

## 8. 結果の見かた

飛行が終わると結果が表示されます。

- **到着**: 飛行時間、飛行距離、着陸誤差、コース逸脱の最大 / RMS、推定消費電力量、荷物と風の条件
- **墜落 / 荷物の衝突**: 衝突対象、衝突速度、飛行時間、飛行距離、目的地までの残り

機体が 2 m/s 以上でぶつかるか、接触中に 69° 以上傾くと墜落です。**もう一度** で同じ条件をやり直せます。

## 9. 注意・制限

- 衝突判定があるのは、読み込んだ範囲（出発地・目的地 + 周囲 900 m）だけです。マニュアル飛行でその外に出ると建物をすり抜けます。
- 3D 表示の建物はカメラから約 3 km 以内です。遠くの建物は、近づくと読み込まれます。
- 建物は 2.5 次元（屋根の高さ）で表現しています。張り出しや電線などの細い構造物はありません。
- 京都タワーの塔の部分は PLATEAU にないため、円柱を組み合わせて追加しています。
- 地図選択画面の背景地図（国土地理院 標準地図）は、英語表示でも日本語のままです。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| 読み込みに失敗する | `npm run data` を実行したか確認してください（public/data が必要です） |
| 地面が単色 | インターネット接続を確認してください（航空写真は国土地理院から読み込みます） |
| 強風・荷物ありで飛び切れない | 機体の能力を超える条件です。「モーター推力」を 18 N 程度に上げると飛べます |
| 動作が重い | 「地名ラベル」を OFF にするか、ウィンドウを小さくしてください |
