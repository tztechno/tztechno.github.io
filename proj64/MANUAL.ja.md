# Kyoto Drone 操作マニュアル

PLATEAU の京都市の街並み（3D 建物 約 51 万棟）の中で、物理シミュレーション（MuJoCo）で動くドローンを飛ばすブラウザアプリです。出発地と目的地を選び、5 つのシナリオで「ぶつかる」「避けて飛ぶ」「風や荷物に耐える」「自分で操縦する」を体験できます。

English version: [MANUAL.en.md](MANUAL.en.md)

---

## 1. 起動

```sh
cd kyoto_drone
npm install
npm run data      # 初回のみ（約 20 秒）。京都市のデータを変換して public/data に置く
npm run dev
```

ブラウザで <http://localhost:5173> を開きます。読み込み中はタイトル画面に「飛行前点検」として読み込みの段階（地形・高さ場・MuJoCo 物理・PLATEAU 建物・ルート計画）が順にチェックされます。すべて済むと **離陸（TAKE OFF）** ボタンが出るので、押すか Enter で 4 つのモーターが始動してアプリ画面に移ります。京都駅 烏丸口 → 伏見稲荷大社 の「2. コース飛行」が選ばれた状態で始まります。タイトル画面右下のボタンでも表示言語を切り替えられます。

- 航空写真と地図選択の背景地図は、国土地理院からインターネット経由で読み込みます。オフラインでは地面が単色になります。
- PC のブラウザ（Chrome / Edge / Safari / Firefox の最新版）を推奨します。

## 3. 出発地・目的地を選ぶ

### プリセットから選ぶ

パネルの「1. 出発地・目的地」の 2 つのリストから選びます（緑 = 出発地、赤 = 目的地）。⇅ ボタンで入れ替えます。

プリセット（20 か所）: 京都駅 烏丸口、伏見稲荷大社、八坂神社、三十三間堂、東本願寺、京都国立博物館、東福寺、知恩院、南禅寺、四条烏丸、四条大橋 (鴨川)、錦市場、梅小路公園、京都御所、平安神宮、鴨川デルタ (出町柳)、北野天満宮、京都府立植物園、嵐山 渡月橋、伏見桃山城

どれも世界遺産の構成資産ではなく、屋根の上ではない平らな地面に着陸します（次の「世界遺産は飛行しない」を参照）。

### 地図で選ぶ

「🗺 地図で選ぶ」（またはミニマップのクリック）で大きな地図が開きます。

1. 上のボタンで **出発地を選ぶ / 目的地を選ぶ** を切り替えます。開いた直後は出発地です。
2. 地図をクリックすると、その場所が出発地になり、続けて目的地の選択に切り替わります。
3. **決定して閉じる**（または Esc）で閉じます。**↺ 選び直す** で、地図を開いたときの地点に戻ります。

- ドラッグで移動、ホイール・ピンチ・＋－で拡大縮小。**地図 / 写真** で背景を切り替えます。
- 選べるのは PLATEAU 京都市データの範囲（嵐山〜醍醐寺、上賀茂〜伏見の約 17 km × 23 km）です。範囲外は暗く表示されます。
- 選んだ地点は、半径 30〜40 m 以内の平らな場所に自動で寄せられます。地点名は近くの施設名（「〇〇付近」）か緯度経度になります。
- 世界遺産の境内は赤く塗られ、「（世界遺産・飛行禁止）」と表示されます。

### 世界遺産は飛行しない

「古都京都の文化財」（世界遺産）を構成する 17 か所の境内（清水寺・二条城・東寺・西本願寺・金閣寺・銀閣寺・下鴨神社・上賀茂神社・醍醐寺・天龍寺・仁和寺・龍安寺・西芳寺・高山寺 など）は、飛行禁止として扱います。

- どの 2 点を選んでも、ルート A・B・C は境内と周囲 30 m の上空を通りません。
- 出発地・目的地が境内（周囲を含む）にあるときは、境内の外のいちばん近い平らな場所に移し、地点名に「（世界遺産の外）」を付けます。画面左下にも何 m 移したかを表示します。
- 3D 画面では境内の周りに赤い半透明の柵（高さ 40 m）、ミニマップと地図で選ぶ画面では赤い範囲として表示します。
- 「1. 直線飛行」だけは、障害物も世界遺産も考えずに一直線に飛ぶ失敗の体験なので、境内の上空を横切ることがあります。
- 境内の範囲は OpenStreetMap の世界遺産のタグ（heritage:operator=whc）付きの敷地から作っています。

### 範囲の読み込み

出発地と目的地を決めると、2 点を囲む範囲（周囲 900 m の余裕つき）の建物・地形データを読み込みます。読み込み中は画面上部に「地域の建物・地形データを読み込み中…」と表示されます。

- 衝突判定は 2.5 m 格子です。10 km を超えるような長距離では 5 m 格子になり、建物の形が少し粗くなります。
- 長距離ルートの立案には数秒かかることがあります。

## 4. シナリオ

「2. シナリオ」で選びます。**▶ 開始**（Enter）で飛行を始めます。

### 1. 直線飛行（失敗の体験）

出発地の上空（既定は対地 20 m）から目的地の上空まで一直線に飛びます。障害物を考えないので、ほとんどの場合は建物や東山の斜面に衝突して落下します。「直線の対地高度」を上げると、ぶつかる場所が変わります。

### 2. コース飛行

建物を避けて立案したルート A・B・C のどれかに沿って飛び、目的地に着陸します。「4. 条件」の 4 つのボタンで飛行条件を選びます。

| 条件 | 内容 |
|---|---|
| 無風・荷物なし | 基本の飛行 |
| 強風・荷物なし | 平均風 + 突風 + 乱流。風向は既定でコースに対する横風 |
| 無風・荷物あり | ロープ（既定 1.5 m）で箱（既定 2.5 kg）を吊って運び、接地させて切り離してから着陸 |
| 強風・荷物あり | いちばん厳しい条件。既定の推力では飛び切れないことがあります |

荷物が建物や地面に強く当たる（2.5 m/s 超）か、1 秒以上引っかかると、その時点で失敗になります。

### 3. ルート立案

障害物を避けるルートを 3 通り自動で立案し、距離・最大対地高度・上昇量・所要時間を表で比べます。3D 画面は全体を見渡す視点になります。表の **飛ぶ** を押すと、そのルートで「2. コース飛行」に移ります。

| ルート | 方針 |
|---|---|
| A 高高度直行 | 地上約 80 m で建物の上を最短で |
| B 低空・道路沿い | 地上 45 m 以下で、なるべく道路や川の上を通る |
| C 別回廊 | B とは別の通りを低空で抜ける |

どのルートも、建物から水平 5 m・垂直 8 m 以上離れるように作られます。高度は航空法の 150 m 未満に収めています。世界遺産の境内と周囲 30 m の上空は通りません。2 点を結ぶ直線が世界遺産を横切るときは、表の上に「世界遺産 〇〇 が直線上にあります」と表示し、3 ルートとも避けて立案したことを示します。

### ルートを書き出す

コース飛行・ルート立案の表の下にある「ルート 〇 を書き出す」で、選択中のルートをファイルに保存できます。保存先は飛行記録と同じです（ブラウザはダウンロード、デスクトップ版はダウンロードフォルダ）。

| 形式 | 内容 | 主な用途 |
|---|---|---|
| GPX | 経路の点（緯度経度・海抜）と出発地・目的地 | 地図ソフトでの表示、共有、実機の軌跡との比較 |
| .plan | QGroundControl のミッション（離陸 → 速度設定 → ウェイポイント → 着陸）。高さは離陸地点からの相対。周辺の世界遺産の境内を飛行禁止のジオフェンスとして含む | ArduPilot / PX4 の機体のミッション計画の下書き |
| CSV | ウェイポイントごとの緯度経度・海抜・離陸地点からの高さ・対地高度・距離 | 表計算での確認・解析 |

書き出したルートはシミュレーション用の計画です。実機で使う前に、法令・許可、現地の状況（PLATEAU にない電線・樹木・新しい建物など）、高さの基準、機体の設定を必ず確認してください。

### 4. 自律回避

コックピット視点で、ルート上に置かれたクレーン・係留気球・横切る他機ドローンを前方センサーで検知します。そのあと「回避 → 安全確認 → コース復帰」を自動で行います。

- 画面中央の帯に「⚠ 障害物回避 / 安全確認中 / コース復帰中」が表示されます。
- 右下のセンサー表示は、横が方位 −90°〜+90°、縦が仰角です。赤は近い障害物、緑は空いた方向、白枠は選んだ回避方向を表します。
- 「センサー光線」にチェックを入れると、3D 画面に光線が表示されます。

### 5. マニュアル

キーボードかゲームパッドで自由に飛びます。目的地から 15 m 以内に着地すると到着になります。

| 操作 | キーボード | ゲームパッド（モード 2） |
|---|---|---|
| 前進 / 後退 | W / S | 右スティック 上下 |
| 左右移動 | A / D | 右スティック 左右 |
| 上昇 / 下降 | ↑ / ↓ | 左スティック 上下 |
| 旋回 | ← / →（Q / E も可） | 左スティック 左右 |

- **離陸**: ↑（左スティック上）でモーターが始動します。
- **停止**: 着地してから ↓ を押し続けると、モーターが止まります。

## 5. 条件・パラメータ

「4. 条件」のスライダーです。表示される項目はシナリオによって変わります。

| 項目 | 範囲 | 内容 |
|---|---|---|
| 巡航速度(上限) | 3〜15 m/s | 自動飛行の最高速度（既定 10） |
| 直線の対地高度 | 10〜80 m | 直線飛行の高度（既定 20） |
| 平均風速 | 0〜18 m/s | 強風時の平均風（既定 10） |
| 風向(から) | 16 方位 | 風が吹いてくる方向 |
| 突風(上乗せ) | 0〜12 m/s | 数秒続く突風の強さ（既定 6） |
| 乱流強度 | 0〜60 % | 風の細かな揺らぎ（既定 30 %） |
| 荷物の質量 | 0.5〜4 kg | 吊り荷の重さ（既定 2.5、機体は 1.8 kg） |
| ロープ長 | 0.5〜4 m | 吊りロープの長さ（既定 1.5） |
| モーター推力 | 8〜25 N × 4 | ロータ 1 つの最大推力（既定 13） |
| 再生速度 | ×1〜×8 | 表示の早送り。物理計算は常に 2 ms 刻み |

**飛行中の変更**: 巡航速度、風（平均風速・風向・突風・乱流）、モーター推力、再生速度は、飛行中に動かすとすぐに反映されます。風を強めたり推力を上げ下げしたりして、その場で効き方を比べられます。コース飛行の「無風 / 強風」の切り替えも、荷物の有無が変わらなければ飛行中に反映されます。
荷物の質量・ロープ長・直線の対地高度と、荷物の有無を変える条件ボタンは、機体のモデルやコースに組み込まれるため、飛行中は操作できません（半透明になります）。飛行が終わるか、リセットすると変更できます。
飛行中に変えた設定は、画面左下のメッセージと飛行記録（「9. 飛行記録の保存」）に残ります。

チェックボックス:

- **外乱オブザーバ(風の推定・補償)**: 風や荷物の振れによる力を推定して打ち消します。OFF にすると、風で流されやすくなるのを比べられます。
- **質量推定(荷物に適応)**: 荷物を持ったときの重さを推定して、高度を保ちます。

## 6. カメラと表示

「カメラ」のボタン、または C キーで切り替えます。

| モード | 内容 |
|---|---|
| 追従 | 機体の後ろから追いかけます |
| コックピット | 機体からの視点。姿勢指示器（水平線・方位・速度・高度）とセンサー表示つき |
| 真上 | 真上から見下ろします |
| 自由 | マウスで回転・ズーム・移動できます |

- **地名ラベル**: 3D の地名タグの表示 / 非表示
- **センサー光線**: 自律回避のセンサー光線の表示 / 非表示
- **効果音（飛行音・衝突音）**: ロータ音と衝突音の ON / OFF（設定はブラウザに保存）。ロータ音は 4 つのモーターの推力に合わせて音程と音量が変わり（上昇や突風、荷物で高く・大きくなる）、カメラが機体から離れると小さくなります。衝突音は衝突速度に応じた強さで鳴ります。音は画面を一度クリックするかキーを押すと出るようになります

## 8. 結果の見かた

飛行が終わると結果が表示されます。

- **到着**: 飛行時間、飛行距離、着陸誤差、コース逸脱の最大 / RMS、推定消費電力量、荷物と風の条件
- **墜落 / 荷物の衝突**: 衝突対象、衝突速度、飛行時間、飛行距離、目的地までの残り

機体が 2 m/s 以上でぶつかるか、接触中に 69° 以上傾くと墜落です。**もう一度** で同じ条件をやり直せます。**📄 ログを保存（CSV）** で、そのフライトの記録を保存できます（次の章）。

---

## 9. 飛行記録の保存（CSV）

フライトごとの記録を CSV ファイルに保存できます。Excel で開いても日本語が文字化けしない形式（UTF-8、BOM 付き）です。

| 保存するもの | ボタン | 内容 |
|---|---|---|
| フライトのログ | 結果画面の **📄 ログを保存（CSV）** | そのフライトの 0.1 秒ごとの記録と、イベント・設定変更 |
| 飛行履歴 | パネルの「飛行履歴 N 件」の **CSV 保存** | これまでの全フライトの条件と結果（1 フライト 1 行） |

保存先は、ブラウザ版ではブラウザのダウンロード、デスクトップ版では **ダウンロード** フォルダです（同じ名前のファイルがあると `(2)` を付けて保存し、上書きしません）。保存すると画面左下に保存先が表示されます。

### フライトのログ

ファイル名は `kyoto-drone_<日時>_<シナリオ>-<ルート>.csv` です（例 `kyoto-drone_20261009-141502_course-B.csv`）。先頭に `#` で始まる行でそのフライトの条件と結果（飛行履歴と同じ項目）を書き、その後に 0.1 秒ごとの表が続きます。時刻は物理シミュレーションの時間なので、再生速度を変えても記録の間隔は同じです。pandas では `pd.read_csv(ファイル名, comment='#')` で表だけを読めます。

| 列 | 内容 |
|---|---|
| t_s | 経過時間 (s) |
| x_m, y_m, z_m | 位置（ローカル座標、x 東・y 北・z 海抜、m） |
| lat, lon | 緯度・経度 |
| agl_m | 対地高度 (m) |
| speed_mps, vz_mps | 速さ・上昇率 (m/s) |
| tilt_deg, heading_deg | 傾き・機首方位（北 0°、時計回り） |
| f1_N〜f4_N, thrust_pct, fmax_N | 4 つのロータの推力、最大推力に対する割合 (%)、そのときの最大推力 |
| wind_e_mps, wind_n_mps, wind_u_mps | 機体の位置の風（東・北・上向き成分） |
| dob_e_mps2, dob_n_mps2 | 外乱オブザーバが推定した外乱加速度 |
| mass_est_kg | 推定した全備質量 |
| xtrack_m | コースからのずれ（マニュアルでは空欄） |
| phase, avoid | 飛行段階（takeoff / cruise / landing / done / crashed）・回避の状態（follow / avoid / confirm / return） |
| min_ray_m | 前方センサーの最短距離（自律回避のみ） |
| state | 機体の状態（ground / flying / crashed / landed） |
| event | その時刻のイベント（離陸、障害物検知、墜落など）と飛行中の設定変更 |

400 秒のフライトで約 4,000 行、500 KB 程度です。

### 飛行履歴

フライトが終わるたびに 1 行ずつブラウザに保存されます（最大 1,000 件）。途中でリセットしたり、シナリオや地点を変えたりしたフライトは、結果を「中断 (aborted)」として残します。**消去** で履歴を空にできます。ブラウザのサイトデータを消したときや、プライベートウィンドウでは履歴は残りません。

| 列 | 内容 |
|---|---|
| date | 開始日時（UTC） |
| scenario, from, to, route | シナリオ、出発地、目的地、ルート |
| wind_on, wind_mps, wind_from_deg, gust_mps, turbulence | 開始時の風の条件 |
| payload_kg, rope_m | 荷物の質量・ロープ長（荷物なしは空欄） |
| thrust_N_x4, cruise_mps, dob, mass_est | 開始時の推力・巡航速度、外乱オブザーバ・質量推定の ON / OFF |
| result, reason | 結果（ok 到着 / crash 墜落 / payload 荷物の衝突 / aborted 中断）と衝突対象 |
| flight_time_s, distance_km, energy_Wh | 飛行時間、飛行距離、推定消費電力量 |
| xtrack_max_m, xtrack_rms_m | コース逸脱の最大・RMS |
| goal_dist_m, max_agl_m, impact_mps | 終了時の目的地までの距離、最大対地高度、衝突速度 |
| mass_est_end_kg, setting_changes | 終了時の推定質量、飛行中に設定を変えた回数 |

条件の列は開始時の値です。飛行中に変えた値は、フライトのログの event 列で確かめられます。

## 10. 注意・制限

- 衝突判定があるのは、読み込んだ範囲（出発地・目的地 + 周囲 900 m）だけです。マニュアル飛行でその外に出ると建物をすり抜けます。
- 3D 表示の建物はカメラから約 3 km 以内です。遠くの建物は、近づくと読み込まれます。
- 建物は 2.5 次元（屋根の高さ）で表現しています。張り出しや電線などの細い構造物はありません。
- 京都タワーの塔の部分は PLATEAU にないため、円柱を組み合わせて追加しています。
- 地図選択画面の背景地図（国土地理院 標準地図）は、英語表示でも日本語のままです。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| 読み込みに失敗する | `npm run data` を実行したか確認してください（public/data が必要です） |
| 地面が単色 | インターネット接続を確認してください（航空写真は国土地理院から読み込みます） |
| 強風・荷物ありで飛び切れない | 機体の能力を超える条件です。「モーター推力」を 18 N 程度に上げると飛べます |
| 動作が重い | 「地名ラベル」を OFF にするか、ウィンドウを小さくしてください |
