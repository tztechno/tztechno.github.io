Core Innovations

Kotoba Boothが選ばれる4つの理由

最先端のローカルAI技術とWeb標準技術を融合し、これまでにないスピードとプライバシーを実現。

双方向リアルタイム音声認識 & 読み上げ

AUTOモードで話者の言語（日本語/英語）を自動判定。発話が終わると即座に相手の言語に翻訳し、OS内蔵の高品質な音声合成でクリアに自動発音します。

Under The Hood

最先端の翻訳アーキテクチャ

端末のスペックや用途に合わせて最適な推論エンジンを選択できます。

In-browser FuguMT (WASM) Default / Offline

WebAssembly技術により、端末内のCPU/GPUで高速推論。初回の約145MBモデル保存後は完全オフラインで軽快に動作します。

Local LLM via Ollama Private & Rich Context

PC上で稼働するOllama（gemma4:e4b、qwen等）とシームレスに通信。文脈に応じた極めて自然な翻訳とニュアンス表現が可能です。

Claude AI Cloud High Precision

最先端のクラウドLLM APIを活用し、極めて難解な専門用語や長文もプロの通訳レベルで美しく翻訳します。

How It Works

直感的な3ステップで会話が繋がる

複雑な操作は一切ありません。話すだけでスムーズに通じ合えます。

1

1. 話す・または入力

マイクボタンまたはキーボードからテキストを入力。言語はAUTOで瞬時に自動判定されます。

2

2. リアルタイム高精度翻訳

ニューラルAIが瞬時に文脈を読み解き、自然な英語・日本語に翻訳します。

3

3. 相手の言語で自動音声発音

翻訳完了と同時にOS内蔵のクリアな音声で自動発声。対面でのスムーズな会話を実現します。
