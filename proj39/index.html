SYSTEM FEATURES // 主な特徴

🃏

本格大富豪ルール実装

トランプ52枚＋ジョーカー1枚を使用。手札を早く減らした方が勝ちとなる基本ルールに、パスすると山札から1枚引く特別ルールを採用。8切りによる親権奪取、スートしばりによる制限、4枚出しによる革命、ジョーカーに対するスペ3返し、そして最後の反則上がり判定まで、心理戦を高めるルールが盛り込まれています。

🤖

AI Lv1〜Lv4 & 観戦モード

Lv1のランダムAIから、Lv2の弱カード優先、Lv3の役温存と8切り使用、そしてLv4の手札手数評価による最適プレイを行う本格AIまで4段階。人 vs AIだけでなく、AI同士のレベルを個別に選んで対戦を観戦することもできます。

🔓

登録不要・買い切り課金

アカウント登録やサブスクリプションは一切なし。まずは無料でプレイでき、続けて遊びたい場合のみStripe決済で¥100（税込）の買い切りライセンスを購入するだけのシンプル設計です。

TECHNICAL SPEC // 技術構成

CyberPresidentはReact + TypeScript製のクライアントサイド・ゲームエンジンと、Netlify Functionsによるサーバーレスな決済処理を組み合わせ、軽量かつサーバーコストを抑えた構成で動作しています。

DEAL & DRAW PILE
手札を各10枚配札し、残りの33枚を山札に設定。
DAIFUGO RULES
8切り・しばり・革命・ジョーカー・スペ3返し・反則上がりをクライアント側で判定。
AI ENGINE Lv1–4
手札の手数評価や役温存などのヒューリスティックによる4段階AI。
STRIPE CHECKOUT
Netlify Functionsがワンタイム決済セッションを発行・検証。

React 19 + TypeScript + Vite

対戦盤面の描画コンポーネントと、配札・出し方判定・しばり・革命といったゲームロジックを明確に分離して実装。すべての演算はブラウザ内で完結し、外部サーバーへ手札データが送信されることはありません。

Stripe + Netlify Functions

買い切りライセンスの決済はStripe Checkoutで処理し、Netlify Functions上のサーバーレス関数が決済セッションの発行・検証を担当。プレイ回数と購入状態はブラウザのlocalStorageに保存され、余計な個人情報を保持しません。

FAQ // よくある質問

Q: 無料で何回遊べますか？

ブラウザごとに設定された無料枠の回数までプレイできます。上限に達すると、¥100（税込）の買い切りライセンスを購入することで無制限にプレイできるようになります。

Q: アカウント登録は必要ですか？

不要です。プレイ状態や購入状態はブラウザのlocalStorageに保存される仕組みのため、メールアドレスやパスワードの登録なしでそのまま遊べます。ブラウザや端末を変更すると無料プレイ回数はリセットされます。

Q: 人と対戦することはできますか？

現在は「人 vs AI」と「AI vs AI（観戦）」のみに対応しています。大富豪は互いの手札を見せない前提のゲームのため、同じ画面を共有するローカル対戦は用意していません。まずはAI相手に本格ルールを楽しめます。

Q: AIのレベルはどう違いますか？

Lv1は基本のランダム戦略、Lv2は弱いカードの優先消化、Lv3は8切りや2/Jokerなどの役温存、Lv4は残りの手札手数評価を用いて最も効率的に上がれるよう最適プレイを行います。

Q: スマートフォンでも遊べますか？

はい、Chrome や Safari などの標準的なモバイルブラウザで動作します。ただし画面が小さい端末ではカードの視認性が下がる場合があるため、より快適に遊びたい場合はPCやタブレットでのプレイを推奨します。

Q: 購入したライセンスは他の端末でも使えますか？

ライセンスの購入状態はブラウザのlocalStorageと決済セッションIDに紐づいて管理されます。別のブラウザや端末に切り替えた場合は、現状は改めて購入いただく必要があります。
